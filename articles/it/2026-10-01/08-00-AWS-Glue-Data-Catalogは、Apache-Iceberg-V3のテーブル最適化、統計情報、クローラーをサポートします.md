# AWS Glue Data Catalogは、Apache Iceberg V3のテーブル最適化、統計情報、クローラーをサポートします

- **公開日時**: 2026年10月01日 08:00

## 概要

AWS Glue Data Catalogは現在、Apache Iceberg バージョン3（V3）テーブルのテーブル最適化、統計情報、クローラーをサポートしています。これらの新機能により、V3テーブルを自動的に維持・最適化し、クエリ性能を改善し、S3上での発見を可能にします。

テーブル最適化を使用すると、binpack、ソート、または z-order の戦略を用いて V3 テーブルを圧縮し、クエリ性能を向上させるとともに、期限切れのスナップショットや孤立ファイルを削除してストレージコストを削減できます。これらの最適化は V3 に対応しています。
