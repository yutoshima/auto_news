# Amazon Cognitoがアプリクライアントの秘密情報としてAWS Secrets Managerをサポートしました

## 概要

<p><a href="https://aws.amazon.com/cognito/">Amazon Cognito</a> が <a href="https://aws.amazon.com/secrets-manager/">AWS Secrets Manager</a> と連携するようになり、Secrets Manager にユーザープールのアプリクライアントシークレットを保存・管理できます。Amazon Cognito は、数分でユーザー、AIエージェント、マイクロサービス向けの安全なサインインとアクセス制御を実装するのに役立ちます。アプリクライアントシークレットは、アプリケーションを Cognito に認証させるためのものです。以前は、Cognito で直接これらのシークレットを管理・回転させる必要がありました。
