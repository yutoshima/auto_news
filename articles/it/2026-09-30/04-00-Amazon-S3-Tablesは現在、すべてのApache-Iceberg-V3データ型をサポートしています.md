# Amazon S3 Tablesは現在、すべてのApache Iceberg V3データ型をサポートしています

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月30日 04:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-s3-tables-iceberg-v3-data-types](https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-s3-tables-iceberg-v3-data-types)

## 概要

<p>Amazon S3 Tables は、Apache Iceberg Version 3 (V3) 仕様に定義されているデータ型である geometry、geography、unknown、nanosecond timestamp、そして列のデフォルト値をサポートしました。これにより、地理空間座標やナノ秒精度のイベント時刻を文字列や整数としてエンコードすることなく、ネイティブに保存できるようになりました。データアーキテクチャを単純化し、ストレージ効率とパフォーマンスを向上させます。このリリースにより、S3 Tables は V3 で導入されたすべてのデータ型をサポートします。
