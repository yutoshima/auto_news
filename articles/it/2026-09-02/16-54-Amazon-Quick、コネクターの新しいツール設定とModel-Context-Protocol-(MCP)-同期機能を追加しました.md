# Amazon Quick、コネクターの新しいツール設定とModel Context Protocol (MCP) 同期機能を追加しました

- **カテゴリ**: it
- **公開日時**: 2026年09月02日 16:54

## 概要

<p>Amazon Quickは、Outlook、Slack、Salesforce、Jira、独自のMCPサーバーなどのツールとサービスを、チャット、エージェント、アプリ、フロー、深いリサーチのワークフローに直接組み込むことを可能にします。現在、Amazon Quickは新しいツール設定とMCP同期サポートを導入し、管理者とコネクターの所有者がコネクターをどのように展開し、最新の状態を維持するかについて、より多くの制御を行えるようにします。</p>
<p>コネクターの所有者と管理者は、コネクター内の個別ツールを選択的に有効化または無効化できるようになりました</p>
