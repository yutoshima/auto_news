## 概要

<p>AWS Security Hubのネットワークスキャニング機能が、AWS GovCloud (US) で正式にサポートされるようになりました。</p>
<p>ネットワークスキャニングは、セキュリティグループのルールやルーティング テーブルに基づいて“到達可能”かもしれないのではなく、実際の到達可能性をインターネットからリソースへ検出します。公開IPアドレス、仮想マシン、ロードバランサーを AWS 環境全体で検出し、到達可能なポートを特定し、それらの背後で動作しているサービスを判断します。これは、Security Hub の既存のネットワーク到達性機能を補完します。</p>
