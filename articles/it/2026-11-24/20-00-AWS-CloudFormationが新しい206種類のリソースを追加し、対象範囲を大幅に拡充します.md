# AWS CloudFormationが新しい206種類のリソースを追加し、対象範囲を大幅に拡充します

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月24日 20:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/cloudformation-coverage-expansion/](https://aws.amazon.com/about-aws/whats-new/2026/11/cloudformation-coverage-expansion/)

## 概要

AWS CloudFormation は現在、88のサービスにわたる206種類の追加リソースタイプをサポートしています。これには Amazon SageMaker Hub、Amazon Bedrock AgentCore PolicyEngine、Amazon EC2 Snapshot などが含まれます。これにより CloudFormation のカバレッジの重要なギャップが埋まり、顧客が安全でスケーラブルなインフラ管理ワークフローを標準化できるようになります。ローンチは、リソースタイプの CloudFormation への取り込みコストを削減する新しいAI駆動の内部フレームワークを活用し、CloudFormation の継続的なカバレッジ拡張を可能にする設定を行いました。
