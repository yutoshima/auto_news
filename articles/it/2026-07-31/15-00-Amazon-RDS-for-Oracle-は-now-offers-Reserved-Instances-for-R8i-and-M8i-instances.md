# Amazon RDS for Oracle は now offers Reserved Instances for R8i and M8i instances の日本語訳は次の通りです：

Amazon RDS for Oracle は R8i および M8i インスタンス用のリザーブドインスタンスを提供します。

## 概要

<a href="https://aws.amazon.com/rds/oracle/">Amazon RDS for Oracle</a>は、R8iおよびM8iインスタンス向けに1年および3年のリザーブドインスタンスを提供開始しました。オンデマンド価格と比べて最大53％のコスト削減が可能です。これらのインスタンスは、AWSのみで提供されるカスタムIntel Xeon 6プロセッサを搭載し、同等のIntelプロセッサと比べてクラウドでの最高レベルのパフォーマンスと最速のメモリ帯域幅を実現します。R8iおよびM8iインスタンスは、価格性能比を最大15％改善し、メモリ帯域幅を2.5倍拡張します。
