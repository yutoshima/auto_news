# Amazon EventBridgeのカスタムイベントバスがWebhookイベントに対応しました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月20日 17:30
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-eventbridge-webhook-events](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-eventbridge-webhook-events)

## 概要

<p>Amazon EventBridge は拡張されたカスタムイベントバスのために Webhook イベントをサポートするようになりました。 SaaS アプリケーション、AI エージェント、カスタム統合は HTTPS 経由でイベントをバスへ送信できます。WebHook を受信し、それをバスへ公開するために自分の API エンドポイントや計算リソースを展開・運用する必要はなくなります。</p> 
<p>EventBridge のカスタムイベントバスはサーバーレスのイベントブローカーで、アプリケーション間、SaaS 統合間でイベントをルーティングすることにより、スケーラブルなイベント駆動型アプリケーションを作成できるようにします。
