# AWS Elastic Disaster Recovery は、AWS Graviton ベースのソースサーバをサポートします

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月25日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/09/elastic-disaster-recovery-graviton/](https://aws.amazon.com/about-aws/whats-new/2026/09/elastic-disaster-recovery-graviton/)

## 概要

<p>AWS Elastic Disaster Recovery（AWS DRS）は、AWS Gravitonベースの（arm64）ソースサーバーの災害復旧に対応しました。従来と同じ簡単で信頼できるDRS体験を、x86ワークロードと同様にGravitonワークロードにも適用して保護・復旧できます。</p>
<p>コスト性能の利点からGravitonへ workloads が移行するほど、環境の他の部分と同じ災害復旧カバレッジが求められます。DRSはarm64ソースサーバーを自動的に検出し、Gravitonへ復旧します。</p>
