## 概要

AWS Client VPN は、コマンドラインインターフェイス（CLI）をサポートし、エンタープライズ向け管理機能と接続確立をより高速化した再構築版の AWS VPN Client v6.0.x を提供します。これにより、VPN接続の自動化や組織全体のデバイス管理の集中化が容易になります。  

AWS VPN Client CLI は GUI と完全な機能互換を備えています。これにより、VPN接続を自動化ワークフローやインフラストラクチャ・コードのデプロイに組み込むことが可能です。
