# AWS Elastic Disaster Recoveryは、オーケストレーションされたアプリケーション復旧のためのリカバリプランを導入します。

## 概要

AWS Elastic Disaster Recovery（AWS DRS）は現在、リカバリ計画（Recovery Plans）を提供しています。これは、復旧時や演習時にマルチサーバー構成のアプリケーションを順次起動する作業を自動化する機能です。サーバーを1つずつ起動して依存関係を手作業で追跡する代わりに、リカバリの順序を一度定義すれば、必要なときには1つの操作で実行できます。これにより、データベース、アプリケーション層、補助サービスから構成され、起動順序が重要となるアプリケーションを運用する顧客が直面する共通の課題を解決します。
