# AWS Direct Connect、マンチェスター（イギリス）で100G拡張を発表

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月21日 17:21
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/aws-direct-connect-100g-manchester/](https://aws.amazon.com/about-aws/whats-new/2026/10/aws-direct-connect-100g-manchester/)

## 概要

今日は、英国マンチェスター近郊の Equinix MA3 データセンターにある既存の AWS Direct Connect 拠点において、MACsec 暗号化機能を備えた 10 Gbps および 100 Gbps の専用接続を拡張することを AWS が発表しました。これにより、すべてのパブリック AWS リージョン（中国を除く）、AWS GovCloud リージョン、そして AWS Local Zones へ、民間の直接的なネットワークアクセスを構築できるようになります。
