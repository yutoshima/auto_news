## 概要

<p>Amazon API Gateway は REST API 用のネイティブJWTオーソライザーを提供します。これは、ゲートウェイ内でJSON Web Tokenを直接検証する新しいオーソライザータイプです。これまでは、OpenID ConnectやOAuth 2.0のアイデンティティプロバイダー（Amazon Cognito以外）からのトークンを検証するにはLambdaオーソライザーが必要でした。今後は、コードを作成・運用する代わりにトークン検証を構成できます。</p> 
<p>発行者を1つ以上定義し、それぞれが受け付けるオーディエンス、許可する署名アルゴリズム、その他の追加設定を指定できます。</p>
