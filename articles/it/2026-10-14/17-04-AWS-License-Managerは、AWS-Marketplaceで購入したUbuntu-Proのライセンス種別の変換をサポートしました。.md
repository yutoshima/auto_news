# AWS License Managerは、AWS Marketplaceで購入したUbuntu Proのライセンス種別の変換をサポートしました。

- **カテゴリ**: it
- **公開日時**: 2026年10月14日 17:04
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/aws-license-manager-conversions-ubuntu-pro-marketplace/](https://aws.amazon.com/about-aws/whats-new/2026/10/aws-license-manager-conversions-ubuntu-pro-marketplace/)

## 概要

<p><a href="https://aws.amazon.com/license-manager/">AWS License Manager</a> は、EC2 Ubuntu LTS（Long Term Support）インスタンスを、AWS Marketplace で入手できる Ubuntu Pro へインプレースでアップグレードすることを現在サポートしています。これにより、フリートを再構築したり、ワークロードを新しいインスタンスや AMI に移行したりすることなく、セキュリティ体制を強化し、コンプライアンス要件を満たすことができます。Ubuntu Pro のサブスクリプションを利用すると、最大10年間のセキュリティパッチを受けることができ、15年まで延長可能です。
