# AWS Backupは、現在、他アカウントの管理と他アカウントへのバックアップを、AWSヨーロピアンソブリン・クラウドでサポートしています。

## メタデータ

- **カテゴリ**: it
- **公開日時**: 2026年10月29日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/aws-backup-cross-account-esc/](https://aws.amazon.com/about-aws/whats-new/2026/10/aws-backup-cross-account-esc/)

## 概要

<p>AWS Backup は現在、クロスアカウント管理、クロスアカウントバックアップ、および AWS European Sovereign Cloud (Germany) リージョンの委任管理者をサポートしています。これらの機能により、組織内のアカウント間でのバックアップの一元管理、監視、コピーを AWS Organizations を使用して実現できます。</p> 
<p>クロスアカウント管理を用いれば、AWS Organizations の管理アカウントまたは委任管理者アカウントから組織全体のバックアップポリシーを展開できます。バックアップの監視も行えます。</p>
