# Amazon S3テーブルは、AWSアカウントの各AWSリージョンあたり最大100個のテーブルバケットをサポートするようになりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月01日 04:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-s3-tables-table-bucket-increase](https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-s3-tables-table-bucket-increase)

## 概要

Amazon S3 Tablesは、AWSアカウントごとにAWSリージョンあたり最大100個のテーブルバケットをサポートするようになりました（以前は10個）。これにより、AWSリージョンごとに最大100万のテーブルを作成できます。より多くのテーブルバケットの割り当てにより、データセット、ワークロード、またはチームごとに別々のテーブルバケットを作成し、各バケットに対して暗号化、アクセスポリシー、レプリケーションといったテーブルバケットレベルの設定を適用できます。高い割り当ては追加コストなしでデフォルトで全アカウントに適用されます。
