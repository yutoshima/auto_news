# AWS Pricing Calculator は新しい API を通じてワークロードの費用を見積もる機能を提供します

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月20日 18:35
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/aws-pricing-calculator-api/](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-pricing-calculator-api/)

## 概要

AWS Pricing Calculatorは現在、GetUsageLinesEstimatedCostという新しいAPIを提供します。これは、計画中のワークロードの推定コストを1回のAPI呼び出しで返す機能です。1回のリクエストで最大500件の使用量行を送信し、推定値をアカウントへ保存することなく、すぐにコストが返されます。Pricing Calculatorでワークロードの推定値を作成・保存できるのに対し、GetUsageLinesEstimatedCostはニーズに応じて、直接自分のツールやワークフロー内でコストを取得します。
