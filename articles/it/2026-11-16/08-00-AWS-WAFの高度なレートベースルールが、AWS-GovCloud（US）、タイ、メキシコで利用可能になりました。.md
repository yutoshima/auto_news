# AWS WAFの高度なレートベースルールが、AWS GovCloud（US）、タイ、メキシコで利用可能になりました。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月16日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/waf-advanced-rate-rules-available/](https://aws.amazon.com/about-aws/whats-new/2026/11/waf-advanced-rate-rules-available/)

## 概要

AWS WAFの高度なレート制御ルールが、アジア太平洋地域（タイ）、メキシコ（中部）、AWS GovCloud（US-East）、AWS GovCloud（US-West）リージョンで利用可能になりました。これらのリージョンの顧客は、既存の5分および10分の評価ウィンドウに加え、カスタムキーを使用してリクエストを集計し、1分または2分の評価ウィンドウを選択できるようになりました。これは他のAWSリージョンですでに提供されている同じ機能です。

レート制御ルールはリクエストをカウントし、Blockや CAPTCHA などのアクションを適用します。
