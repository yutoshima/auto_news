# AWS Marketplaceは現在、みなし供給の払い戻しに対するVATクレジットノートをサポートしています

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月13日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/aws-marketplace-vat-credit-notes/](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-marketplace-vat-credit-notes/)

## 概要

AWSマーケットプレイスの出品者は、AWSパートナーセントラルのセルフサービス体験を通じて、還付済みのみなし供給取引に関するVAT（付加価値税）クレジットノートを提出できるようになりました。これまでは、対象取引に対してVATが出品者へ支払われ、購入者が後で返金された場合、出品者は対応するクレジットノートを提出するためにAWSへ連絡する必要がありました。このローンチにより、返金後のVAT文書作成が出品者にとって簡素化されます。
出品者は、VAT on deemed supplyセクションで、対象となる返金請求項目を確認できます。
