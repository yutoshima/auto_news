# AWSがクレジットの分割払いと移転を開始

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月17日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/aws-credit-splitting-transfers/](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-credit-splitting-transfers/)

## 概要

AWSは現在、クレジットの分割払いと転送をサポートしており、顧客がAWSクレジットを複数の小さなクレジットに分割し、ペイヤーアカウント内の他のリンク済みアカウントへ転送できるようになりました。以前は、AWSは所有アカウントを起点にクレジットを適用し、超過分を他のアカウントと共有して使用量に基づいて配分していたため、膨大なクレジットを持つ顧客が特定のチームや事業部門へ正確な金額を割り当てることが難しい状況でした。FinOpsチームは現在、ドル金額ごとにクレジットを分割して割り当てることができます。
