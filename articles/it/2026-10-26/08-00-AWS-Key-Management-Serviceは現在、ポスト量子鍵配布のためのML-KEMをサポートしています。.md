# AWS Key Management Serviceは現在、ポスト量子鍵配布のためのML-KEMをサポートしています。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月26日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/kms-ml-kem-post-quantum/](https://aws.amazon.com/about-aws/whats-new/2026/10/kms-ml-kem-post-quantum/)

## 概要

AWS Key Management Service（KMS）は現在、NIST FIPS 203に基づくポスト量子暗号標準であるモジュールラティスベースの鍵包絡機構（ML-KEM）をサポートしています。ML-KEMは、二者が共通の秘密を確立できるようにします。NISTは、DH/ECDHの鍵認証やRSAベースの鍵転送といった古典的な鍵確立方式を、戦略的暗号設計ロードマップで置換するためにML-KEMを設計しました（詳しくは以下を参照してください：https://csrc.nist.gov/）
