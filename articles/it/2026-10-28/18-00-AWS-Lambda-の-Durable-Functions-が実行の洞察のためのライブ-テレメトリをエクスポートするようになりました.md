# AWS Lambda の Durable Functions が実行の洞察のためのライブ テレメトリをエクスポートするようになりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月28日 18:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/lambda-durable-telemetry/](https://aws.amazon.com/about-aws/whats-new/2026/10/lambda-durable-telemetry/)

## 概要

AWS Lambdaは、Lambda耐久関数用のDurable Execution Telemetry Exporterプラグインを発表します。この新しい可観測性プラグインは、耐久実行のステップごとの履歴をキャプチャし、任意の1つまたは複数の宛先へ送信します。エクスポートされたデータを活用して運用・ビジネスの洞察を得るとともに、標準の保持期間を超えた履歴を保持することができます。また、AIエージェント（例：Kiro）などがあなたのエクスポートデータを照会できるModel Context Protocol（MCP）サーバーの companion も同時にリリースします。
