# Amazon RDS for Oracleは、追加のAWSリージョンでM8iおよびR8iインスタンスをサポートするようになりました。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月03日 00:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/rds-oracle-m8i-r8i-instances-new-regions/](https://aws.amazon.com/about-aws/whats-new/2026/11/rds-oracle-m8i-r8i-instances-new-regions/)

## 概要

<p><a href="https://aws.amazon.com/rds/oracle/">Amazon Relational Database Service (Amazon RDS) for Oracle</a>は、追加のAWSリージョンでM8iおよびR8iインスタンスをサポートします。M8iとR8iの両方のインスタンスは、現在Asia Pacific (New Zealand)およびCanada West (Calgary)で利用可能で、R8iインスタンスは Europe (Milan, Stockholm, Zurich)およびIsrael (Tel Aviv)でも利用可能です。</p>
<p>これらのインスタンスは、AWSのみで入手可能なカスタムIntel Xeon 6プロセッサを搭載しており、最高のパフォーマンスを提供します。</p>
