# AWS Backupは、論理的に空気ギャップされたボールトのサポートをAmazon Neptuneに拡張し、さらに3つのAWSリージョンを追加します

## メタデータ

- **カテゴリ**: it
- **公開日時**: 2026年08月06日 07:00

## 概要

AWS Backup の論理的にエアギャップされたボールトを使用した Amazon Neptune のサポートが、三つの追加の AWS リージョン（アジア太平洋地域＝メルボルン、ヨーロッパ地域＝スペイン、ヨーロッパ地域＝チューリッヒ）で利用可能になりました。

この拡張により、これらのリージョンの論理的にエアギャップされたボールトに Neptune のバックアップを保存できます。論理的にエアギャップされたボールトは不変で、デフォルトでロックされ、AWS が所有するキーまたは顧客管理キーを使用して暗号化されます。バックアップを別のアカウントやリージョンへコピーしたり、回復のためにボールトを共有したりすることができます。
