## 概要

AWSは、AWS Partner Central コンソールおよび AWS Partner Central Agents Model Context Protocol（MCP）サーバーへのアクセスを通じて利用できる AWS Partner Central ガイドを発表します。これらのガイドは、パートナーがビジネスの成長と拡大を支援するために AWS が整理したコンテンツを、検索・閲覧・共有するための1か所を AWS パートナーに提供します。ガイドには、プログラム、特典、テクニカルなどのパートナー固有の権威ある知識が含まれています。
