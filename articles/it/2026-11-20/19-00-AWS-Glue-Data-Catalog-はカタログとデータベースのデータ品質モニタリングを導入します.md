# AWS Glue Data Catalog はカタログとデータベースのデータ品質モニタリングを導入します

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月20日 19:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/glue-catalog-data-quality-monitoring/](https://aws.amazon.com/about-aws/whats-new/2026/11/glue-catalog-data-quality-monitoring/)

## 概要

AWS Glue Data Catalogは、AWS Glue Data Qualityを活用してカタログとデータベースのデータ品質モニタリングを提供します。単一の設定からカタログ規模でテーブルをプロファイリング・評価します。データ品質チェックをカタログ、データベース、または単一テーブルに対して一度定義すれば、AWS Glue Data Qualityが対象範囲のすべてのテーブル（後で追加されるテーブルも含む）を、選択した cadence（頻度）で評価します。データの変化に伴い品質問題が表面化し、個別のテーブル設定や手動実行を必要とせずに検出されるため、継続的な品質管理を支援します。
