# AWS Lambdaの耐久型関数がデフォルトの実行およびAPIクォータを増加させる

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月05日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/lambda-durable-functions-default-quotas/](https://aws.amazon.com/about-aws/whats-new/2026/11/lambda-durable-functions-default-quotas/)

## 概要

AWS Lambda の耐久関数は、実行数と API リクエストレートのデフォルト割り当てを引き上げました。以下の新しい割り当ては、US East (N. Virginia)、US West (Oregon)、Europe (Ireland) を除くすべての AWS リージョンで適用され、これらのリージョンではこの割り当ての2倍になります。

- アカウントあたりの耐久実行の実行数（100万→500万）
- 耐久実行を開始するための関数呼び出しレート（1秒あたり300→3,000 リクエスト）
- CheckpointDurableExecution および GetDurableExecutionState
