# Amazon ECS Managed Daemonsは、非クリティカルなデーモンをサポートするようになりました。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月03日 22:01
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/09/ecs-managed-daemons-non-critical/](https://aws.amazon.com/about-aws/whats-new/2026/09/ecs-managed-daemons-non-critical/)

## 概要

<p><a href="https://docs.aws.amazon.com/AmazonECS/latest/developerguide/Welcome.html">Amazon Elastic Container Service</a>（Amazon ECS）は現在、<a href="https://aws.amazon.com/ecs/managed-instances/">ECS Managed Instances</a>の非クリティカルなManaged Daemonをサポートしています。デーモンを非クリティカルとして構成することで、デーモンが失敗・停止・不健康になった場合でも、ミッション全体のクリティカルなアプリケーションタスクを途切れずに実行し続けることができます。</p> 
<p>Amazon ECS Managed Daemonsを使えば、デーモンを一元的にデプロイできます。
