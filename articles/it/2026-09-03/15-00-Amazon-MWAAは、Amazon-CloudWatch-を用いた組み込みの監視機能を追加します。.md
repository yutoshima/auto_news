# Amazon MWAAは、Amazon CloudWatch を用いた組み込みの監視機能を追加します。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月03日 15:00

## 概要

<p>Amazon Managed Workflows for Apache Airflow（MWAA）は、環境詳細ページに組み込みのモニタリング機能を追加しました。新しい指標ダッシュボードは、環境の主要な Amazon CloudWatch 指標を1つの場所で表示し、各グラフには推奨警告レンジを重ねて表示するオプションのトグルが用意されています。これにより、環境の健全性やパフォーマンスに影響を与える可能性のある状況を迅速に特定できます。</p>
