# Amazon ECS が LiveTaskCount を追加し、RunningTaskCount メトリックの料金を廃止します

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月13日 22:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/ecs-service-metrics/](https://aws.amazon.com/about-aws/whats-new/2026/10/ecs-service-metrics/)

## 概要

本日、Amazon Elastic Container Service（Amazon ECS）は「LiveTaskCount」を新たなサービス指標として発表します。これは、サービス内で現在アクティブに実行中のタスク数を報告し、すべての顧客が追加料金なしで利用できるものです。さらに、Amazon CloudWatch Container Insightsの既存のRunningTaskCount指標は、今後料金が発生しなくなります。

LiveTaskCountは、ACTIVATING、RUNNING、DEACTIVATINGのすべての希望状態を横断して、現在アクティブに実行中のECSタスク数を報告します。
