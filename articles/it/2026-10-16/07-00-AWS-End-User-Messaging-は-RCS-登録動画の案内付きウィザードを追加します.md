# AWS End User Messaging は RCS 登録動画の案内付きウィザードを追加します

- **カテゴリ**: it
- **公開日時**: 2026年10月16日 07:00

## 概要

今日は、AWS End User Messaging が、RCSエージェント登録のためのビデオキャプチャ全体を指揮するウィザードを追加します。米国を含む複数の国でのRCS登録には、メッセージ体験を示すスクリーン録画が必要です。録画するには、テストデバイスに特定の順序でメッセージを送る必要があり、これまでは自分でそのメッセージ列をスクリプト化していたため、エラーが起きやすく、ミスマッチまたは不完全なビデオを作成することがRCSで最も難しい部分の一つでした。
