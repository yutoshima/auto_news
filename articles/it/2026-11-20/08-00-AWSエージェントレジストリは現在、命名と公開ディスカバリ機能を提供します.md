# AWSエージェントレジストリは現在、命名と公開ディスカバリ機能を提供します

- **カテゴリ**: it
- **公開日時**: 2026年11月20日 08:00

## 概要

AWS Agent Registryは現在、公開命名機能を提供しており、エージェントやAIツールに検証済みのドメイン名を簡単に結びつけられます。開発者やネットワーク管理者はドメイン所有権を証明するためのドメイン検証を行い、検証済みドメイン名をエージェントと関連付けて、レジストリやAWSアカウントを超えた公開表示を促進できます。

以前は、開発者はエージェント同士の発見と接続の方法を手動で構成する必要があり、これが複雑さを追加していました。
