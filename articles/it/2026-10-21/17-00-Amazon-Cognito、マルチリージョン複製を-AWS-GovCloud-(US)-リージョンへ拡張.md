# Amazon Cognito、マルチリージョン複製を AWS GovCloud (US) リージョンへ拡張

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月21日 17:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/cognito-multi-region-us-govcloud/](https://aws.amazon.com/about-aws/whats-new/2026/10/cognito-multi-region-us-govcloud/)

## 概要

<p>Amazon Cognito のマルチリージョンレプリケーション（MRR）が AWS GovCloud（US） Regions をサポート開始。MRR の耐障害性をより多くのワークロードへ拡張します。MRR は、資格情報、ユーザプールの設定、連携設定を含むユーザーおよび機械識別データを、あなたが指定する待機リージョンの二次ユーザプールへほぼリアルタイムで同期します。待機リージョンにユーザーデータを保持しておくことで、プライマリリージョンに障害が発生した場合でもトラフィックをリダイレクトし、認証を継続させることが可能です。</p>
