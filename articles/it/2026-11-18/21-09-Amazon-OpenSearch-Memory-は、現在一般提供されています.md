# Amazon OpenSearch Memory は、現在一般提供されています

## 概要

今日は、AIエージェントにパーシステントメモリを追加するためのAmazon OpenSearch Serviceの新しいサーバーレス機能「Amazon OpenSearch Memory」が一般提供開始されたことを発表しました。OpenSearch Memoryは、エージェントのやり取りを検索可能なイベントとして保存し、有用なメモリを導出、セッションを跨いだ関連コンテキストを取得します。これにより、エージェントは以前の意思決定や過去のやり取り、ユーザーの好みを、モデルに全会話履歴を再生させることなく思い出すことができます。顧客はエージェントに長期のメモを提供することができます。
