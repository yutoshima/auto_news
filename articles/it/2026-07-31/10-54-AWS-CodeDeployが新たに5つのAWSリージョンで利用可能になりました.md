# AWS CodeDeployが新たに5つのAWSリージョンで利用可能になりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年07月31日 10:54
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/07/aws-codedeploy-five-additional-regions](https://aws.amazon.com/about-aws/whats-new/2026/07/aws-codedeploy-five-additional-regions)

## 概要

AWS CodeDeployは、以下の5つの追加AWSリージョンで利用可能になりました: アジア太平洋（ニュージーランド）、アジア太平洋（タイ）、アジア太平洋（台北）、アジア太平洋（マレーシア）、およびメキシコ（中部）。AWS CodeDeployは完全に管理されたデプロイメントサービスで、アプリケーションのデプロイをAmazon EC2インスタンス、オンプレミスのサーバー、AWS Lambda関数、およびAmazon ECSサービスへ自動化します。これら新規追加リージョンの顧客はCodeDeployを現地で利用できるようになり、待機遅延の低下とデータ居住性のサポートが期待されます。
