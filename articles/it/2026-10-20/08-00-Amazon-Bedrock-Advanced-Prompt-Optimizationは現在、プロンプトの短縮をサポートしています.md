# Amazon Bedrock Advanced Prompt Optimizationは現在、プロンプトの短縮をサポートしています

## 概要

<p>Amazon Bedrock Advanced Prompt Optimizationは現在、プロンプト短縮をサポートしています。これは、評価スコアを維持または向上させつつ、プロンプトの長さを短くするオプション設定です。Advanced Prompt Optimizationは、Amazon Bedrock上のいかなるモデルに対しても、独自の評価基準に基づいてプロンプトを最適化します。これまでは、最適化は品質のみに焦点を当てていました。最適化されたプロンプトは元のものより長くなることが多く、長いプロンプトは入力トークンのコストを押し上げ、最初のトークンまでの時間を増加させる可能性があります。</p>
