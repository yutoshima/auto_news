# 移行のための AWS Transform が既存のランディングゾーンを拡張サポート

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月20日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/aws-transform-migrations-landing-zones/](https://aws.amazon.com/about-aws/whats-new/2026/10/aws-transform-migrations-landing-zones/)

## 概要

AWS Transformは、移行のためのランディングゾーンを構築する際に、既存のAWS環境のより多くのタイプをサポートするようになりました。これにはAWS Control TowerのランディングゾーンやAWS Organizationsを使用して構築されたランディングゾーンが含まれます。AWS Transformは現在の環境をAWSのベストプラクティスと照らして基盤ギャップ分析を行い、ターゲットアカウントに既にあるものの上にランディングゾーンを拡張するため、チームはより早く移行を開始できます。

AWS Transformは、インフラストラクチャをコードとして管理する（IaC）にも対応しています。
