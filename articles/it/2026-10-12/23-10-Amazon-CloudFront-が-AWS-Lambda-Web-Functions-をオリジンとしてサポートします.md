# Amazon CloudFront が AWS Lambda Web Functions をオリジンとしてサポートします

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月12日 23:10
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/cloudfront-lambda-web-functions-origin/](https://aws.amazon.com/about-aws/whats-new/2026/10/cloudfront-lambda-web-functions-origin/)

## 概要

本日より、AWS Lambda Web Functions 上で構築されたウェブアプリケーションを CloudFront のグローバルエッジネットワーク経由で配信できます。 CloudFront を Lambda Web Function の前に置くことで、エッジでの TLS 終端による低遅延・高速な接続、キャッシュによるパフォーマンス向上、マネージド TLS 証明書を用いたカスタムドメインが利用可能になります。アプリケーションコードの変更は不要です。CloudFront Origin Access Control（OAC）は、Lambda Web Function へのアクセスを CloudFront 経由のみに制限します。
