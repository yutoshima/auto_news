# Amazon EC2 G7インスタンスが、AWS Europe（スペイン）リージョンで利用可能になりました。

## 概要

<p>NVIDIA RTX PRO 4500 Blackwell Server Edition GPU を搭載した Amazon Elastic Compute Cloud（Amazon EC2） G7 インスタンスが、ヨーロッパリージョン（スペイン）で利用可能になりました。G7 インスタンスは、G6 インスタンスと比較して AI 推論パフォーマンスを最大 4.6 倍、グラフィックスパフォーマンスを最大 2.1 倍を実現します。G7 インスタンスは、GPU 拡張データ分析ワークロードのパフォーマンスも向上させます。</p> 
<p>お客様は、言語翻訳、映像・画像分析、音声認識モデルのデプロイに G7 インスタンスを利用できます</p>
