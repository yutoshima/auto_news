# Amazon S3 サーバーアクセスログの CloudWatch Logs への配信が、5つの追加 AWS リージョンで利用可能になりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月21日 13:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-s3-server-access-logs-cloudwatch-logs-regions/](https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-s3-server-access-logs-cloudwatch-logs-regions/)

## 概要

<p>Amazon S3のサーバーアクセスログのCloudWatch Logsへの配信が、AWS GovCloud (US) Regions、AWS European Sovereign Cloud、およびAWS China Regionsで利用可能になりました。CloudWatch Logsにアクセスログを格納することで、到着時点での照会、アラームの設定、AWS Key Management Service（AWS KMS）キーによる暗号化が可能になります。この新しい配信経路は、従来のS3の汎用バケットへのサーバーアクセスログ配信を補完し、アクセスの監視と分析における柔軟性を高めます。
