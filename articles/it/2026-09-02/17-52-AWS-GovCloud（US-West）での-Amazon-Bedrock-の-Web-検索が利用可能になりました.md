# AWS GovCloud（US-West）での Amazon Bedrock の Web 検索が利用可能になりました

## 概要

Amazon Bedrock の Web Search ビルトインのサーバーサイドツールが、AWS GovCloud (US-West) で利用可能になりました。法令遵守が求められる政府・公共部門のワークロードに、信頼性のあるウェブ結果を提供します。Web Search は、対応する OpenAI GPT モデルの回答をウェブ情報で根拠づけます。回答には、モデルが使用した情報源の出典が引用として含まれ、各主張をウェブの出典に遡って確認できるようになっています。特に、回答が変化する情報に依存する場合に、これは有用となることがあります。
