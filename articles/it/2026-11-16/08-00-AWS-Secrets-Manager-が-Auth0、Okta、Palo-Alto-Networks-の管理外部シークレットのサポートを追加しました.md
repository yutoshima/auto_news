# AWS Secrets Manager が Auth0、Okta、Palo Alto Networks の管理外部シークレットのサポートを追加しました

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月16日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/secrets-manager-managed-external-secrets-auth0-okta-palo-alto/](https://aws.amazon.com/about-aws/whats-new/2026/11/secrets-manager-managed-external-secrets-auth0-okta-palo-alto/)

## 概要

AWS Secrets Manager は現在、Auth0・Okta・Palo Alto Networks のマネージド外部機密に対応しています。回転されない長寿命の認証情報は、流出した場合に不正アクセスのリスクを高めます。サードパーティ認証情報をローテーションするには、外部サービスとそれを使用するすべてのアプリケーションへの協調した更新が必要です。回転スケジュールは AWS マネジメントコンソールまたは API から設定します。Secrets Manager は認証情報を回転させ、現在の値をカスタム回転 Lambda 関数なしで格納します。
