## 概要

本日より、顧客は AWS CLI、AWS SDK、CloudFormation、CDK、または PricingPlanManager API を使用して、定額料金プランをプログラム的に購読・管理できます。

CloudFront の定額プランは、グローバルなコンテンツ配信、WAF、DDoS、DNS、ログ記録、エッジコンピュートを含む月額1つの価格を提供し、トラフィックの急増や攻撃に関係なく従量課金の超過料金が発生しません。従来、定額料金プランに購読するにはコンソール経由のみで、手作業が必要でした。
