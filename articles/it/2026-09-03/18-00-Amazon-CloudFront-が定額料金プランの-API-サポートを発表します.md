# Amazon CloudFront が定額料金プランの API サポートを発表します

## 概要

本日より、顧客は AWS CLI、AWS SDK、CloudFormation、CDK、または PricingPlanManager API を使用して、定額料金プランをプログラムで購読・管理できるようになります。

CloudFront の定額料金プランは、月額価格1つでグローバルなコンテンツ配信、WAF、DDoS、DNS、ログ記録、エッジ計算をカバーし、トラフィックの急増や攻撃があっても従量課金の追加料金が発生しないという点が特徴です。これまで顧客はコンソールを使用して定額料金プランに購読することしかできず、手作業が必要でした。
