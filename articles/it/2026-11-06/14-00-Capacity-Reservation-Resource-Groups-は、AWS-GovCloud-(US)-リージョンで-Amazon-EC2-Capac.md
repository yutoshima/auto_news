# Capacity Reservation Resource Groups は、AWS GovCloud (US) リージョンで Amazon EC2 Capacity Blocks および中断可能な Capacity Reservations をサポートしました。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月06日 14:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/capacity-reservation-resource-groups-support-in-aws-govcloud-regions](https://aws.amazon.com/about-aws/whats-new/2026/11/capacity-reservation-resource-groups-support-in-aws-govcloud-regions)

## 概要

本日から、ML用の容量ブロックおよび中断可能な容量予約を、AWS GovCloud (US) リージョンの容量予約リソースグループに追加できます。Amazon EC2 には、On-Demand Capacity Reservations（ODCRs）、中断可能な容量予約、ML用の容量ブロックなど、さまざまな予約オファリングがあります。これまで、容量予約リソースグループには ODCR のみを含めることができました。現在は、任意の種別の容量予約を容量予約リソースグループに追加できます。
