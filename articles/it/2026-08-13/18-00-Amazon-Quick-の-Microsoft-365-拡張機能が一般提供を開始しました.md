# Amazon Quick の Microsoft 365 拡張機能が一般提供を開始しました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月13日 18:00
- **URL**: [https://aws.amazon.com/amazon-quick-microsoft-365-extensions-generally-available](https://aws.amazon.com/amazon-quick-microsoft-365-extensions-generally-available)

## 概要

本日、Amazon Quickは、Excel・PowerPoint・Word・Outlook向けの Microsoft 365 拡張機能を正式提供開始します。これらの拡張機能により、Quick はユーザーの M365 環境内で直接作業を行い、AI を用いて文書の赤線引き、財務モデルの作成、プレゼンテーション用デッキの作成、Outlook の受信トレイ管理といった複雑なローカル作業を処理します。

Excel 拡張機能は、複雑なスプレッドシート分析、ピボットテーブルとチャートの作成、インポート作業などを支援します。
