# AWS Clean RoomsがDatabricksをデータソースとしてサポートするようになりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月20日 12:23
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/aws-clean-rooms-supports-databricks](https://aws.amazon.com/about-aws/whats-new/2026/10/aws-clean-rooms-supports-databricks)

## 概要

AWS Clean Roomsは現在、Databricksをデータソースとしてサポートしています。これにより、コラボレーションのメンバーとパートナーは、ソースデータを移動させたり開示したりすることなく、Databricksで管理されているデータを安全に分析できます。メンバーはDelta Sharingを通じて共有されたDatabricksテーブルを、コラボレーション内で直接クエリします。Databricksは、AWS Glue、Snowflake、Amazon Athenaと同様に、AWS Clean Roomsでサポートされるデータソースとして統合されています。
