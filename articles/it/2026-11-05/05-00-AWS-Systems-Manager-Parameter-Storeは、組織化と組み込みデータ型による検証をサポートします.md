# AWS Systems Manager Parameter Storeは、組織化と組み込みデータ型による検証をサポートします

## 概要

AWS Systems Manager Parameter Store は、パラメータを作成または更新する際に自動的に値を検証する13種類の新しいパラメータデータタイプをサポートするようになりました。組み込みの検証機能により、アプリケーションが読み取る前に、無効なIPアドレス、AWSアカウントID、JSONドキュメントなどの不正な設定値を止めることができ、独自の検証ロジックを記述する必要がありません。これらのデータタイプは、ワークロード全体でパラメータをより適切に整理するのに役立ちます。呼び出す際にタイプでフィルターすることができます。
