# Amazon CloudFrontがオリジンへの接続にHTTP/2をサポート開始を発表

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月23日 17:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/01/amazon-cloudfront-http2-origins/](https://aws.amazon.com/about-aws/whats-new/2026/01/amazon-cloudfront-http2-origins/)

## 概要

<p>Amazon CloudFront は現在、カスタムオリジンと VPC オリジンへの HTTP/2 接続に対応しています。HTTP/2 を使うと、CloudFront がオリジンへより少ない接続で多くのリクエストを送信できます。つまり、オリジンが処理する接続数と TLS ハンドシェイクが減少し、API やエージェント系ワークロード（AI エージェントが MCP サーバーを呼び出す場合や、モバイル・ウェブアプリがバックエンド API を呼び出す場合など）のパフォーマンスが向上します。</p>
<p>これまで CloudFront はオリジンへ HTTP/1.1 でのみ接続しており、接続ごとに1リクエストを処理していました。
