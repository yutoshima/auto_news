# Amazon Redshiftは現在、Apache Iceberg v3 テーブルをサポートしています。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月31日 18:10

## 概要

<p>Amazon Redshiftは現在、データレイク内の Apache Iceberg v3 テーブルの読み取りおよび書き込みをサポートしています。Apache Icebergはオープンなテーブル形式であり、そのv3リリースにはいくつかの新機能が追加されています。今回の発表により、Amazon Redshiftはデフォルトカラム値、行系、削除ベクターのサポートを導入します。<br /> デフォルトカラム値を使用すると、値が提供されない場合にAmazon Redshiftが適用する初期値を定義でき、既存のテーブルに列を追加する際のスキーマ進化を簡素化します。
