# AWS DevOpsエージェントが新しいチャット機能を追加します

## 概要

AWS DevOps Agentは、KiroやClaude CodeなどのMCPクライアントだけでなく、SlackやMicrosoft Teamsのチャンネルにもチャット機能を拡張しました。Model Context Protocol（MCP）をサポートすることで、GitHub、GitLab、Azure DevOps、ServiceNow、PagerDutyのMCPツールを含む指示型チャットアクションをAWS DevOps Agentが実行できるようになり、開発者と運用チームは好みのチャットインターフェースから直接、強力なワークフロー自動化を利用できます。  
このリリースでは、インシデントごとの自動作成機能も追加されます。
