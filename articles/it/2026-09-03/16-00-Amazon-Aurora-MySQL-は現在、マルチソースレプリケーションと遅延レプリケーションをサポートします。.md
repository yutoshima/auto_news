# Amazon Aurora MySQL は現在、マルチソースレプリケーションと遅延レプリケーションをサポートします。

## 概要

<p>本日より、Amazon Aurora MySQL は2つの新しいレプリケーション機能をサポートします：マルチソースレプリケーションと遅延レプリケーションです。マルチソースレプリケーションでは、1つのAurora MySQLクラスターが複数のソースデータベースから同時にレプリケートできるようになり、別々のMySQLデータベースのデータを統合する作業が容易になります。こうした機能は、シャーディングの統合や、地域別または部門別のデータベースなど、別々のデータベースからのデータを中央の場所へ集約して運用するなど、重要なユースケースを実現します。
