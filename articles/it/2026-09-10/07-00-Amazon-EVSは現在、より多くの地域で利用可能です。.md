# Amazon EVSは現在、より多くの地域で利用可能です。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月10日 07:00

## 概要

本日、Amazon Elastic VMware Service（Amazon EVS）が Asia Pacific（大阪）、Asia Pacific（台北）、Europe（スペイン）、および Israel（テルアビブ）リージョンで利用可能になったことを発表します。この拡張により、クラウド上で VMware ワークロードを実行するための AWS の規模と柔軟性を活用する選択肢がさらに広がります。Amazon EVS を利用すると、AWS Ni によって強化された EC2 ベアメタル・インスタンス上の Amazon Virtual Private Cloud（VPC）内で、VMware Cloud Foundation（VCF）を直接実行できます。
