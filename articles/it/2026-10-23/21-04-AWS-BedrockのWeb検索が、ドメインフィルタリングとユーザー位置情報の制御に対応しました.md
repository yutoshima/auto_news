# AWS BedrockのWeb検索が、ドメインフィルタリングとユーザー位置情報の制御に対応しました

- **カテゴリ**: it
- **公開日時**: 2026年10月23日 21:04
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/bedrock-web-search-domain-user-location/](https://aws.amazon.com/about-aws/whats-new/2026/10/bedrock-web-search-domain-user-location/)

## 概要

<p>AWS Bedrock の Web Search は現在、モデルの応答を基づく結果をより厳密に絞り込むための新しい2つのコントロール、ドメインフィルタリングとユーザーの位置情報をサポートします。いずれも、既存の OpenAI Responses API リクエストの web_search ツール directly に設定します。</p>
<p>ドメインフィルタリングを使用すると、Web Search の結果を自分で指定したドメインの集合に制限できます。filters パラメータを使用して、最大 100 の allowed_domains を指定し、結果を信頼できるソースに絞り込むか、または最大 100 の blocked_domains を指定してブロックします。</p>
