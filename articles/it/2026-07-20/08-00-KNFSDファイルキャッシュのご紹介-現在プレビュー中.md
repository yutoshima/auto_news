## 概要

本日、AWS は KNFSD File Cache の利用可能性を発表します。これはオープンソース（Apache-2.0ライセンス）で、AWS上にスケーラブルで高速なネットワークファイルシステム（NFS）キャッシュを展開するソリューションです。KNFSD File Cache は、1つまたは複数のソースNFSサーバーのエクスポートをマウントします。オンプレミス、別のAWSアベイラビリティゾーンやリージョン、あるいは AWS Interconnect を介した別のクラウドなど、マルチクラウド環境であっても再エクスポートしてAWS内のNFSクライアントに提供します。複数のオンプレミスのファイルサーバーや、Amazon FSx などのクラウド内ファイルシステムを前面に配置することも可能です。
