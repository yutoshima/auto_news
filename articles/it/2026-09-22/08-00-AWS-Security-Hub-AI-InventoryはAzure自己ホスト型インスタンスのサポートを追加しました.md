# AWS Security Hub AI InventoryはAzure自己ホスト型インスタンスのサポートを追加しました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月22日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/09/security-hub-ai-inventory-azure-support/](https://aws.amazon.com/about-aws/whats-new/2026/09/security-hub-ai-inventory-azure-support/)

## 概要

<p>AWS Security Hub AI Inventoryは、Microsoft Azure上のセルフホスト型インスタンスで実行されているAI資産の発見とカタログ化をサポートするようになりました。 この拡張により、Security Hubの既存のセルフホスト型ディスカバリ機能がAWSを超えて広がり、セキュリティ運用チームがマルチクラウド環境全体でAI資産とそのセキュリティ状況を継続的に更新される組織全体のビューとして把握できるようになります。</p>
<p>Security Hubは、Amazon InspectorのSBOM（ソフトウェア部品表）分析を活用します。
