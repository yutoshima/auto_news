# Amazon ElastiCache Global Datastore は、タグ付けとタグベースのアクセス制御に対応しました。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月24日 07:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-elasticache-global-datastore-tagging/](https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-elasticache-global-datastore-tagging/)

## 概要

<p>Amazon ElastiCacheは現在、グローバルDatastoreのリソースタグ付けとタグベースのアクセス制御（TBAC）をサポートしています。以前はElastiCacheはグローバルDatastoreを除くすべてのリソースにタグ付けをサポートしており、ElastiCacheのフリート全体で単一で一貫した権限とコスト配分モデルを適用することを妨げていました。</p>
<p>このローンチにより、Global Datastoreに対してAddTagsToResource、RemoveTagsFromResource、ListTagsForResourceを使用でき、それらのタグをIAMポリシの条件として参照することができます。</p>
