# Amazon ECSは現在、Amazon EC2 G6fインスタンスで分数GPUスケジューリングをサポートしています

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月06日 22:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-ecs-fractional-gpu/](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-ecs-fractional-gpu/)

## 概要

Amazon Elastic Container Service（Amazon ECS）は現在、Amazon EC2 G6fインスタンスと組み合わせた分割GPUのスケジューリングをサポートしており、NVIDIA L4 Tensor Core GPUのGPUメモリ3GBを1/8単位のパーティションとして、GPUを最小単位で実行できるようになりました。分割GPUにより、少量のモデルAI推論、モデル実験、グラフィックスレンダリング、ほかのフルGPUを必要としないワークロードのコンテナを適切な規模に合わせて配置する柔軟性が得られます。
