# Amazon VPC IPAM は、BGP ルート保護モニタリングと BYOIP プレフィックスの委任 RPKI をサポートします。

## 概要

<p>Amazon Virtual Private Cloud (VPC) IP Address Manager (IPAM) は、BYOIP（Bring Your Own IP）プレフィックスのための BGP ルート保護監視と委任されたリソースPKI（RPKI）管理を新たにサポートします。ネットワーク管理者は、 BGP ルート保護を集中監視し、組織全体で ROA（Route Origin Authorization）管理を自動化できます。</p>
<p>BGP ルート監視を使用すると、すべての BYOIP プレフィックスの RPKI 有効性ステータス、ROA の強さ、およびルートの重複検出を確認できます。</p>
