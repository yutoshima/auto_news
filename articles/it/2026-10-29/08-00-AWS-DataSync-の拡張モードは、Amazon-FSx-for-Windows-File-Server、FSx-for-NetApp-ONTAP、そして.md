# AWS DataSync の拡張モードは、Amazon FSx for Windows File Server、FSx for NetApp ONTAP、そして Red Hat OpenShift Virtualization をサポートするようになりました。

## 概要

以下が自然な日本語訳です。

AWS DataSync Enhanced モードは、Amazon FSx for Windows File Server および Amazon FSx for NetApp ONTAP をソースまたはデスティネーションの場所としてサポートしました。これにより、オンプレミスのファイルサーバーから FSx for Windows File Server へなど、Windows から Windows への転送を実行できるようになりました。さらに、Enhanced モードのエージェントは Red Hat OpenShift Virtualization バージョン 4.20 以降で実行可能です。

このリリースにより、Enhanced モードと Basic モードで同じ場所オプションを使用できるようになります。Enhanced モードはデータを処理します。
