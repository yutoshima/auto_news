# AWSのアプリケーション＆ネットワークロードバランサは、RFC 9151準拠のセキュリティポリシーをサポートするようになりました。

## メタデータ

- **カテゴリ**: it
- **公開日時**: 2026年08月04日 18:28
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/aws-application-network/](https://aws.amazon.com/about-aws/whats-new/2026/08/aws-application-network/)

## 概要

AWS Application Load Balancer（ALB）および Network Load Balancer（NLB）は、RFC 9151 TLS サーバ要件に準拠した CNSA 1.0 スイート要件を満たす新しい TLS ベースのセキュリティポリシーをサポートするようになりました。これらのポリシーは、TLS 1.2 および TLS 1.3 プロトコルを使用した安全な通信のための米国国家安全保障局（NSA）によって定義された暗号要件を実装しています。CNSA 1.0 TLS セキュリティ要件を満たす必要がある顧客は、今後これらを利用できます。
