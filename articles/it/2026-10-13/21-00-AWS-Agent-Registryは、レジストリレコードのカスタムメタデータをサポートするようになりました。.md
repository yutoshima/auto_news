# AWS Agent Registryは、レジストリレコードのカスタムメタデータをサポートするようになりました。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月13日 21:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/aws-agent-registry-custom-metadata-registry-records](https://aws.amazon.com/about-aws/whats-new/2026/10/aws-agent-registry-custom-metadata-registry-records)

## 概要

AWS Agent Registryは、組織内のエージェント、MCPサーバー、エージェントスキル、ゲートウェイ、カスタムリソースを一元化・統治するカタログです。組織が数百のリソースへと拡大していくと、名前と説明だけでは効果的なガバナンスと発見には不十分です。カスタムメタデータを使えば、組織独自の構造化フィールドをすべてのリストレコードに拡張できるため、個人と自動化システムの双方が一貫してリソースを見つけ、管理できるようになります。
