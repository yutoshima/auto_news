# AWS Backup が Amazon EBS Snapshots Archive の論理的なエアギャップ付きボールトを追加します

## 概要

AWS Backup の論理的に空間を隔離したボールトが、Amazon EBS Snapshots Archive をサポートしました。論理的に空間を隔離したボールトは、アカウント間および AWS Organizations 間でバックアップを安全に共有でき、データ損失時の回復時間を短縮するために直接リストアをサポートする、AWS Backup の一種です。

これにより、論理的に空間を隔離したボールトに保持される Amazon EBS バックアップを、ほとんどアクセスしないスナップショットの低コスト階層である Amazon EBS Snapshots Archive にアーカイブできるようになりました。論理的に空間を隔離したボールトには、読み取り専用の保護を与えるためのアイデッドリフトといった機能が含まれています。
