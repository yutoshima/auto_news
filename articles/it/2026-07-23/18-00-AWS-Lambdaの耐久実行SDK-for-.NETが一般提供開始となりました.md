# AWS Lambdaの耐久実行SDK for .NETが一般提供開始となりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年07月23日 18:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/07/lambdadf-dotnet/](https://aws.amazon.com/about-aws/whats-new/2026/07/lambdadf-dotnet/)

## 概要

本日、AWSは .NET 用 AWS Lambda Durable Execution SDK の一般提供を発表します。これにより C# 開発者は Lambda の耐久関数を用いて、堅牢で長時間実行されるワークフローを構築できます。この SDK を使えば、決済処理パイプライン、AI エージェントのオーケストレーション、ヒトの介入を伴う承認プロセスなど、アプリケーション内で直接複数ステップのアプリケーションを作成でき、進行状況の追跡を独自に実装したり外部オーケストレーションサービスを統合したりする必要がなくなります。
