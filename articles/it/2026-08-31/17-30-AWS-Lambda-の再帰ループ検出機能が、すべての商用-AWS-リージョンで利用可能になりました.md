# AWS Lambda の再帰ループ検出機能が、すべての商用 AWS リージョンで利用可能になりました

## 概要

AWS Lambda の再帰ループ検知機能が、すべての商用 AWS リージョンでの使用を拡張しました。この機能はデフォルトで有効になっており、Lambda 関数と他のサポート対象サービス間の再帰呼び出しを自動的に検知して停止させ、暴走するワークロードを防ぐガードレールです。

S3、SQS、SNS などのイベントソースを使用して Lambda 関数をトリガーする場合、設定ミスが起こることがあります。
