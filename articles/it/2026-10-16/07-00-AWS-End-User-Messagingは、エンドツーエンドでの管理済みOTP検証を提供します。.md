# AWS End User Messagingは、エンドツーエンドでの管理済みOTP検証を提供します。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月16日 07:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/aws-end-user-messaging-adds-end-to-end-managed-OTP](https://aws.amazon.com/about-aws/whats-new/2026/10/aws-end-user-messaging-adds-end-to-end-managed-OTP)

## 概要

今日は、AWS End User Messaging が Notify におけるエンドツーエンドの管理付きワンタイムパスコード（OTP）検証を発表します。電話番号の取得やキャリアへの登録、メッセージ配信方法の管理を行うことなく、電話番号とコード検証を含む動作するOTPソリューションを5分未満で利用できます。以前は自分でパスコードを生成してNotifyに送信を依頼し、コードの作成・保管・有効期限の管理ロジックを自分で構築・維持していました。今ではNotifyがコードを生成します。
