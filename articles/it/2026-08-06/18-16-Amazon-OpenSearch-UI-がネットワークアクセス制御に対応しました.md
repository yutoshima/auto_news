# Amazon OpenSearch UI がネットワークアクセス制御に対応しました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月06日 18:16
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/opensearch-ui-network-access-control](https://aws.amazon.com/about-aws/whats-new/2026/08/opensearch-ui-network-access-control)

## 概要

<p>Amazon OpenSearch Service は現在、OpenSearch UI アプリケーション向けのネットワークアクセス制御をサポートしています。OpenSearch UI は、複数の AWS データソースにわたる検索、分析、および統合的な可観測性のための完全 managed ウェブサービスです。ネットワークアクセス制御を使用すると、すでに AWS の他の場所で使用しているのと同じ IAM 条件キー（aws:SourceVpce、aws:SourceVpc、aws:SourceIp）を用いて、承認済みネットワークに対して OpenSearch UI アプリケーションへのアクセスを制限し、データの一貫性を確保するのに役立ちます。
