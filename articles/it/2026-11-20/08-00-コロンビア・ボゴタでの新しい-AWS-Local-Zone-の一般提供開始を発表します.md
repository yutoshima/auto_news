# コロンビア・ボゴタでの新しい AWS Local Zone の一般提供開始を発表します

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月20日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/aws-local-zone-bogota-colombia/](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-local-zone-bogota-colombia/)

## 概要

本日、AWSはコロンビアのボゴタに新しいローカルゾーンの一般提供を開始し、エンドユーザーに近い場所へAWSインフラを展開して、ミリ秒単位の低遅延を要求するアプリケーションをサポートします。ボゴタのローカルゾーンは、リアルタイムのゲーム、ライブ動画ストリーミング、医用画像処理、金融取引処理などのワークロードに利用できます。

AWS Local Zonesは、計算、ストレージ、ネットワーキング、その他選択されたAWSサービスを大都市圏の近くに配置するインフラストラクチャ展開です。
