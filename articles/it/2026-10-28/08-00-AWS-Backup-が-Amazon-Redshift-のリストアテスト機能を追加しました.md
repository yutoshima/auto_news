# AWS Backup が Amazon Redshift のリストアテスト機能を追加しました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月28日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/aws-backup-adds-redshift-restore-testing/](https://aws.amazon.com/about-aws/whats-new/2026/10/aws-backup-adds-redshift-restore-testing/)

## 概要

<p>AWS Backupのリストアテストは現在Amazon Redshiftをサポートしています。リストアテストはバックアップのリストアテストを自動化し定期的に実行できるようにするもので、Amazon Redshiftのバックアップが正常にリストアされることを確認し、リストアに要する時間を測定できます。</p>
<p>これで他のAWSリソース（ストレージ、コンピュート、データベースサービス）と同様に、リストアテスト計画にAmazon Redshiftを含めることができます。リストアテスト計画は回復ポイントを自動的に選択し、リストアを実行します。</p>
