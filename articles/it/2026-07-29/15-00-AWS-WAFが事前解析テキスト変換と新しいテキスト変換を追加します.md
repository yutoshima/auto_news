# AWS WAFが事前解析テキスト変換と新しいテキスト変換を追加します

## 概要

本日、AWS WAF はクエリ引数用の前処理テキスト変換と、任意のルールステートメントで使用できる新たな10件のテキスト変換を追加しました。どちらも、リクエストの内容をアプリケーションが解釈する方法と同じように AWS WAF が検査できるよう、リクエスト内容を正規化するのに役立ちます。

前処理テキスト変換は、AWS WAF がクエリ文字列をキーと値のペアへ解析する前に生のクエリ文字列を正規化し、HTTP パラメータ汚染やパーサ差異回避のギャップを埋めます。この変換は最大10件まで連結でき、URL などを含みます。
