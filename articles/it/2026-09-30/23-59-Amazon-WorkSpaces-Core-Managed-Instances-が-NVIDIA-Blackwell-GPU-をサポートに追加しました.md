## 概要

<p>Amazon WorkSpaces Core Managed Instances は、NVIDIA RTX PRO 4500 Blackwell Server Edition GPU と Intel Xeon 6 プロセッサを搭載した Graphics G7 インスタンスをサポートしました。G7 インスタンスは、前世代の G6 インスタンスと比較して、グラフィックス集約型ワークロードで最大 2.1 倍のパフォーマンスを発揮します。</p>
<p>Graphics G7 を利用することで、CAD/CAM、3D レンダリング、科学的可視化、ビデオ編集、AI アシスト設計ワークフローなど、より高い忠実度で demanding なプロフェッショナルアプリケーションを実行できます。</p>
