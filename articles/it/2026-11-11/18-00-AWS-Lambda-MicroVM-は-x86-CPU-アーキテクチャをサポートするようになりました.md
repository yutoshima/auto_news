# AWS Lambda MicroVM は x86 CPU アーキテクチャをサポートするようになりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月11日 18:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/aws-lambda-microvms-x86-architecture/](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-lambda-microvms-x86-architecture/)

## 概要

<p>AWS Lambda MicroVMs は現在 x86 CPU アーキテクチャをサポートしているため、再コンパイルやポーティングを行うことなく、既存の x86 アプリケーション、ツール、ソフトウェア依存関係を実行できます。マイクロVM イメージを作成するときには、これまでどおり x86 と Arm（AWS Graviton）を選択でき、ワークロードが使用するアーキテクチャごとにユーザーまたはジョブに分離された MicroVM を割り当てられます。</p> 
<p>Lambda MicroVMs は、VM レベルの分離、ほぼ瞬時の起動・再開、状態の保持を提供するサーバーレスコンピューティングの基礎要素です。</p>
