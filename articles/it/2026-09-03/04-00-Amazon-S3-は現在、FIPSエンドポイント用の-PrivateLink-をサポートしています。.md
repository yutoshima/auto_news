# Amazon S3 は現在、FIPSエンドポイント用の PrivateLink をサポートしています。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月03日 04:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-s3-privatelink-fips-endpoints](https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-s3-privatelink-fips-endpoints)

## 概要

Amazon S3 は現在、FIPS 140-3 プログラムの検証を受けたエンドポイントに対して AWS PrivateLink をサポートしています。

セキュリティとコンプライアンス要件を満たす顧客は、S3 への接続時に FIPS 検証済み暗号モジュールを使用しつつ、トラフィックを仮想プライベートクラウド（VPC）内にとどめることができます。開始するには、新規または既存の S3 用インターフェイス VPC エンドポイントを作成または編集し、FIPS S3 エンドポイントを使用するように設定します。
