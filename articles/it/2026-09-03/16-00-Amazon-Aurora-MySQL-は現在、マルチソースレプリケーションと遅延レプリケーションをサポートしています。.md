# Amazon Aurora MySQL は現在、マルチソースレプリケーションと遅延レプリケーションをサポートしています。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it

## 概要

<p>本日より、Amazon Aurora MySQL は新たに二つのレプリケーション機能をサポートします：マルチソース・レプリケーションと遅延レプリケーションです。マルチソース・レプリケーションは、単一の Aurora MySQL クラスターが複数のソースデータベースから同時にレプリケートできるようにし、別々の MySQL データベースのデータを統合しやすくします。これにより、シャードの統合や別々のデータベース（例：地域別や部門別のインスタンス）からのデータを中央地点へ集約するなど、運用上の重要なユースケースを実現します。</p>
