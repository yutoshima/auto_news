# AWS Elastic Beanstalk は、共有インフラストラクチャ上で複数のアプリケーションを実行するためのクラスター モードを導入します。

## 概要

AWS Elastic Beanstalkは、アカウント内の共有インフラストラクチャ上で複数のアプリケーションを実行・管理できる新しいデプロイモード「クラスターモード」を導入します。ソースコード、Dockerfile、または Amazon ECR のコンテナイメージを提供すると、Elastic Beanstalk がコンテナ化、プロビジョニング、継続的な運用を、すでに使用しているコンソール・CLI・APIを通じて処理します。新しい Elastic Beanstalk GitHub Action を使用して、CI/CDパイプラインの一部としてリポジトリから直接アプリケーションをデプロイします。
