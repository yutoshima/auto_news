# AWS Device Farm向けのテストインサイトを発表

- **カテゴリ**: it

## 概要

<p><a href="https://aws.amazon.com/device-farm/">AWS Device Farm</a>は、モバイルおよびウェブアプリのテスト用サービスで、現在複数デバイスに対する Appium、Espresso、XCUITest の実行に対して Test Insights を提供しています。Test Insights は、デバイスごとおよびテストごとにテストスイートを詳細に分解して表示することで、テストの健全性を理解し、AIエージェントとともに障害の解決を faster に進めるのを支援します。</p>
<p>Test Insights を使うと、Device Farm の既存 API から テストのメタデータの強化版と、失敗の根本原因を含む情報が返されるようになります</p>
