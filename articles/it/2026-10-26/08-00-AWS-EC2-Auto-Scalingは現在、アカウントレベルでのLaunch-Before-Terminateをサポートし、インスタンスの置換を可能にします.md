# AWS EC2 Auto Scalingは現在、アカウントレベルでのLaunch Before Terminateをサポートし、インスタンスの置換を可能にします。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月26日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/ec2-auto-scaling-launch-before-terminate/](https://aws.amazon.com/about-aws/whats-new/2026/10/ec2-auto-scaling-launch-before-terminate/)

## 概要

AWS EC2 Auto Scaling は、アカウント内のすべての Auto Scaling グループで、デフォルトの置換動作として「起動後に終了」を有効にできるようになりました。これを有効にすると、Auto Scaling は置換用のインスタンスを起動し、健康チェックを通過するまで待機してから、置き換えられるインスタンスを終了します。これにより、インスタンスの置換イベント中もアプリケーションの容量と可用性を維持できます。これは、インスタンスのリフレッシュ、リバランス、ヘルスチェック、最大値などの置換イベントにも適用されます。
