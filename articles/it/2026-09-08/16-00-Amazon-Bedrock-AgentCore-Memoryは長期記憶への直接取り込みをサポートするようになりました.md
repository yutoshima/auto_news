# Amazon Bedrock AgentCore Memoryは長期記憶への直接取り込みをサポートするようになりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月08日 16:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/09/agentcore-memory-direct-ingest](https://aws.amazon.com/about-aws/whats-new/2026/09/agentcore-memory-direct-ingest)

## 概要

<p>Amazon Bedrock AgentCore Memory は、開発者が短期メモリイベントとして永続化することなく、長期メモリ抽出のためのコンテンツを直接提出できるようになりました。新しい IngestData API はコンテンツを受け取り、それをメモリに設定された長期メモリ戦略へ拡散し、他の長期メモリレコードと同じ取得操作を通じて結果として得られるメモリレコードを利用可能にします。すべてが短期イベントを作成せずに行われます。<br /> <br /> これまで、すべてのコンテンツは長期メモリレコードとして保存する必要がありました。
