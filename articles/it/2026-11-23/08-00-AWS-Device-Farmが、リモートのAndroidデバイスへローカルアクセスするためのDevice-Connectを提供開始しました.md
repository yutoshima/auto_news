# AWS Device Farmが、リモートのAndroidデバイスへローカルアクセスするためのDevice Connectを提供開始しました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月23日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/device-farm-device-connect/](https://aws.amazon.com/about-aws/whats-new/2026/11/device-farm-device-connect/)

## 概要

AWS Device Farm はモバイルおよびウェブアプリのテスト用サービスですが、現在 Device Connect を提供しています。Device Connect を使えば、AIエージェントとともに、ローカルマシン上の任意のIDE・ターミナル・開発環境から、あたかもノートパソコンに直接接続されているかのようにリモートのAndroid端末を利用できます。デバッガを接続したり、パフォーマンスをプロファイリングしたり、ビルドをプレビューしたり、ADB（Android Debug Bridge）コマンドを実行したり、端末と手動で対話したりすることができます。さらにライブでの操作も可能です。
