# IAM Roles AnywhereがAWS SDK用のJavaプラグインを提供開始

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月25日 13:18

## 概要

AWS Identity and Access Management (IAM) Roles Anywhereは、外部のワークロードがJavaアプリケーションプロセス内で直接一時的なAWS認証情報を取得できるようにする、<a href="https://docs.aws.amazon.com/sdk-for-java/latest/developer-guide/home.html">AWS SDK for Java v2</a>用プラグインを提供します。プラグインはアプリケーションと同じJava Virtual Machine (JVM)で動作するため、IAM Roles Anywhereの実行を別の場所に分離する必要がなくなります。
