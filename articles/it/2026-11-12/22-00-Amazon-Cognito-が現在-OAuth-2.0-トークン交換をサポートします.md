# Amazon Cognito が現在 OAuth 2.0 トークン交換をサポートします

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月12日 22:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/cognito-token-exchange/](https://aws.amazon.com/about-aws/whats-new/2026/11/cognito-token-exchange/)

## 概要

<p><a href="https://aws.amazon.com/cognito/">Amazon Cognito</a>は現在、OAuth 2.0 トークン交換（RFC 8693）をサポートしています。Amazon Cognitoは、ウェブアプリケーション、モバイルアプリケーション、AIエージェントにサインアップ・サインイン・アクセス制御を追加するのに役立ちます。トークン交換を使用すると、ユーザーに代わって動作するサービスやAIエージェントが、ユーザーのトークンを特定の下流サービスに対してスコープされた新しいトークンへ交換することができます。従来は、ユーザーに代わって別のサービスを呼び出すサービスは、ユーザーの元のトークンを送信する必要がありました。</p>
