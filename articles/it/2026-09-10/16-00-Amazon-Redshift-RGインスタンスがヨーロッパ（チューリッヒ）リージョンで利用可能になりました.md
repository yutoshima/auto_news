# Amazon Redshift RGインスタンスがヨーロッパ（チューリッヒ）リージョンで利用可能になりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月10日 16:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-redshift-rg-available-zurich](https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-redshift-rg-available-zurich)

## 概要

<p>Amazon Redshift RG インスタンスは、AWS Graviton プロセッサを搭載し、AWS Europe (Zurich) リージョンで利用可能になりました。RG インスタンスは、データウェアハウスおよびデータレイクのワークロードを、前世代の RA3 インスタンスより最大 2.4 倍の速度で実行しつつ、vCPU あたりの価格を 30%抑えることで、より高い性能を提供します。RG インスタンスには、Redshift が独自に構築したベクトル化データレイククエリエンジンが含まれており、クラスタノード上で Apache Iceberg および Parquet データを処理することで、データウェアハウス全体にわたる SQL アナリティクスの実行を可能にします。</p>
