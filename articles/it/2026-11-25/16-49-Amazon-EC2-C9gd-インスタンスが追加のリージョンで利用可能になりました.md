# Amazon EC2 C9gd インスタンスが追加のリージョンで利用可能になりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月25日 16:49
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-ec2-c9gd-instances-additional-regions/](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-ec2-c9gd-instances-additional-regions/)

## 概要

本日より、Amazon Elastic Compute Cloud (Amazon EC2) C9gd インスタンスが Europe (Ireland, Spain) リージョンで利用可能になります。これらのインスタンスは AWS Graviton5 プロセッサを搭載しており、カスタム設計CPUの第5世代で、Amazon EC2 上で実行される幅広いワークロードに対して最良の価格性能を提供します。

C9gd インスタンスは、AWS Graviton4ベースの C8gd インスタンスより最大25%高い計算性能を実現します。
