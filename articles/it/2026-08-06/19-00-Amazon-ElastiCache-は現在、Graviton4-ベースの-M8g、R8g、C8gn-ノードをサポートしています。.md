# Amazon ElastiCache は現在、Graviton4 ベースの M8g、R8g、C8gn ノードをサポートしています。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月06日 19:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-elasticache-graviton4-m8g-r8g-c8gn/](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-elasticache-graviton4-m8g-r8g-c8gn/)

## 概要

<p>Amazon ElastiCache は、Valkey および Memcached の Graviton4 ベースの M8g、R8g、C8gn ノードファミリーをサポートします。Graviton4 ベースのノードは、同等サイズの Graviton3 ベースノードと比較して、ノードファミリー、サイズ、ワークロード構成に応じて、オンデマンド料金で最大47％のスループット向上、最大P99レイテンシ32％低下、価格性能比最大31％向上を実現します。</p>
<p>Graviton4 ベースのノードは、同等の Graviton3 ベースノードと比較して、ノードあたりのメモリ容量も多く提供します。</p>
