# Amazon S3 Tables は現在、S3 サーバーアクセスログ記録をサポートしています。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月10日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-s3-tables-server-access-logging/](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-s3-tables-server-access-logging/)

## 概要

<p>Amazon S3 Tables は現在、サーバーアクセスログのサポートを提供します。これにより、テーブルバケットに対するリクエストの詳細な記録を取得できます。テーブル操作、ネームスペース管理、データアクセスを追跡し、セキュリティ監査、アクセス分析、コストの配分をサポートします。ログの配信は追加料金なしで利用でき、ログファイルのストレージのみ料金が発生します。</p> 
<p>テーブルバケットでサーバーアクセスログを有効にすると、S3 は全てのテーブルとネームスペースへのリクエストについてログを配信します。</p>
