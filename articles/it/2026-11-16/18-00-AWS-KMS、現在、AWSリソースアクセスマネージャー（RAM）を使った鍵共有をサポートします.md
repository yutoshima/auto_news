# AWS KMS、現在、AWSリソースアクセスマネージャー（RAM）を使った鍵共有をサポートします

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月16日 18:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/kms-key-sharing-resource-access-manager/](https://aws.amazon.com/about-aws/whats-new/2026/11/kms-key-sharing-resource-access-manager/)

## 概要

AWS Key Management Service (KMS) は現在、AWS Resource Access Manager (RAM) と統合されました。これにより、AWS アカウント間、AWS Organizations 内の組織内、特定の IAM ロールやユーザーとの間で KMS キーを共有する方法がよりシンプルで一貫性のあるものになります。RAM の再利用可能なマネージド権限を用いて、信頼できる相手に必要なアクセス権を定義してもらいながら、キーとキー ポリシーの完全な管理を自分たちで維持することができます。キーを共有するには、共有するキーを選択してリソース共有を作成します。
