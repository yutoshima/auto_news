# Amazon OpenSearch Serverless は、時系列コレクション向けのインテリジェントなデータ取り込みをサポートします。

## 概要

次世代の Amazon OpenSearch Serverless は、時系列コレクション向けのインテリジェントなインジェストをサポートします。S3 から時系列コレクションへログやイベントデータを、インジェストパイプラインを運用することなく取り込むことができます。インテリジェントインジェストを使えば、設定を完了して AWS Management Console で数回のクリック、または単一の API コールでデータの取り込みを開始できます。

インテリジェントインジェストはデータタイプを検出し、各レコードを解析して、あなたのコレクションにインデックスします。
