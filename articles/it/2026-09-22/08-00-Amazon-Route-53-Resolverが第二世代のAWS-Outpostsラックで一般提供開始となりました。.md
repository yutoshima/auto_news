# Amazon Route 53 Resolverが第二世代のAWS Outpostsラックで一般提供開始となりました。

- **カテゴリ**: it

## 概要

<p>Amazon Route 53 Resolverが第二世代のAWS Outpostsで一般提供されました。Outpost上で直接、ローカルに管理された再帰的DNS解決を行います。Outpost上で動作するワークロードのDNSクエリはローカルで解決され、待機遅延の低減と、親となるAWSリージョンへ到達するためのサービスリンクの経由を不要にします。Route 53 Resolverはサービスリンクが切断されてもキャッシュされたDNSレコードを保持するため、接続障害が発生しても継続的なDNS解決を保証します。
