# AWS Transform for migrationsは、ローンチ後の作業を自動化します。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月06日 17:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/aws-transform-for-migrations-automates-post-launch-actions](https://aws.amazon.com/about-aws/whats-new/2026/08/aws-transform-for-migrations-automates-post-launch-actions)

## 概要

AWS Transformは、移行ワークフローを通じて、ローンチ後のアクションの設定と実行を自動化します。アカウントレベルでアクションを定義し、ターゲットアカウント内の各ソースサーバーに自動的に適用します（マルチアカウント移行を含む）。これらのアクションを自動化することで、サーバーごとに設定する遅くてエラーが発生しやすい作業を排除し、チームがより多くのサーバーを手作業の負担を減らして移行できるようにします。

ローンチ後のアクションは、AWS Systems Manager（SSM）を通じて直ちに実行されます。
