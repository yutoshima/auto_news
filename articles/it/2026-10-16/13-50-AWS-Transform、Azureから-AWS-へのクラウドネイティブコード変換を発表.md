# AWS Transform、Azureから AWS へのクラウドネイティブコード変換を発表

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月16日 13:50
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/aws-transform-azure-to-aws-code-conversion/](https://aws.amazon.com/about-aws/whats-new/2026/10/aws-transform-azure-to-aws-code-conversion/)

## 概要

本日、AWSは AWS Transform で Azure SDK から AWS SDK へのアプリケーションコード変換の一般提供を発表しました。これにより、Microsoft Azure クラウドネイティブ .NET アプリケーションを AWS へ移行するための加速した道筋が提供されます。AWS Transform .NET モダナイゼーションエージェントは、Azure サービスコードを特定し、それを同等の AWS サービスコードへ変換します。例えば、Azure Cosmos DB を使用する Azure Functions のサーバーレス機能は、Amazon DynamoDB を使用する AWS Lambda の機能へ変換できます。
