# AWS Elastic Disaster Recoveryが、6つの追加のAWSリージョンで利用可能になりました。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年07月21日 22:00

## 概要

AWS Elastic Disaster Recovery（AWS DRS）は、以下の6つの追加AWSリージョンで利用可能になりました：アジア太平洋（バンコク）、アジア太平洋（マレーシア）、アジア太平洋（ニュージーランド）、アジア太平洋（台北）、カナダ西部（カルガリー）、メキシコ（中部）。Elastic Disaster Recoveryは、AWSへのディザスタリカバリに推奨されるサービスです。手頃なストレージ、最小限のコンピュート、ポイント・イン・タイムのリカバリを活用して、オンプレミスおよびクラウドベースのアプリケーションを迅速かつ信頼性高く復旧させることで、ダウンタイムとデータ損失を最小化します。
