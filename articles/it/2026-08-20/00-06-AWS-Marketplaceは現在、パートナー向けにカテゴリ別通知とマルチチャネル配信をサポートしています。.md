# AWS Marketplaceは現在、パートナー向けにカテゴリ別通知とマルチチャネル配信をサポートしています。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月20日 00:06
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/aws-marketplace/](https://aws.amazon.com/about-aws/whats-new/2026/08/aws-marketplace/)

## 概要

AWSパートナーは、AWS User Notificationsを通じて、カテゴリ別通知の設定と複数チャンネルでのAWS Marketplace通知配信を行えるようになりました。従来、パートナーはAWSアカウントのルートメールアドレスやカスタムメールエイリアス宛にAWS Marketplaceの通知を受け取り、通知カテゴリを選択したり各カテゴリを管理担当チームへルーティングしたりする方法がありませんでした。この開始により、パートナーは各通知カテゴリを受け取る連絡先と、その配信方法を選択できるようになります。
