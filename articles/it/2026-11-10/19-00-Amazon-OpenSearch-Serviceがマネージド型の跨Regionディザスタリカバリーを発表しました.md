# Amazon OpenSearch Serviceがマネージド型の跨Regionディザスタリカバリーを発表しました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月10日 19:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-opensearch-service-managed-cross-region-disaster-recovery/](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-opensearch-service-managed-cross-region-disaster-recovery/)

## 概要

<p>Amazon OpenSearch Service は現在、マネージドのクロスリージョン災害復旧を提供しており、重要な検索・AI・分析ワークロードの可用性と事業継続性の厳しい要件を、リプリケーションを自分で構築・維持することなく満たせます。2つのリージョンでドメインを作成した後、単一の API 呼び出しまたは AWS Management Console のいくつかの手順でペアリングできます。</p>
<p>マネージド災害復旧は、復旧時点目標（RPO）を1分未満に、復旧時間目標（RTO）を迅速に提供します。</p>
