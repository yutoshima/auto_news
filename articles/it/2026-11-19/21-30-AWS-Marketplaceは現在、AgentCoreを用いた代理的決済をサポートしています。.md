# AWS Marketplaceは現在、AgentCoreを用いた代理的決済をサポートしています。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月19日 21:30
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/marketplace-agentic-payments-agentcore/](https://aws.amazon.com/about-aws/whats-new/2026/11/marketplace-agentic-payments-agentcore/)

## 概要

AWS Marketplaceは現在、x402プロトコルを用いたエージェンシック決済をサポートしています。AIエージェントはAgentCore決済（Amazon Bedrock AgentCoreの一部）を通じて、USドルで選択された製品を発見・購入し、リクエストごとに支払いを行うことができます。エージェントは作業中に有料のAPI、データ、コンテンツを必要とすることが多いですが、アクセスには通常、人物がサインアップを行い、支払い方法を追加し、APIキーを作成する必要があります。エージェンシック決済を利用すれば、顧客は個別のセラーごとの設定を省略でき、従来の既存のAWS請求に対して課金が清算され、暗号ウォレットは不要です。
