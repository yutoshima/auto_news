# AWS WAF、Amazon Bedrock Guardrails を使用した LLM、MCP、A2A エンドポイントの自動検出と保護を発表

- **カテゴリ**: it
- **公開日時**: 2026年11月23日 18:47

## 概要

自動化されたAIエンドポイントの検出と保護が一般提供となり、AWS Organization 全体の Amazon API Gateway、Application Load Balancer、そして Amazon CloudFront の背後にある language model (LLM)、Model Context Protocol (MCP)、および Agent2Agent (A2A) のエンドポイントを検出し、それらを AWS WAF で保護できるようになりました。

検出は新しい API Gateway API Portal を通じて利用可能であり、トラフィックログとサービスから自動的に検出される API の中から AI エンドポイントを認識します。
