# AWS Bedrock の Web 検索は現在、ドメインフィルタリングとユーザーの位置情報制御をサポートしています。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月23日 21:04
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/bedrock-web-search-domain-user-location/](https://aws.amazon.com/about-aws/whats-new/2026/10/bedrock-web-search-domain-user-location/)

## 概要

<p>現在、AWS Bedrock の Web Search は、モデルの応答を根拠づける結果に対してより正確さを与える二つの新しいコントロール、ドメインフィルタリングとユーザー所在地をサポートします。どちらも、既存の OpenAI Responses API リクエスト内の web_search ツール上で直接設定します。</p> 
<p>ドメインフィルタリングを使用すると、Web Search の結果を自分で選択したドメインのセットに限定できます。filters パラメータを用いて、最大 100 の allowed_domains を指定して信頼できる情報源に結果を制限するか、最大 100 の blocked_domains を指定して特定のドメインをブロックすることができます。＞
