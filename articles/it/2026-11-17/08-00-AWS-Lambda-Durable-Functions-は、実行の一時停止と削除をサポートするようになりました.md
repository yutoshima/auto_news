# AWS Lambda Durable Functions は、実行の一時停止と削除をサポートするようになりました

## メタデータ

- **カテゴリ**: it
- **公開日時**: 2026年11月17日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/lambda-durable-pause-delete/](https://aws.amazon.com/about-aws/whats-new/2026/11/lambda-durable-pause-delete/)

## 概要

AWS Lambda の durable functions は、実行中の durable 実行を一時停止し、後で再開しても進捗を失わないことを可能にします。再開時には、前回のチェックポイントから同じファンクションバージョンで続行します。デフォルトでは、再開に要した時間は実行タイムアウトにはカウントされません。また、保留期間が終了する前に完了した実行のデータを削除することもできます。

Lambda durable functions を使えば、耐障害性のある複数ステップのアプリケーションや、AI ワークフローを構築できます。
