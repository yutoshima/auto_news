# Amazon S3 サーバーアクセスログの CloudWatch Logs への配信が、5つの追加 AWS リージョンで利用可能に

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月21日 13:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-s3-server-access-logs-cloudwatch-logs-regions/](https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-s3-server-access-logs-cloudwatch-logs-regions/)

## 概要

<p>Amazon S3のサーバーアクセスログをAmazon CloudWatch Logsに配信する機能が、AWS GovCloud (US)リージョン、AWS European Sovereign Cloud、およびAWS Chinaリージョンで利用可能になりました。CloudWatch Logsにアクセスログが到着するたびにクエリを実行したり、アラームを設定したり、AWS Key Management Service（AWS KMS）キーで暗号化したりすることができます。この新しい配信経路は、従来のS3一般用途バケットへのサーバーアクセスログ配信を補完するもので、アクセスの監視と分析の柔軟性を高めます。
