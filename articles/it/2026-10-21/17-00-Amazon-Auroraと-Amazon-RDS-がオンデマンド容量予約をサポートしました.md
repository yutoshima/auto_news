# Amazon Auroraと Amazon RDS がオンデマンド容量予約をサポートしました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月21日 17:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-aurora-rds-on-demand-capacity-reservations/](https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-aurora-rds-on-demand-capacity-reservations/)

## 概要

本日より、Amazon Aurora および Amazon RDS DB インスタンスの計算容量を、1つ以上のアベイラビリティゾーンで、必要な期間だけ事前に予約することができます。容量を予約することで、DB インスタンスの作成、復元、スケール計算、起動操作が容量不足のために失敗するリスクを減らすことができます。

オンデマンド容量予約は、ビジネスクリティカルなイベント時に、特定の DB インスタンス容量が利用可能であることを確信する必要があるワークロード向けに設計されています。
