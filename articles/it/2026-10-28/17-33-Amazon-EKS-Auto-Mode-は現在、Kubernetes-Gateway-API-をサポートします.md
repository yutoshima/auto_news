## 概要

Amazon EKS Auto ModeはKubernetes Gateway APIをサポートするようになり、トラフィックがアプリケーションへどのように到達するかを標準的で移植性のある方法で定義できます。顧客はGatewayおよびHTTPRouteリソースを使用してアプリケーションのロードバランシングを設定でき、EKS Auto Modeは基盤となるAWSインフラストラクチャを自動的にプロビジョニングおよび管理します。

このリリースにより、EKS Auto Modeの顧客は、別個のインストールや設定を行うことなく、次世代のKubernetesトラフィック管理基準を採用できます。
