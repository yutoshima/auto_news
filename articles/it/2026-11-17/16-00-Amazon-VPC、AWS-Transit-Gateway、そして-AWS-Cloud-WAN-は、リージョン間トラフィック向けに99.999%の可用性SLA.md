## 概要

AWSは現在、Amazon Virtual Private Cloud（Amazon VPC）間ピアリング、AWS Transit Gateway、AWS Cloud WANを通じたクロスリージョン通信に対して、99.999％の可用性SLAを提供しています。新機能の「マルチパス・レジリエンス（Multipath Resilience）」により、決済処理、金融取引、電話通信、ライブメディア配信など、リージョン間でトラフィックを送るミッションクリティカルなアプリケーションのレジリエンスを向上させやすくなります。
