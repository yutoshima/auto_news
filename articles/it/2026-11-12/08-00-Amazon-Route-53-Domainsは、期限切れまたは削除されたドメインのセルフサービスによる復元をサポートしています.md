# Amazon Route 53 Domainsは、期限切れまたは削除されたドメインのセルフサービスによる復元をサポートしています

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月12日 08:00

## 概要

<p>Amazon Route 53 Domains では、期限切れまたは最近削除されたドメインを、自分で復元できるようになりました。Amazon Route 53 コンソール、AWS CLI、または AWS SDK を使用します。以前はドメインの復元には AWS サポートへのリクエストが必要でした。これにより、支払い方法の失効、更新の見逃し、または誤って削除してしまったドメインを回復し、それに依存するウェブサイト、メール、アプリケーションを復元できます。</p>
<p>ドメインを復元するには、ドメイン名を入力し、復元料金を確認し、請求を承認します。</p>
