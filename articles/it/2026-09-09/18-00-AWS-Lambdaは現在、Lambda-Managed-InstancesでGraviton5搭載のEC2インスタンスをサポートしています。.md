# AWS Lambdaは現在、Lambda Managed InstancesでGraviton5搭載のEC2インスタンスをサポートしています。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月09日 18:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/09/aws-lambda-graviton5-ec2/](https://aws.amazon.com/about-aws/whats-new/2026/09/aws-lambda-graviton5-ec2/)

## 概要

AWS Lambdaは現在、AWS Graviton5搭載のC9g、C9gd、M9g、M9gdインスタンスを Lambda Managed Instances でサポートします。最新世代のGravitonプロセッサ上でLambda関数を実行でき、Graviton4搭載インスタンスと比較して最大25%の計算性能向上を実現します。

AWS Lambda Managed Instances は、Lambdaの運用性を保ちながら、EC2インスタンス上でLambda関数を実行できるようにします。
