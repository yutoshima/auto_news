# AWS ユーザー体験のカスタマイズ（UXC）が、すべての商用 AWS リージョンで利用可能になりました。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月02日 13:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/aws-uxc-aws-regions](https://aws.amazon.com/about-aws/whats-new/2026/08/aws-uxc-aws-regions)

## 概要

AWS ユーザーエクスペリエンスのカスタマイズ（UXC）は、すべての商用 AWS リージョンで利用可能になりました。UXC を使用すると、アカウント管理者がカスタムアカウントカラーを設定し、AWS マネジメントコンソールに表示されるサービスとリージョンを制御できます。

以前は UXC は米国東部（ノースバージニア）でのみ利用可能で、これらの設定をプログラム的に管理する顧客は、単一のリージョンへ API コールを向ける必要がありました。本日の拡張により、顧客は商用 AWS の任意のリージョンからアカウントカスタマイズを管理できるようになります。
