# AWS Secrets Manager は現在、アカウントを跨ぐレプリケーションに対応しています。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月13日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/secrets-manager-cross-account/](https://aws.amazon.com/about-aws/whats-new/2026/11/secrets-manager-cross-account/)

## 概要

AWS Secrets Managerは現在、他アカウント間レプリケーションをサポートしており、主要シークレットの同期コピーを別のAWSアカウントで維持することで、他アカウントアクセス、バックアップ、災害復旧を実現します。アカウント間レプリケーションは、既存のマルチリージョンレプリケーション機能をアカウントの境界を越えて拡張します。

アカウント間レプリケーションを使えば、プラットフォームやセキュリティ担当チームがシークレットの所有とローテーションを中心的に管理でき、各利用アカウントはローカルで常に最新のコピーを取得できます。
