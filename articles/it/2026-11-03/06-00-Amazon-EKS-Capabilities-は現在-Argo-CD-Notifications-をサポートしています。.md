# Amazon EKS Capabilities は現在 Argo CD Notifications をサポートしています。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月03日 06:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-eks-argo-cd-notifications](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-eks-argo-cd-notifications)

## 概要

<p>Amazon Elastic Kubernetes Service（Amazon EKS）向けのArgo CD Capabilityは、Argo CD Notificationsをサポートするようになり、アプリケーションの同期、失敗、健全性の変化時に通知を提供します。トリガーとメッセージテンプレートをクラスター内で定義し、個々のアプリケーションをアノテーションで購読します。これは上流のArgo CDと同じ方法です。</p> 
<p>このローンチにより、Slack、PagerDuty、Opsgenie、Amazon SQS、Amazon EventBridgeなど、16の通知サービスへ通知を配信できるようになります。</p>
