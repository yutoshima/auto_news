# Amazon EKS Auto Mode は現在、Pod のセキュリティグループをサポートしています

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月11日 17:26
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-eks-auto-mode-security-groups-for-pods/](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-eks-auto-mode-security-groups-for-pods/)

## 概要

<p>Amazon EKS Auto Modeは現在、Pod用のセキュリティグループをサポートしており、個々のPodに専用のAmazon EC2セキュリティグループルールを適用できます。同じノード上の異なるワークロードが異なるセキュリティグループを持つことができ、アプリケーションごとに別々のノードプールを作成することなく、Podにネットワークレベルのセグメンテーションを提供します。</p>
<p>Pod用セキュリティグループは既存のAWSネットワークコントロールをPodレベルに拡張するため、PodはAmazon RDSやAmazon ElastiCacheデータベースなどのリソースにアクセスできます。</p>
