# Amazon RDS for Oracle が現在、プライマリーエンドポイントをサポートします

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月20日 22:54
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/rds-oracle-primary-endpoint-v2/](https://aws.amazon.com/about-aws/whats-new/2026/11/rds-oracle-primary-endpoint-v2/)

## 概要

<strong>Amazon Relational Database Service (Amazon RDS) for Oracle</strong> は現在、レプリカ構成で常に現在のプライマリ DB インスタンスを指す DNS 名であるプライマリエンドポイントを提供します。Oracle レプリカへ切り替えた場合、Amazon RDS はプライマリエンドポイントを新しいプライマリ DB インスタンスに pointing するため、アプリケーションの接続文字列を変更する必要はありません。従来は、スイッチオーバーのたびに接続文字列や DNS を更新する必要がありました。
