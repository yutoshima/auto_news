# AWS Workload Credentials Provider は ACM 証明書のコンテナ対応を追加しました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月17日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/acm-certificates-container-support/](https://aws.amazon.com/about-aws/whats-new/2026/11/acm-certificates-container-support/)

## 概要

オープンソースの AWS Workload Credentials Provider は、Amazon Elastic Container Service (Amazon ECS) 上のコンテナ（AWS Fargate、Amazon Elastic Kubernetes Service (Amazon EKS)、および Amazon EC2 上の Docker を含む）で、AWS Certificate Manager (ACM) 証明書をアプリケーションへエクスポートできるようになりました。EC2 で行うのと同じように、コンテナ化された TLS ワークロードの証明書のデプロイと更新を自動化できます。
