# AWS Elemental MediaConnect Routerは現在、エンドポイント接続管理をサポートします

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月26日 08:00

## 概要

AWS Elemental MediaConnect Routerは、新しいエンドポイントレジストリを介した接続管理をサポートするようになりました。これにより、MediaConnect以外のデバイスやソフトウェアを登録し、それらのエンドポイントをルータの入力および出力に接続できます。登録済みエンドポイントを他のAWSアカウントと直接共有できるため、ルータの入力と出力を手動でチェインしたり、IPアドレスや暗号化設定の調整を行う手間が省けます。
