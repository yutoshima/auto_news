# Amazon Connectのお客様は、APIを通じてカスタム指標を作成・管理・検索できます

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月16日 16:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/09/connect-customer-custom-metrics-apis/](https://aws.amazon.com/about-aws/whats-new/2026/09/connect-customer-custom-metrics-apis/)

## 概要

<p>Amazon Connect Customer は標準指標のライブラリを提供します。カスタム指標を使えば、ビジネス独自の測定を定義してさらに深掘りできます。しかし、さまざまなインスタンスで手動で管理すると、定義が徐々にずれてしまい、数値がもはや整合しなくなります。信頼できない指標は、指標が全くない状態より悪いのです。なぜなら、それに基づいて人々が意思決定を行うからです。</p> 
<p>今度は、1つの指標を定義したら、7つの新しい API 操作（CreateMetric、DeleteMetric、…）を通じてプログラム的に管理します。</p>
