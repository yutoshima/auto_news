# AWS Lambdaは現在、Amazon SQS FIFOキューのバッチサイズを最大10,000件のメッセージまでサポートします。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月20日 19:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/aws-lambda-10K-batch-size-SQSFIFO/](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-lambda-10K-batch-size-SQSFIFO/)

## 概要

AWS Lambda は現在、Amazon Simple Queue Service（Amazon SQS）の FIFO キューのイベントソースマッピング（ESM）を「割り当てモード」で、1回の呼び出しあたり最大10,000件のメッセージのバッチサイズをサポートします。以前の10件から増加しています。より大きなバッチによって、金融取引、受注処理、在庫更新など、発生量が多く、順序を保つワークロードを呼び出し回数を減らして処理できます。
