# AWS Lambda はLambda Managed Instances向けに Seekable OCI（SOCI）レイジーローディングをサポートします

## 概要

AWS Lambdaは現在、Open Container Initiative (OCI) イメージとしてパッケージ化された「イベント関数」を遅延ロードするための Seekable OCI (SOCI) をサポートします。これらは Lambda Managed Instances 上で実行されます。SOCI のサポートにより、実行環境の起動の各段階で必要なファイルだけを取得し、ダウンロードする代わりに取得します。"
