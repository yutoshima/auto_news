# AWS IAM は、信頼されたアイデンティティの伝播を IAM フェデレーションと IAM Roles Anywhere に拡張し、IAM Identity Center での簡素化を実現します。

## 概要

Trusted identity propagation (TIP) は、サポートされている AWS サービスへのリクエストとともに、人間のユーザーまたはワークロードの識別情報を伝播します。顧客はその識別情報を IAM ポリシーの条件でアクセス制御に利用したり、AWS CloudTrail で元の人間ユーザーやワークロードを識別したりできます。AWS は TIP を拡張しています。
