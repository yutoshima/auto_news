# EC2のAmazon Machine Imagesは、Amazon Inspectorを通じて脆弱性スキャンが可能になりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月02日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/ec2-amis-scanned-through-inspector/](https://aws.amazon.com/about-aws/whats-new/2026/11/ec2-amis-scanned-through-inspector/)

## 概要

<p>Amazon Inspectorは脆弱性スキャン機能をEC2のAmazon Machine Images（AMIs）にも拡張し、インスタンスを起動したり追加ソフトウェアをインストールしたりすることなく、AMI内のソフトウェア脆弱性を特定できるようになりました。これにより、AMIがフリート全体でインスタンスを起動する前に、根本原因を修正することが可能です。</p>
<p>この機能を使えば、AMIカタログを継続的に評価して新たに発見された脆弱性を監視したり、特定の対象に対して一度きりのスキャンを実行することができます。</p>
