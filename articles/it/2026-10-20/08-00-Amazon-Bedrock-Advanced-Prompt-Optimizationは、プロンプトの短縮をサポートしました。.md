# Amazon Bedrock Advanced Prompt Optimizationは、プロンプトの短縮をサポートしました。

## 概要

<p>Amazon Bedrock Advanced Prompt Optimizationは、評価スコアを維持または向上させつつ、プロンプトの長さを短くするオプション設定「プロンプト短縮」への対応を開始しました。Advanced Prompt Optimizationは、Amazon Bedrock上の任意のモデル向けに、独自の評価基準に基づいてプロンプトを最適化します。これまでの最適化は品質の向上だけに焦点を当ててきました。最適化されたプロンプトは元のものより長くなることが多く、長いプロンプトは入力トークンコストを引き上げ、最初のトークンまでの時間を増加させる可能性があります。</p>
