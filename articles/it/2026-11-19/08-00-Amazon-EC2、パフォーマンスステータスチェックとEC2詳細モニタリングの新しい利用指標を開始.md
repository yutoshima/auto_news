# Amazon EC2、パフォーマンスステータスチェックとEC2詳細モニタリングの新しい利用指標を開始

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月19日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/ec2-performance-status-checks/](https://aws.amazon.com/about-aws/whats-new/2026/11/ec2-performance-status-checks/)

## 概要

顧客は現在、Amazon EC2 のパフォーマンスステータスチェックと EC2 Detailed Monitoring の新しい利用状況メトリクスを利用して、インスタンス内でのセットアップを不要にした状態で EC2 ワークロードのパフォーマンスを観察・対応でき、ゲスト側ツールを補完します。パフォーマンスに敏感な EC2 ワークロードを実行している顧客は、これらの信号を用いて CPU および GPU リソースを監視し、容量ニーズを調整し、アプリケーションの問題をトラブルシュートできます。 

EC2 パフォーマンスステータスチェックは、非終端のハードウェア状態を識別します
