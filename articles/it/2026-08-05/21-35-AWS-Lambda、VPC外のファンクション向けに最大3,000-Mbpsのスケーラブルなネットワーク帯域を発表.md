# AWS Lambda、VPC外のファンクション向けに最大3,000 Mbpsのスケーラブルなネットワーク帯域を発表

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月05日 21:35
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/aws-lambda-network-bandwidth/](https://aws.amazon.com/about-aws/whats-new/2026/08/aws-lambda-network-bandwidth/)

## 概要

<AWS Lambda> は現在、Lambda 関数のスケーラブルなネットワーク帯域をサポートしており、実行環境へのデータ転送を遅延に敏感なワークロード向けに高速化します。この機能により、VPC 外でメモリ2 GB以上に設定された場合、帯域幅が比例的に拡大され、2 GB時の625 Mbps から 10 GB時の 3,000 Mbps までアクセスできます。  
顧客は Lambda を用いて、遅延に敏感なデータ処理ワークロードを構築します。
