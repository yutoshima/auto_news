# AWS IoT Coreが時系列データ向けのネイティブなInfluxDBルーティングをサポートするようになりました

## 概要

<AWS IoT Core>は、<a href="https://docs.aws.amazon.com/iot/latest/developerguide/influxdb-rule-action.html">InfluxDBルールアクション</a>をサポートし、IoTデバイスからの時系列データを直接<InfluxDB>データベースへルーティングします。デバイス側のカスタムコードを書いたり、中間クラウドサービスを使用したりする必要はありません。AWS IoT Coreは、完全に管理されたサービスで、セキュリティも確保されています。
