# AWS IAM Identity Centerは、新しい組織インスタンスにおけるAWSアカウントアクセスの管理を任意にします

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月05日 15:12
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/aws-identity-center-accounts-optional/](https://aws.amazon.com/about-aws/whats-new/2026/08/aws-identity-center-accounts-optional/)

## 概要

<p>AWS IAM Identity Centerは、新しい組織インスタンスを作成する際に、AWSアカウントへのアクセス管理を有効にするかどうかを決定できるようになりました。これにより、AWSアカウントへのアクセス管理を行うことなく、IAM Identity Centerを使用してAWSアプリケーションへのアクセスのみを管理できます。 この機能はIAM Identity Centerインスタンスの初期設定時に利用可能で、既存のIAM Identity Centerインスタンスには影響しません。</p> 
<p>IAM Identity Centerはあなたの作業を接続することを可能にします</p>
