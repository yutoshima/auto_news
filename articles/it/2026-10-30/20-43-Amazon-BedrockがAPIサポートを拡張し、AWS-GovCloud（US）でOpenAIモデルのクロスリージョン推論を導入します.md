# Amazon BedrockがAPIサポートを拡張し、AWS GovCloud（US）でOpenAIモデルのクロスリージョン推論を導入します

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月30日 20:43
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/bedrock-openai-runtime-govcloud/](https://aws.amazon.com/about-aws/whats-new/2026/10/bedrock-openai-runtime-govcloud/)

## 概要

Amazon Bedrock は現在、 bedrock-runtime エンドポイント上で OpenAI GPT-5.6 モデル（Terra と Luna）をサポートしており、AWS GovCloud (US) で Responses、Converse、Chat Completions API を利用できます。さらに、Cross-Region Inference のサポートを追加し、AWS GovCloud (US) の各リージョン間での高いスループットと冗長性の向上を実現します。Cross-Region Inference は、推論リクエストを自動的に両方の AWS GovCloud (US) リージョンへルーティングします。
