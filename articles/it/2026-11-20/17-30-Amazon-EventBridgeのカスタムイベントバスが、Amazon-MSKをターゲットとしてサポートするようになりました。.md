# Amazon EventBridgeのカスタムイベントバスが、Amazon MSKをターゲットとしてサポートするようになりました。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月20日 17:30
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-eventbridge-msk-target/](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-eventbridge-msk-target/)

## 概要

<p>Amazon EventBridge は拡張されたカスタムイベントバスのターゲットとして Amazon Managed Streaming for Apache Kafka（Amazon MSK）をサポートするようになり、独自のプロデューサを実行せずに Kafka トピックへイベントを配信できます。</p>
<p>EventBridge のカスタムイベントバスは、サーバーレスのイベントブローカーで、アプリケーション、SaaS統合、AWSサービス間でイベントをルーティングすることにより、スケーラブルなイベント駆動型アプリケーションを作成できるようにします。MSK へイベントを配信するには、クラスターを指定する Subscriber を作成します</p>
