# AWS料金計算機が新しいAPIを通じてワークロードのコストを見積もるようになりました

## 概要

<p>AWS Pricing Calculatorは新しいAPI GetUsageLinesEstimatedCostを提供します。これにより、計画されたワークロードの推定コストを単一のAPI呼び出しで取得できます。1回のリクエストで最大500の使用量行を送信すると、見積もりをアカウントに保存せずにすぐにコストが返されます。ワークロードの推定値を作成してPricing Calculatorに保存することはできますが、GetUsageLinesEstimatedCostはニーズに応じて、推定コストを直接自分のツールやワークフローで返します。</p>
