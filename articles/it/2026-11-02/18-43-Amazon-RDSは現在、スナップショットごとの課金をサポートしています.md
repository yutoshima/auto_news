# Amazon RDSは現在、スナップショットごとの課金をサポートしています

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月02日 18:43
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-rds-per-snapshot-billing/](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-rds-per-snapshot-billing/)

## 概要

本日より、Amazon RDS は RDS スナップショットごとの請求をサポートします。スナップショットごとの請求により、各個別のスナップショットのコストを把握できます。

従来、RDS スナップショットの料金は Cost and Usage レポートおよび Cost Explorer でデータベースインスタンス単位に集計されていました。これにより、スナップショットの料金を把握する際には、個々のスナップショットを掘り下げるのではなく、データベースインスタンス単位の集計ビューしか確認できませんでした。これからは、個々のスナップショットごとに料金を確認できるようになります。
