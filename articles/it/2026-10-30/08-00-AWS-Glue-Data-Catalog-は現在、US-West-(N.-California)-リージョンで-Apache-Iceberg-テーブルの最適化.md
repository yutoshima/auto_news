# AWS Glue Data Catalog は現在、US West (N. California) リージョンで Apache Iceberg テーブルの最適化をサポートします

## 概要

AWS Glue Data Catalog は現在、US West (N. California) Region における Apache Iceberg テーブルの自動テーブル最適化をサポートしています。Apache Iceberg は、データレイク内の大規模テーブルに対して高速なクエリ性能を提供するオープンなテーブル形式です。このリリースにより、個々のテーブルまたはデータカタログ内の全テーブルに対してテーブル最適化を有効化できます。

Apache Iceberg テーブルは、書き込みごとに小さなファイル、スナップショット、参照されていないファイルを蓄積し、クエリを遅くし、ストレージを増大させます。
