# Amazon Linux 2027 が現在パブリックプレビュー公開中です

## 概要

本日、AWSは Amazon Linux 2027（AL2027）のパブリックプレビューを発表します。AL2027は、AWS上のクラウド native ワークロード向けに、パフォーマンス・スケール・セキュリティを念頭に置いて設計された、次世代の Amazon Linux オペレーティングシステムです。AL2023のベースラインを土台に、ウェブアプリケーション・データベース・コンテナ化されたマイクロサービス・AI／MLワークロード・大規模なインフラストラクチャを運用する、セキュアで安定し、AWSネイティブなOSを必要とする顧客を想定して設計されています。

AL2027はカーネル7.1以上で動作します。
