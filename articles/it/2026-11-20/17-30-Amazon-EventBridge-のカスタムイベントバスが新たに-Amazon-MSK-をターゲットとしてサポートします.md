# Amazon EventBridge のカスタムイベントバスが新たに Amazon MSK をターゲットとしてサポートします

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月20日 17:30
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-eventbridge-msk-target/](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-eventbridge-msk-target/)

## 概要

<p>Amazon EventBridge は現在、拡張されたカスタムイベントバスのターゲットとして Amazon Managed Streaming for Apache Kafka (Amazon MSK) をサポートしているため、独自のプロデューサーを実行せずに Kafka トピックへイベントを配信できます。</p> 
<p>EventBridge のカスタムイベントバスはサーバーレスのイベントブローカーで、アプリケーション、SaaS 統合、AWS サービス間でイベントをルーティングすることで、スケーラブルなイベント駆動型アプリケーションを作成できるようにします。MSK へイベントを配信するには、サブスクライバーを作成し、クラスタを指定します。</p>
