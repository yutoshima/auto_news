# AWS Elemental MediaConnect Routerは現在、ハイビットレートモードをサポートしています

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月19日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/mediaconnect-router-high-bitrate/](https://aws.amazon.com/about-aws/whats-new/2026/10/mediaconnect-router-high-bitrate/)

## 概要

AWS Elemental MediaConnect Router は、250 Mbps と 500 Mbps の二つの新しい階層を追加し、高ビットレートモードをサポートします。これにより、高ビットレートを必要とするプロの放送局は、品質や信頼性を損なうことなく高価値コンテンツを伝送できます。

この強化により、放送貢献、コンテンツ配信、リモートプロダクションのための、VSF TR-07 準拠のトランスポートストリーム配布など、業界標準のワークフローが実現します。ハイビットレートモードは、最大で二つの冗長ソースをサポートします。
