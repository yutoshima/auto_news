# Amazon Timestream for InfluxDB がカスタマー管理鍵をサポートしました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月20日 20:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-timestream-influxdb-cmk/](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-timestream-influxdb-cmk/)

## 概要

<p>Amazon Timestream for InfluxDB は、InfluxDB 2 データベースインスタンス、InfluxDB 2 Read Replica、および InfluxDB 3 クラスターの静的データを暗号化するための AWS Key Management Service（AWS KMS）カスタマーマネージドキーをサポートします。顧客はデータベースリソースを作成する際に対称キーの AWS KMS キーを選択します。</p>
<p>Timestream for InfluxDB は、選択されたキーを使用して InfluxDB 2 および InfluxDB 3 リソースの基盤となるデータベースストレージを暗号化します。キーはデータベースと同じ AWS アカウントおよび AWS リージョン内でなければなりません。</p>
