# AWS Lambdaは現在、Lambda Managed Instances容量プロバイダのログを公開しています

- **カテゴリ**: it

## 概要

<p>AWS Lambda は現在、Lambda Managed Instances（LMI）容量プロバイダのログを Amazon CloudWatch Logs に公開し、スケーリング活動とインスタンスのライフサイクル操作を可視化します。LMI はサーバーレスの運用のシンプルさを保ちながら、Amazon EC2 インスタンス上で Lambda 関数を実行できるようにします。容量プロバイダは、Lambda が代わりにプロビジョニングするコンピューティングリソースを定義できるリソースです。容量プロバイダのログを使用することで、それらの監視、トラブルシューティング、最適化を行うことができます。
