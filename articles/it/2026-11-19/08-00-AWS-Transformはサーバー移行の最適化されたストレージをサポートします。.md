# AWS Transformはサーバー移行の最適化されたストレージをサポートします。

## 概要

AWS Transformは、 migrations のための推奨事項として、移行する各サーバーごとに最適化されたストレージタイプと構成を提案するようになりました。そのため、サーバーごとに個別に判断する必要はなくなります。最近のストレージ評価機能を基に、AWS Transform の推奨は各サーバーの実測パフォーマンスと容量データを活用して、過剰プロビジョ닝を抑制します。
