# Amazon Inspector Code Security は GitHub Enterprise Server とプライベート接続を追加します。

- **カテゴリ**: it

## 概要

<p>Amazon Inspector Code Securityは現在、GitHub Enterprise Server（GHES）連携とGHESおよびGitLab Self-Managed用のプライベートネットワーク接続をサポートしています。Code Securityはパブリックプレビューで自動修正プルリクエストの機能も開始します。プライベートネットワーク内でGHESまたはGitLab Self-Managedをホストする組織は、Amazon Virtual Private Cloud（Amazon VPC）構成またはAWS CodeConnectionsを通じて接続できるようになり、ファイアウォールをAWS全体のIPアドレスに開放することなくリポジトリをスキャンできます。】
