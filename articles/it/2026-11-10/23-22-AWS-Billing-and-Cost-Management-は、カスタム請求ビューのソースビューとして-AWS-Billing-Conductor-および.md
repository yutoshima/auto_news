# AWS Billing and Cost Management は、カスタム請求ビューのソースビューとして AWS Billing Conductor および AWS Billing Transfer のビューをサポートしました。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月10日 23:22
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/aws-billing-and-cost-management-multi-source-custom-billing-views](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-billing-and-cost-management-multi-source-custom-billing-views)

## 概要

<p>カスタム課金ビューは現在、ソースビューとして AWS Billing Conductor および AWS Billing Transfer のビューをサポートしています。これらは、課金グループごと、課金転送関係ごとに AWS が管理しているビューです。これらを単一のカスタム課金ビューに組み合わせ、フィルターを適用し、Cost Explorer、AWS Budgets、Billing and Cost Management コンソールでそのビューを使用できます。3 つのソースビュータイプがあります。Billing group（課金グループ）ビューには、各 Billing Conductor 課金グループのコストが含まれており、それらを組み合わせて使用します。
