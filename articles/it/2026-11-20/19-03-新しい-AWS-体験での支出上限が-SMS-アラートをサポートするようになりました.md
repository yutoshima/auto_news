# 新しい AWS 体験での支出上限が SMS アラートをサポートするようになりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月20日 19:03
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/sms/](https://aws.amazon.com/about-aws/whats-new/2026/11/sms/)

## 概要

新しい AWS エクスペリエンスを Paid プランで利用しているビルダーは、従来のメール通知に加えて、テキストメッセージ（SMS）での支出上限アラートを受け取れるようになりました。支出上限は、プロジェクトの月間最大費用を設定します。通知は、プロジェクトが上限に近づいたときと上限に達したときに送信され、上限に達すると AWS が自動的にプロジェクトを一時停止します。SMS は、プロジェクトの費用について把握するための二つ目の手段となります。

メール通知は、ビルダーが受信トレイを離れていると気づかれずに見逃されることがあります。
