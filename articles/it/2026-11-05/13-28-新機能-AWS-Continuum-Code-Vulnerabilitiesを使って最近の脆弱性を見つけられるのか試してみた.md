# AWS Continuum for code vulnerabilities の要約

## サービス概要

2026年10月23日にAWSが**Continuum for code vulnerabilities**をGA（一般提供）開始しました。本サービスは、脆弱性の発見から修正提案までをひとつのループにした統合セキュリティサービスです。スキャナー等の検出結果をコードリポジトリおよびAWS環境のコンテキストと突き合わせて「本当に悪用可能か」を見極め、隔離サンドボックス上でPoC（概念実証）を生成し、ビジネス影響度に基づいて優先度付けし、人がマージする前提の修正PRを返すことが特徴です。
