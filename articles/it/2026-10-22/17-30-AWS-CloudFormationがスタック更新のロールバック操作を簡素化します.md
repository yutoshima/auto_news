# AWS CloudFormationがスタック更新のロールバック操作を簡素化します

## 概要

AWS CloudFormation は、更新のロールバックを完了してデプロイ作業に戻るのをより簡単にします。更新ロールバックは、スタックを既知の良好な状態に戻します。本日から、リソースの自動ロールバックが不可能な場合でも、強制ロールバックにより1回の操作でロールバックを完了できます。これは、AWS CLI の CloudFormation ワークフローを含むすべての CloudFormation ワークフローで機能します。
