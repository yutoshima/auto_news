# Amazon Managed Workflows for Apache Airflow は現在、AIエージェントスキルを提供しています

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月15日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-mwaa-ai-agent-skills/](https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-mwaa-ai-agent-skills/)

## 概要

Amazon Managed Workflows for Apache Airflow (MWAA) は現在、<a href="https://docs.aws.amazon.com/agent-toolkit/latest/userguide/what-is-agent-toolkit.html">AWS Agent Toolkit</a>と連携して、組み込みのAIエージェントスキルを提供します。これにより、MWAAワークフローの作成・デバッグ・テスト、およびエージェントスキルをサポートする任意のAIコーディングアシスタントを用いたMWAA環境のアップグレードを可能にします。

4つのスキルは、authoring-mwaa-workflow、debugging-mwaa-workflow、testing-mwaa-workflow、upgrading-mwaa-environment です。
