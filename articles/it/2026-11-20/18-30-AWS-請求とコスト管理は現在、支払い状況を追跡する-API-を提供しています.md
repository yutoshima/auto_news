## 概要

本日、AWS 請求とコスト管理が、AWS SDKと AWS CLIを通じて AWS の支払い情報を閲覧できる新しい API を発表します。これらの API を使えば、アカウント残高を確認したり、支払期日がある請求書や延滞中の請求書を見つけたり、各請求書に適用された支払いやクレジットメモを確認したり、アカウントの支払方法が有効かどうかを確認したりできます。独自のツールから、または AI エージェントを介して API を呼び出すことも可能です。
