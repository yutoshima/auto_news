# AWSのSplit Cost AllocationデータがAmazon S3をサポートしました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月17日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/split-cost-allocation-data-s3/](https://aws.amazon.com/about-aws/whats-new/2026/11/split-cost-allocation-data-s3/)

## 概要

本日から、共用の Amazon S3 汎用バケットのストレージと請求コストを、そのバケット内のプレフィックスに割り当て、AWS Cost and Usage Report（CUR）で確認できるようになります。組織はしばしば、マーケティングや財務といった異なるプレフィックスの下に、複数のチーム、アプリケーション、またはテナントのデータを1つのバケットに格納します。これまでは、各プレフィックスへの請求額を特定するには、S3 Inventory や Storage Lens レポートを基にしたカスタムパイプラインと独自の価格計算ロジックを作成する必要がありました。
