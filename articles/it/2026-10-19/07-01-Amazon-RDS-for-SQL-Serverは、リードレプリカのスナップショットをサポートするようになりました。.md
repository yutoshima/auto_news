# Amazon RDS for SQL Serverは、リードレプリカのスナップショットをサポートするようになりました。

## メタデータ

- **カテゴリ**: it
- **公開日時**: 2026年10月19日 07:01
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/rds-sqlserver-supports-snapshots-on-read-replicas](https://aws.amazon.com/about-aws/whats-new/2026/10/rds-sqlserver-supports-snapshots-on-read-replicas)

## 概要

Amazon Relational Database Service (Amazon RDS) for SQL Serverは現在、読み取り専用レプリカインスタンス上でDBスナップショットを直接作成できるようになりました。以前はスタンドアロンおよびプライマリDBインスタンス上でのみスナップショットを作成できました。読み取り専用レプリカを先に昇格させることなくスナップショットを取れるようになり、バックアップおよび災害復旧（DR）ワークフローの柔軟性が高まりました。
