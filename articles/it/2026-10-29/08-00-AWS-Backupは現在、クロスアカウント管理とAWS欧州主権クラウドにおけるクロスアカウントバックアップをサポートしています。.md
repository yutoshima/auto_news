# AWS Backupは現在、クロスアカウント管理とAWS欧州主権クラウドにおけるクロスアカウントバックアップをサポートしています。

- **カテゴリ**: it

## 概要

AWS Backupは現在、クロスアカウント管理、クロスアカウントバックアップ、および委任された管理者をAWS European Sovereign Cloud（ドイツ）リージョンでサポートしています。これらの機能により、AWS Organizationsを使用して、組織内のアカウント間でバックアップを一元的に管理・監視・コピーすることが可能になります。

クロスアカウント管理を使用すると、AWS Organizationsの管理アカウントまたは委任された管理者アカウントから、組織全体のバックアップポリシーを展開できます。バックアップの監視も行うことができます。
