# Amazon VPC IPAM ポリシーは、自動化されたインターネットファイアウォールと AWS Lambda Web Functions および MicroVM のサポートを追加しました

## 概要

<p>Amazon Virtual Private Cloud (VPC) IPアドレスマネージャー（IPAM）ポリシーは現在、AWS Network Firewallの自動インターネットファイアウォールおよびAWS Lambda Web FunctionsとMicroVMにも対応しています。特定のIPAMプール（BYOIPアドレスやAmazon提供の連続IPv4ブロックなど）から、これらのリソースへ公衆IPv4アドレスを割り当てるよう、AWSアカウントおよびAWSリージョン全体でIPAMポリシーを集中管理できます。これにより、セキュリティ体制を強化し、ネットワークとセキュリティ運用を合理化します。
