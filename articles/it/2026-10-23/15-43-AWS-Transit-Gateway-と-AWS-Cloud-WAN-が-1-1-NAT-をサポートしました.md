# AWS Transit Gateway と AWS Cloud WAN が 1:1 NAT をサポートしました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月23日 15:43
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/aws-transit-gateway-cloud-wan-1-1-nat/](https://aws.amazon.com/about-aws/whats-new/2026/10/aws-transit-gateway-cloud-wan-1-1-nat/)

## 概要

AWS Transit GatewayとAWS Cloud WANは、Regional Private NAT Gatewayとの統合を通じて、アタッチメント上で直接管理された1対1のネットワークアドレス変換（NAT）を提供します。これにより、同じIPアドレスレンジを共有するプライベートネットワーク間で、ネットワークの番号変更やNATアプライアンスの設置、リターン・トラフィックルールの作成を行うことなく接続できるようになります。

重複したクラスレス・インタードメイン routing（CIDR）ブロックを持つネットワークは、長い間通信できませんでした。
