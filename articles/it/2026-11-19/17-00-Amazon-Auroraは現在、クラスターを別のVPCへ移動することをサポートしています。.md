# Amazon Auroraは現在、クラスターを別のVPCへ移動することをサポートしています。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月19日 17:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/aurora-move-clusters-to-different-vpc/](https://aws.amazon.com/about-aws/whats-new/2026/11/aurora-move-clusters-to-different-vpc/)

## 概要

Aurora PostgreSQL と Aurora MySQL のクラスターは、データ移行なしである VPC（Amazon Virtual Private Cloud）間へ移動できるようになりました。クラスターを単一の API 呼び出しや RDS コンソールの更新操作で移動できます。これにより、IP アドレス空間が大きい VPC へ移動したり、重複しない CIDR 範囲を持つ VPC に移行したり、ネットワーク構成を統合したり、セキュリティとコンプライアンス要件の変更に対応したりできます。

以前は、別の VPC へ Aurora クラスターを移動するには作成が必要でした
