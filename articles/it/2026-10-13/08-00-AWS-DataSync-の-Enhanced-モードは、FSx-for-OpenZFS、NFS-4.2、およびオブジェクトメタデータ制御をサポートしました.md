# AWS DataSync の Enhanced モードは、FSx for OpenZFS、NFS 4.2、およびオブジェクトメタデータ制御をサポートしました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月13日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/datasync-enhanced-openzfs-nfs42-metadata/](https://aws.amazon.com/about-aws/whats-new/2026/10/datasync-enhanced-openzfs-nfs42-metadata/)

## 概要

AWS DataSync Enhanced モードは、Amazon FSx for OpenZFS をソースまたはデスティネーションロケーションとして、オンプレミス NFS サーバーおよび FSx for OpenZFS ファイルシステムの NFS バージョン 4.2、そしてオブジェクトストレージ転送用の新しい ObjectMetadata オプションをサポートしました。これまで FSx for OpenZFS へデータを転送する場合は、Basic モードに限定されていました。

NFS 4.2 を使えば、最新バージョンの NFS サーバーからデータを転送でき、古いプロトコルバージョンへ再設定する必要がありません。ObjectMetadata オプションは、オブジェクトストレージ転送に使用されます。
