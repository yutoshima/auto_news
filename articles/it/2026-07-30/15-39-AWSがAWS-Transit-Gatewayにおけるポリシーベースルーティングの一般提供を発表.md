# AWSがAWS Transit Gatewayにおけるポリシーベースルーティングの一般提供を発表

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年07月30日 15:39
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/07/aws-transit-gateway-policy-based-routing/](https://aws.amazon.com/about-aws/whats-new/2026/07/aws-transit-gateway-policy-based-routing/)

## 概要

AWS Transit Gateway は現在、ポリシーベースルーティング（PBR）をサポートしており、ネットワーク管理者が AWS ネットワーク全体のトラフィック転送を細かく制御できます。PBR を使用すると、転送決定を宛先 IP アドレスだけでなく、ソースおよび宛先 IP アドレス、ポート、プロトコルといったパケット属性の組み合わせに基づいて行うことが可能です。  
以前は、トラフィックの制御やワークロードの分離を必要とする顧客は、追加のルーティングを伴うマルチVPC構成を構築する必要がありました。
