## 概要

<p>Amazon Virtual Private Cloud (VPC) IPアドレスマネージャー（IPAM）ポリシーは、AWS Network Firewallの自動インターネットファイアウォールおよびAWS Lambda Web FunctionsとMicroVMにも対応しました。特定のIPAMプール（BYOIPアドレスやAmazon提供の連続IPv4ブロックなど）から、これらのリソースへ公衆IPv4アドレスを割り当てるよう、AWSアカウントやAWSリージョン全体でIPAMポリシーを一元的に設定できます。これにより、セキュリティ体制が強化され、ネットワークとセキュリティ運用が簡素化されます。
