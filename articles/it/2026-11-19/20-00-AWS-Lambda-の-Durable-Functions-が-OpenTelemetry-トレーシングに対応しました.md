# AWS Lambda の Durable Functions が OpenTelemetry トレーシングに対応しました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月19日 20:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/lambda-durable-otel/](https://aws.amazon.com/about-aws/whats-new/2026/11/lambda-durable-otel/)

## 概要

AWS LambdaがOpenTelemetry（OTel）サポートを発表しました。Lambdaの耐久性関数のトレースが可能になり、耐久性実行を追跡してトレースをAmazon CloudWatchや他の業界標準の可観測性ツールへ送信できます。これにより、システムのボトルネックを特定し、障害の根本原因を迅速に解明し、実稼働環境でのワークフローの挙動を理解するのに役立ちます。

Lambdaの耐久性関数を使えば、最大1年間実行されるリジリエントで多段階のアプリケーションやAIワークフローを構築でき、組み込みのチェッック機能などと組み合わせて運用できます。
