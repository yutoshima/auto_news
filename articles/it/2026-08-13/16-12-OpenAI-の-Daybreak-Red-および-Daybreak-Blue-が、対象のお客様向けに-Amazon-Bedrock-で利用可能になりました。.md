# OpenAI の Daybreak Red および Daybreak Blue が、対象のお客様向けに Amazon Bedrock で利用可能になりました。

## 概要

セキュリティチームは現在、OpenAIの Daybreak Red および Daybreak Blue を Amazon Bedrock から利用できます。どちらも Daybreak の一部で、OpenAI のサイバー防御イニシアティブとして、ディフェンダーがサイバーセキュリティ作業のために最先端AIへ統治されたアクセスを提供します。

Daybreak Blue は、脆弱性発見、検知エンジニアリング、インシデント対応など、Defensive ワークフローのほとんどの出発点となる基盤です。Daybreak Red は、脆弱性リサーチなどの高度で認可済みのタスク向けに設計されています。
