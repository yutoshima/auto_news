# AWS TransformがAzure-to-AWSクラウドネイティブコード変換を発表しました。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月16日 13:50
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/aws-transform-azure-to-aws-code-conversion/](https://aws.amazon.com/about-aws/whats-new/2026/10/aws-transform-azure-to-aws-code-conversion/)

## 概要

本日、AWS は AWS Transform で Azure SDK から AWS SDK へのアプリケーションコード変換の一般提供を発表し、Microsoft Azure クラウドネイティブ .NET アプリケーションを AWS へ移行するための加速パスを提供します。 AWS Transform の .NET モダナイゼーション エージェントは Azure のサービスコードを識別し、それを同等の AWS サービスコードへ変換します。例えば、Azure Cosmos DB を使用する Azure Functions のサーバーレス関数は、Amazon DynamoDB を使用する AWS Lambda 関数へ変換できます。
