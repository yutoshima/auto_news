# Amazon MSK Replicator は現在 AWS GovCloud (US-East, US-West) リージョンで利用可能です。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月06日 16:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-msk-replicator-additional-aws-regions](https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-msk-replicator-additional-aws-regions)

## 概要

Amazon MSK Replicator を AWS GovCloud (US-East, US-West) リージョンで利用できるようになり、<a href="https://aws.amazon.com/msk/">Amazon MSK</a> クラスター間および外部 Apache Kafka クラスター（オンプレミス、AWS 上のセルフマネージド、他のクラウドプロバイダーを含む）から Amazon MSK Provisioned クラスターへ、ストリーミングデータをレプリケートできます。

MSK Replicator は、Kafka クラスター間のデータレプリケーションを自動化する Amazon MSK の機能で、カスタムレプリケーション基盤を管理する手間をなくします。
