# AWS Agent Registry は現在、WebBotAuth ボット登録をサポートしています。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月20日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/agent-registry-webbotauth-support/](https://aws.amazon.com/about-aws/whats-new/2026/11/agent-registry-webbotauth-support/)

## 概要

AWS Agent Registryは、WebBotAuth（WBA）ボットを新しいレコードタイプとして登録することをサポートしました。これにより、標準化されたプロトコルを通じて正当なボットトラフィックを検証することが容易になります。以前は、組織が検証済みのボットと悪意のあるトラフィックを識別する標準化された方法を欠いていました。現在、ボットはWebBotAuthを通じてドメイン所有権を証明でき、この検証を<https://aws.amazon.com/about-a>と統合できます。
