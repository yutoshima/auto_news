# Amazon DynamoDBが一括でアイテムを追加する機能をサポートしました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月05日 18:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-dynamodb-now-supports-bulk-put-items/](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-dynamodb-now-supports-bulk-put-items/)

## 概要

今日は、Amazon DynamoDBへの大量データ投入機能の一般提供を発表します。これは完全マネージドの機能で、Amazon S3から既存のDynamoDBテーブルへデータを書き込むことができます。多くのDynamoDBアプリケーションは、他のシステムが生成・保存するデータをAmazon S3に保持しています。このデータを既存のDynamoDBテーブルへ書き込むには、通常はカスタムパイプラインを構築し、テーブルの容量を管理する必要がありました。大量データ投入機能を使えば、既存のワークロードに影響を与えることなく、このデータを書き込むことができます。
