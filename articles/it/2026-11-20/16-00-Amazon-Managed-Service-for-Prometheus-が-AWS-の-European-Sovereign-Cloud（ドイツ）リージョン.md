# Amazon Managed Service for Prometheus が AWS の European Sovereign Cloud（ドイツ）リージョンで利用可能になりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月20日 16:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amp-aws-european-sovereign-cloud/](https://aws.amazon.com/about-aws/whats-new/2026/11/amp-aws-european-sovereign-cloud/)

## 概要

<p>Amazon Managed Service for Prometheus は、AWS European Sovereign Cloud（Germany）リージョンで、Amazon Managed Service for Prometheus Collector とともに利用可能になりました。Amazon Managed Service for Prometheus は完全に管理された Prometheus 互換の監視サービスで、スケールして運用メトリクスの監視とアラートを行うのに役立ちます。AWS European Sovereign Cloud の顧客は、これまでより低いレイテンシで地域内に Prometheus 互換の監視ワークロードを実行できるようになり、ローカルワークロードの遅延が軽減されます。</p>
