# AWS Cloud WANがフロー・ログをサポートするようになりました

## メタデータ

- **カテゴリ**: it
- **公開日時**: 2026年11月11日 20:05

## 概要

AWS Cloud WANはVPC Flow Logsのサポートを追加し、グローバルネットワーク全体のIPトラフィックを中央で可視化できるようになりました。Flow Logsは各フローの詳細情報を取得するため、AWS Cloud WANアカウントを離れることなく、コアネットワーク上のトラフィックの動きを理解できます。

これまでは、ネットワーク管理者は多くのVPC、アカウント、リージョンからVPC Flow Logsを組み合わせて、グローバルネットワーク全体のトラフィックを確認する必要がありました。彼らはしばしば、他のチームがそれらのロギングデータへアクセスするのを待つこともありました。
