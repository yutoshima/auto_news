# AWSアカウントは現在、電話番号の検証をサポートしています

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月30日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/09/aws-accounts-phone-number-verification/](https://aws.amazon.com/about-aws/whats-new/2026/09/aws-accounts-phone-number-verification/)

## 概要

AWSアカウントは、主要連絡先電話番号の検証を電話番号認証としてサポートするようになりました。以前は、AWSアカウントの連絡先情報に登録された電話番号の形式は検証されていましたが、外部の手段による検証は行われていませんでした。現在は、SMSのワンタイムパスコード（OTP）を用いて電話番号を検証できます。

電話番号を検証するには、AWS Management Console から検証を開始するか、新しい SendPhoneNumberVerification API をプログラムで利用して検証を実行します。このAPIは6桁のOTPを送信します。
