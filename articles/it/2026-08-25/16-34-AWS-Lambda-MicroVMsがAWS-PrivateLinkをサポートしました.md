# AWS Lambda MicroVMsがAWS PrivateLinkをサポートしました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月25日 16:34
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/lambda-microvms-supports-privatelink](https://aws.amazon.com/about-aws/whats-new/2026/08/lambda-microvms-supports-privatelink)

## 概要

AWS Lambda MicroVMs は現在 AWS PrivateLink をサポートしており、 Lambda MicroVMs へ直接 private connectivity を提供します。これにより、パブリックインターネットにトラフィックを公開することなく、Amazon Virtual Private Cloud（VPC）リソースから Lambda MicroVMs へ private に接続できます。このローンチは、金融サービス、医療、政府機関などの規制対象ワークロードが、Lambda MicroVMs を用いて構築する際の厳格なネットワーク分離要件を満たすのに役立ちます。

PrivateLink VPC Endpoints は、VPC から AWS サービスへの private な接続を提供し、トラフィックが公開ネットワークを経由しないようにします。
