# AWS Elemental Inference をカスタマイズする — カスタムモデル、プロンプト、意思決定を活用して

- **カテゴリ**: it

## 概要

AWS Elemental Inference は、ライブ動画の分析方法を2通りの方法でカスタマイズできるようになりました。Amazon Bedrock のマルチモーダル基盤モデルを使用して動画に対するカスタム質問を行う関数を作成するか、あなたが定義するラベルと質問を用いて文脈的メタデータの意思決定を追加できます。どちらも、垂直動画作成やスマート字幕といった内蔵機能と同じパイプラインで実行され、別のパイプラインを構築することなく GetMetadata API を通じて結果を返します。
