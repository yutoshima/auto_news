# Amazon Bedrock Managed Knowledge Base は、Salesforce および Zendesk をネイティブデータソースコネクターとしてサポートするようになりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月23日 17:41
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-bedrock-managed-knowledge-base-salesforce-zendesk-native-data-source-connectors/](https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-bedrock-managed-knowledge-base-salesforce-zendesk-native-data-source-connectors/)

## 概要

AWSは、完全マネージドのリトリーバル・オーグメンテッド・ジェネレーション（RAG）サービスであるAmazon Bedrock Managed Knowledge Base向けの Salesforce および Zendesk データソース・コネクタを発表します。顧客は Salesforce のナレッジ記事や Zendesk の記事・コミュニティ投稿を、マネージドナレッジベースに直接同期できるようになります。
以前は、これらのプラットフォームから Bedrock Knowledge Base にコンテンツを取り込むには、カスタムインジェスチョン・パイプラインを構築する必要がありました。今は、インスタンスの認証情報を提供するだけで、コネクタが自動的に取り込んでくれます。
