# Amazon RDS for Oracle は、ダウンタイムを削減するためのリプリカ・ファースト・パッチ適用に対応しました

## 概要

<a href="https://aws.amazon.com/rds/oracle/">Amazon Relational Database Service (Amazon RDS) for Oracle</a>は、マイナーアップグレード時のダウンタイムを削減するReplica First Patchingをサポートしました。Replica First Patchingはエンタープライズ版DBインスタンスで利用できます。Replica First Patchingでは、プライマリDBインスタンスが引き続きトラフィックを処理している間に、同じAWSリージョン内のレプリカに先にマイナー版を適用し、準備が整い次第レプリカへフェイルオーバーします。
