# Amazon RDS for Db2がデータベース名の変更に対応しました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月20日 08:53

## 概要

<p>Amazon Relational Database Service (Amazon RDS) for Db2は、データベースをその場でリネームする機能を追加しました。新しいrdsadmin.rename_databaseストアドプロシージャを呼び出すことで、DBインスタンス上のデータベースを名前変更できます。以前はデータベースをバックアップして新しい名前で復元する必要がありました。リネームではデータをその場に保持するため、データベースのバックアップと復元よりも高速です。</p> 
<p>データベースのリネームは、データベースを置換するようなワークフローを簡素化します。</p>
