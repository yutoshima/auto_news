# Amazon WorkSpaces は現在、ネスト型仮想化をサポートしています。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月18日 09:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/nested-virtualization-workspaces/](https://aws.amazon.com/about-aws/whats-new/2026/08/nested-virtualization-workspaces/)

## 概要

AWSは、Amazon WorkSpaces PersonalおよびAmazon WorkSpaces Core Managed Bundles向けのネスト仮想化の提供を発表します。ネスト仮想化が有効化されていれば、開発者はWindows WorkSpaces上でDocker Desktop、WSL2、その他のハイパーバイザー依存ツールを直接実行でき、Linux WorkSpaces上ではKVMベースのワークロード、Androidエミュレータ、ネストされたコンテナを、別途の物理ハードウェアや回避策用環境を用意せずに利用できます。

ネスト仮想化はライセンスに関してサポートされています
