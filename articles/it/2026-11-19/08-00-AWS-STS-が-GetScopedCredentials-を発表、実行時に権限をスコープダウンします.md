# AWS STS が GetScopedCredentials を発表、実行時に権限をスコープダウンします

## 概要

AWS Security Token Service (AWS STS)は、既存の一時的なセキュリティ認証情報の権限を絞ることができる新しいAPI「GetScopedCredentials」を発表します。GetScopedCredentialsを使用すると、エージェント、サブエージェント、ワークロードごとに、必要な権限だけを含む独自の認証情報を付与できます。

GetScopedCredentialsは、すでに使用している一時的なセキュリティ認証情報を用いて権限の縮小、セッション長の短縮、またはその両方を実行することができます。結果として得られる認証情報は、元の認証情報の信頼性を維持します。
