# AWS Lambda の durable functions が AWS GovCloud (US) リージョンで利用可能になりました。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月16日 18:26
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/durablefunctions-govcloud/](https://aws.amazon.com/about-aws/whats-new/2026/10/durablefunctions-govcloud/)

## 概要

AWS Lambdaの耐久性関数が、AWS GovCloud (US-West) および AWS GovCloud (US-East) リージョンで利用可能になりました。耐久性関数を使うと、Lambdaの開発体験の中で、信頼性の高い多段階アプリケーションやAIワークフローを構築できます。

耐久性関数は、イベントハンドラ内の新しいプリミティブ（「step」や「wait」など）を追加して、進行状況をチェックポイント化し、障害から自動的に回復し、実行を停止することを可能にします。
