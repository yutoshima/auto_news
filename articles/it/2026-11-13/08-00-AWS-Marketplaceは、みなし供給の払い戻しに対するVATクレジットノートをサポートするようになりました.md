# AWS Marketplaceは、みなし供給の払い戻しに対するVATクレジットノートをサポートするようになりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月13日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/aws-marketplace-vat-credit-notes/](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-marketplace-vat-credit-notes/)

## 概要

<p>AWS Marketplaceの販売者は、AWS Partner Centralのセルフサービス体験を通じて、返金済みのみなし供給取引に対する付加価値税（VAT）のクレジットノートを提出できるようになりました。以前は、適格な取引に対してVATが販売者へ支払われ、後で購入者が返金を受けた場合、販売者は対応するクレジットノートを提出するためにAWSへ連絡する必要がありました。このリリースにより、返金後のVAT関連書類の作成が販売者にとって簡素化されます。</p>
<p>販売者は、みなし供給に関するVATのセクションで、対象となる返金の明細を確認できます</p>
