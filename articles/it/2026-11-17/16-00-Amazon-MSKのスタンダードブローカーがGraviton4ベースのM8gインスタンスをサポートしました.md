# Amazon MSKのスタンダードブローカーがGraviton4ベースのM8gインスタンスをサポートしました

## メタデータ

- **カテゴリ**: it
- **公開日時**: 2026年11月17日 16:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-msk-standard-brokers-graviton4-m8g-instances/](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-msk-standard-brokers-graviton4-m8g-instances/)

## 概要

AWS Graviton4ベースのM8gインスタンスが、Amazon Managed Streaming for Apache Kafka（Amazon MSK）のStandard Brokers向けに一般提供されました。M7gのStandard Brokersと比較して、M8gはP99のプロデュースレイテンシを最大35%低減し、遅れているコンシューマのキャッチアップを最大30%高速化します。

M8gのStandard Brokersは、すべてのAWSリージョンで本日利用可能です。
