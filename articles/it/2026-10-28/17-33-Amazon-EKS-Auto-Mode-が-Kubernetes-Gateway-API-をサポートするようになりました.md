# Amazon EKS Auto Mode が Kubernetes Gateway API をサポートするようになりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月28日 17:33

## 概要

<p>Amazon EKS Auto ModeはKubernetes Gateway APIをサポートするようになり、顧客がアプリケーションへのトラフィック到達方法を標準的でポータブルな形で定義できるようになりました。顧客はGatewayおよびHTTPRouteリソースを使用してアプリケーションのロードバランシングを構成でき、EKS Auto Modeは基盤となるAWSインフラストラクチャのプロビジョニングと管理を自動で行います。</p>
<p>このリリースにより、EKS Auto Modeの顧客は別途のインストールや設定を行うことなく、次世代のKubernetesトラフィック管理標準を採用できます。</p>
