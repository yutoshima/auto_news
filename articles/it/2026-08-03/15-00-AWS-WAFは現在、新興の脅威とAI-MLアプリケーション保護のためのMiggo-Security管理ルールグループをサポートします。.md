## 概要

AWS WAFは現在、Miggo Securityの2つの新しいパートナー管理ルールグループをサポートしています。AWS Marketplaceを通じて提供されており、以下の2つです：Miggo Rules for AWS WAF – High Emerging Application Threats、および Miggo Rules for AWS WAF – AI/ML Application Protection。これらのルールグループは、継続的に更新される保護機能をAWS WAFの顧客に提供し、脆弱性に対する防御を強化します。
