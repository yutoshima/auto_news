# Amazon EC2 I7i インスタンスが、アジア太平洋（タイ）およびイスラエル（テルアビブ）リージョンで利用可能になりました。

## メタデータ

- **カテゴリ**: it
- **公開日時**: 2026年08月03日 17:28
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-ec2-i7i-instances-in-additional-regions/](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-ec2-i7i-instances-in-additional-regions/)

## 概要

Amazon Web Services（AWS）は、アジア太平洋（タイ）およびイスラエル（テルアビブ）リージョンで高性能のStorage Optimized Amazon EC2 I7iインスタンスの提供を開始したと発表しました。第5世代 Intel Xeon プロセッサーを搭載し、全コア・ターボ時の周波数が3.2 GHz、これらの新しいインスタンスは前世代のI4iインスタンスと比べて計算性能を最大約23%向上し、価格性能も10%以上改善します。第3世代のAWS Nitro SSDを搭載するI7iインスタンスは、最大で45TBのNVMeストレージを提供します。
