# Amazon EC2 C8gn インスタンスが AWS イスラエル（テルアビブ）リージョンで利用可能になりました。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月17日 22:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-ec2-c8gn/](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-ec2-c8gn/)

## 概要

本日より、最新世代の AWS Graviton4 プロセッサを搭載した Amazon Elastic Compute Cloud（Amazon EC2） C8gn インスタンスが、AWS イスラエル（テルアビブ）リージョンで利用可能になります。C8gn インスタンスは、Graviton3 ベースの Amazon EC2 C7gn インスタンスと比べて、最大で 30% の計算性能向上を実現します。Amazon EC2 C8gn インスタンスは最新の第6世代 AWS Nitro Cards を搭載しており、最大 600 Gbps のネットワーク帯域を提供します。これはネットワーク最適化 EC2 インスタンスの中で最も高い帯域です。
