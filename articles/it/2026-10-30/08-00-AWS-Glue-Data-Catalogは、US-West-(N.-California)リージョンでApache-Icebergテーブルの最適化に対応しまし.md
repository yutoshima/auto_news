# AWS Glue Data Catalogは、US West (N. California)リージョンでApache Icebergテーブルの最適化に対応しました。

## 概要

<p>AWS Glue Data Catalogは、US West (N. California) RegionでApache Icebergテーブルの自動テーブル最適化をサポートします。Apache Icebergは、大規模なデータレイク上のテーブルに対して高速なクエリ性能を提供するオープンなテーブルフォーマットです。今回のリリースにより、個別のテーブルまたはデータカタログ内のすべてのテーブルに対して、テーブル最適化を有効化できます。</p>
<p>Apache Icebergテーブルは、書き込みごとに小さなファイル、スナップショット、参照されていないファイルが蓄積され、クエリを遅くし、ストレージを増大させます。</p>
