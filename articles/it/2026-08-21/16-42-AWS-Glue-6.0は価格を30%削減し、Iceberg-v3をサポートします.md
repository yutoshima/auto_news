# AWS Glue 6.0は価格を30%削減し、Iceberg v3をサポートします

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月21日 16:42
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/aws-glue-6-0-price-reduction-iceberg-v3](https://aws.amazon.com/about-aws/whats-new/2026/08/aws-glue-6-0-price-reduction-iceberg-v3)

## 概要

AWS Glue 6.0が正式に提供開始となり、価格を30%削減するとともに、Apache Iceberg v3の完全サポート、新しいバージョンの Apache Hudi と Delta Lake、そして開発者の生産性を向上させる新機能を導入します。AWS Glue 6.0はランタイムを Apache Spark 4.1、Python 3.13、Scala 2.13へとアップグレードします。

Apache Iceberg v3を採用することで、AWS Glue 6.0はVARIANTデータ型を追加し、半構造化データの読み取りを高速化する自動シャーディング機能を提供します。また、高速な行単位削除を可能にする削除ベクター機能も搭載します。
