# AWS Network Load Balancerが、AWSフェニックス・ローカルゾーンで利用可能になりました。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月05日 20:00

## 概要

AWS Network Load Balancerがフェニックス・ローカルゾーン（us-west-2-phx-2a）で利用可能になりました。AWS Local Zonesは、現在AWSリージョンが存在しない大規模な人口・産業・IT拠点に、AWSの計算、ストレージ、データベース、およびその他の選択サービスをより近くへ配置する、AWSのインフラストラクチャ展開の一種です。

このリリースにより、フェニックス・ローカルゾーン内に直接AWS Network Load Balancerを作成できます。これまでは、ターゲットがフェニックス・ローカルゾーン内で動作する場合、ロードバランサを配置する場所に制約がありました。
