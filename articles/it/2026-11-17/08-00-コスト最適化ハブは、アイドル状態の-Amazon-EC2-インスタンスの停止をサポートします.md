# コスト最適化ハブは、アイドル状態の Amazon EC2 インスタンスの停止をサポートします

## 概要

AWS Cost Optimization Hub は、推奨事項からアイドル状態の Amazon EC2 インスタンスを直接停止できるようになりました。Cost Optimization Hub は、アイドルリソースを含む、AWS アカウントとリージョン全体のコスト削減の推奨事項を統合・優先付けします。従来、アイドルインスタンスを停止するには Cost Optimization Hub から離れて、Amazon EC2 コンソールで特定のインスタンスを特定する必要がありました。今は Cost Optimization Hub の Savings opportunities ページから停止できます。
