# AWS Client VPNがMacOS 27 Golden Gateをサポートしました。

## 概要

AWS Client VPNは現在、MacOS 27 Golden Gateクライアント（バージョン6.0以降）をサポートしています。最新のMacOSバージョンでAWS提供のVPNクライアントを実行できます。AWS Client VPNのデスクトップクライアントは無料で提供されており、<a href="https://aws.amazon.com/vpn/client-vpn-download/">こちら</a>からダウンロードできます。 AWS Client VPNは、リモートワークフォースをAWSまたはオンプレミスのネットワークに安全に接続するマネージドサービスです。MacOS、Windows x64、Windows Arm64のデスクトップクライアントをサポートします。
