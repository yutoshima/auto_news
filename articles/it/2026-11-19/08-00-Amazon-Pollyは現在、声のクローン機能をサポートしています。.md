# Amazon Pollyは現在、声のクローン機能をサポートしています。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月19日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-polly-now-supports-voice-cloning/](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-polly-now-supports-voice-cloning/)

## 概要

今日は、Amazon Polly における音声クローン機能の一般提供をゲート付きリリースとして発表できることを嬉しく思います。同意を得た話者の数分間の録音を使用するだけで、その話者に似たクローンボイスを作成できます。クローンボイスは Amazon Polly Generative エンジン上で動作し、他の生成系ボイスと同様の自然さと精度を実現します。音声クローンは英語、スペイン語、ドイツ語、フランス語、イタリア語、ポルトガル語、ヒンディー語の7言語で提供開始されます。 Ea
