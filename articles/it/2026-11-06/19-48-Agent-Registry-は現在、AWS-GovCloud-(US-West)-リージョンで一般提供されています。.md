# Agent Registry は現在、AWS GovCloud (US-West) リージョンで一般提供されています。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月06日 19:48
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/aws-agent-registry-govcloud-us-west/](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-agent-registry-govcloud-us-west/)

## 概要

AWS Agent Registryは、Amazon Bedrock AgentCore経由で利用可能で、AWS GovCloud (US-West) リージョンで利用できます。

AWS Agent Registryは、組織がリソースを整理・キュレーション・発見するための中央カタログを提供する完全管理型のディスカバリサービスです。MCPサーバー、ツール、エージェント、エージェントスキル、カスタムリソースを検索可能なレジストリに公開でき、承認ワークフローを介して何を公開可能にするかを制御できます。人とAIエージェントは、その後レジストリ内のリソースを見つけることができます。
