# Amazon SESは、Mail Managerを使用したSMTP経由のメール送信を簡素化します。

- **カテゴリ**: it
- **公開日時**: 2026年07月24日 15:03

## 概要

<p>Amazon Simple Email Service（SES）は現在、Mail Manager を使用して SMTP 経由でメールを送信するための簡略化されたコンソール体験を提供しています。Mail Manager は SES 内のメールフローを管理する機能ですが、SMTP 送信を設定するために個々のリソースを構成するには複数の手順が必要です。新しいガイド付きセットアップはこれらのリソースを自動的に作成・設定するため、開発者は数回のクリックだけで開始できます。</p>
<p>ガイド付きセットアップは、開発者に実働の SMTP エンドポイントとダウンロード可能なクレデンシャルを提供します。</p>
