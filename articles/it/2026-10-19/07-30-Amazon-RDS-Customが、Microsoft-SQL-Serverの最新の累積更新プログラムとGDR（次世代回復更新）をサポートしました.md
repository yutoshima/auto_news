Amazon Relational Database Service (Amazon RDS) Custom for SQL Server は、Microsoft SQL Server の最新の累積更新プログラム（CU）および一般配布リリース（GDR）をサポートします。本リリースには、SQL Server 2019 CU32+GDR <KB5122772>（RDS バージョン 15.00.4490.9） のサポートが含まれます。
