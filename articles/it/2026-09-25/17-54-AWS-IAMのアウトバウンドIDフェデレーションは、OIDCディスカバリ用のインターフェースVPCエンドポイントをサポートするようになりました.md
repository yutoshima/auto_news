# AWS IAMのアウトバウンドIDフェデレーションは、OIDCディスカバリ用のインターフェースVPCエンドポイントをサポートするようになりました

## メタデータ

- **カテゴリ**: it
- **公開日時**: 2026年09月25日 17:54
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/09/aws-sts-vpc-oidc/](https://aws.amazon.com/about-aws/whats-new/2026/09/aws-sts-vpc-oidc/)

## 概要

AWS Identity and Access Management (IAM) outbound identity federation は、OpenID Connect (OIDC) ディスカバリ API のための Amazon Virtual Private Cloud (VPC) エンドポイントをサポートするようになりました。これにより、VPC 内から AWS PrivateLink を使用して OIDC ディスカバリのメタデータおよび JSON Web Key Set (JWKS) の検証キーのエンドポイントにアクセスできるようになり、トラフィックが公開ネットワークを経由する必要がなくなります。
