# Amazon GuardDuty が Runtime Monitoring の任意の脅威検出ルールを追加します

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月19日 16:01
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/guardduty-runtime-optional-detection-rules/](https://aws.amazon.com/about-aws/whats-new/2026/10/guardduty-runtime-optional-detection-rules/)

## 概要

<p>Amazon GuardDuty は現在、実行時モニタリングの任意の検出ルールをサポートしています。1つの環境では通常でも、別の環境では侵害の兆候である可能性がある、sudoers ファイルの変更や監査ログの無効化など、プロセス・ファイル・ネットワークのアクティビティを検知する 50 以上の実行時モニタリングルールを有効にできます。</p> 
<p>新しいルールは、EC2 インスタンス、Amazon EKS、Amazon ECS の検出を、EC2 および AWS Fargate の両方で提供し、MITRE ATT&CK にマッピングされた 13 の検出タイプにまたがります。</p>
