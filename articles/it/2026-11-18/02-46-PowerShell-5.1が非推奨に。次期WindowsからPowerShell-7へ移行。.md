# PowerShell 5.1が非推奨に。次期WindowsからPowerShell 7へ移行。

- **URL**: [https://pc.watch.impress.co.jp/docs/news/2157354.html](https://pc.watch.impress.co.jp/docs/news/2157354.html)

## 概要

Windowsに標準搭載されるPowerShellが、次期バージョンにて「PowerShell 5.1」から「PowerShell 7」に切り替わる。Microsoftが11月17日にアナウンスしたもので、PowerShell 5.1がデフォルトで有効となるのは、現行のWindows 11バージョン26H2およびWindows Server 2025が最後になる。
