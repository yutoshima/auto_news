# AWS MarketplaceのSaaSは、無料トライアルが自動的に有料購読へと変換されるようになりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月10日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/aws-marketplace-free-trial-conversion/](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-marketplace-free-trial-conversion/)

## 概要

本日、AWS Marketplaceは、使用量ベースのSaaS製品の無料試用が自動的に有料購読へ転換できるようになったと発表しました。無料試用が終了すると、購入者の購読は売り手の使用量ベースの価格のまま継続するため、試用期間後は実際に使用した分だけ支払います。これにより、売り手は試用ユーザーをより多く有料顧客へと転換しやすくなります。購入者は購入前に簡単にソフトウェアを評価でき、購入前の評価に新たな手間は不要です。
