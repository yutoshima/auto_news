# Amazon WorkSpaces Applicationsは現在、WebAuthnリダイレクトをサポートしています。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月19日 19:57
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-workspaces-applications-webauthn-redirection/](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-workspaces-applications-webauthn-redirection/)

## 概要

<p>Amazon WorkSpaces Applications は現在 WebAuthn のリダイレクションをサポートしており、ユーザーはストリーミング セッション内のウェブサイトやアプリケーションに、ローカルデバイス上の FIDO2 認証器（セキュリティキー、Windows Hello、Touch ID など）を使用してサインインできます。これまで、ユーザーのコンピューターに接続された認証器はストリーミングセッション内で使用できなかったため、フィッシング耐性の高い MFA（多要素認証）が必要な組織は、より弱いサインイン方法を使用するか、対象アプリケーションを限定する必要がありました。</p>
