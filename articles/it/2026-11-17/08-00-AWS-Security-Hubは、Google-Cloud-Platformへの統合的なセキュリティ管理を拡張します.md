# AWS Security Hubは、Google Cloud Platformへの統合的なセキュリティ管理を拡張します

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月17日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/security-hub-gcp/](https://aws.amazon.com/about-aws/whats-new/2026/11/security-hub-gcp/)

## 概要

今日は、AWSが AWS Security Hub が Google Cloud Platform（GCP）リソースを監視するようになったことを発表します。これにより、両方のクラウドにまたがってリスク分析、クラウドセキュリティ姿勢管理、脆弱性管理、セキュリティ対応管理を拡張します。AWSとGCPのワークロードを同時に運用している多くの顧客は、それぞれの環境で別々のセキュリティツールを使用せざるを得ず、リスクを全体的に優先順位づけしたり、一貫した対応を行うことが難しくなっていました。Security Hub は now 1つの統合されたエクスペリエンスを提供し、検出を可能にします。
