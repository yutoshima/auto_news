# Amazon ElastiCache for Valkey が ElastiCache Insights を紹介します

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月12日 07:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-elasticache-valkey-elasticache-insights/](https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-elasticache-valkey-elasticache-insights/)

## 概要

Valkey向けの <a href="https://aws.amazon.com/elasticache/">Amazon ElastiCache</a> は現在、ノードベースのクラスター用の事前構築ダッシュボードである ElastiCache Insights を提供します。ElastiCache Insights は、クラスターのヘルス、メモリ、計算、ネットワーク、コマンドスループット、レイテンシ、キー空間、エラーを、ElastiCache が自動的に公開する OpenTelemetry 指標のセットから取得して、1 つのビューに統合します。

ElastiCache Insights を利用して、キャッシュワークロードのヘルスを確認できます。
