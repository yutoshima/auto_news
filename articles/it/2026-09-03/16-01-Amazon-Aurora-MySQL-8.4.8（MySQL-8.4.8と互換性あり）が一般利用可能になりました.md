# Amazon Aurora MySQL 8.4.8（MySQL 8.4.8と互換性あり）が一般利用可能になりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月03日 16:01
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-aurora-mysql-848-available/](https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-aurora-mysql-848-available/)

## 概要

本日より、Amazon Aurora MySQL-Compatible Edition 8.4はMySQL 8.4.8をサポートします。いくつかのセキュリティ強化とバグ修正に加え、Aurora MySQL 8.4.8には、ポスト量子TLS（PQ-TLS）鍵交換、トランザクションのタイムアウト、多重ソースレプリケーション、遅延レプリケーションなど、いくつかの改善が含まれています。PQ-TLSは、データを転送中に暗号化するためのポスト量子暗号化オプションを提供します。トランザクションのタイムアウトは、長時間実行されることによって引き起こされるパフォーマンス問題の防止に役立ちます。
