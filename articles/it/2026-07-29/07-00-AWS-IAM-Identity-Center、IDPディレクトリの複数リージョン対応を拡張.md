# AWS IAM Identity Center、IDPディレクトリの複数リージョン対応を拡張

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年07月29日 07:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/07/aws-iam-identity-center-extends-multi-region-support-to-identity-center-directory](https://aws.amazon.com/about-aws/whats-new/2026/07/aws-iam-identity-center-extends-multi-region-support-to-identity-center-directory)

## 概要

<p>IAM Identity Center は、ワークフォースの AWS アカウントおよびアプリケーションへのシングルサインオン体験を構成するのに役立ちます。Identity Center のディレクトリをアイデンティティソースとして使用する場合、最初に有効化したプライマリ AWS リージョンから、任意の追加リージョンへ IAM Identity Center を複製することができるようになりました。これにより、外部アイデンティティプロバイダーに接続された Identity Center 組織インスタンス向けに以前提供されていたマルチリージョン対応機能を、アイデンティティソースとしてディレクトリを使用するインスタンスにも拡張します。
