# AWSは機械学習向けEC2キャパシティブロックの償却をサポート開始

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月06日 15:00

## 概要

<p>AWS Data Exports for Cost and Usage Report (CUR) 2.0 および AWS Cost Explorer は、機械学習用の Amazon EC2 Capacity Blocks の前払い料金を、各リザベーションの期間にわたって償却します。Capacity Block に投入された各インスタンスの償却費用と、未使用容量の償却費用を確認できるため、前払い料金を使用したワークロードに割り当て、未使用となった容量を特定できます。</p> 
<p>以前は、Capacity Block の前払い料金が 1 回の請求として表示されていました。</p>
