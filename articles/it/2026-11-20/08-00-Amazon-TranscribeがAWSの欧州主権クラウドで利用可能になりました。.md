# Amazon TranscribeがAWSの欧州主権クラウドで利用可能になりました。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月20日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-transcribe-germany/](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-transcribe-germany/)

## 概要

<p>Amazon Transcribeは、AWSの欧州主権クラウド（ドイツ）リージョンで利用可能になりました。規制遵守とデータ主権要件のためにEU内にデータと運用を保持する必要がある顧客は、Region内の自動音声認識（ASR）を利用して音声をテキストに変換できます。</p> 
<p>Amazon Transcribeは、このリージョンで音声を文字起こしする2つの方法を提供します。バッチ文字起こしはAmazon S3に保存されているメディアファイルを処理し、ストリーミング文字起こしはリアルタイムでテキストを返します。</p>
