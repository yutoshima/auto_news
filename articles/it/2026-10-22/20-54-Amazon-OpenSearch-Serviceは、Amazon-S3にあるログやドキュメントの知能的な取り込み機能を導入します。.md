# Amazon OpenSearch Serviceは、Amazon S3にあるログやドキュメントの知能的な取り込み機能を導入します。

## 概要

<p>Amazon OpenSearch Serverless は現在、インテリジェント取り込みを提供しています。これは完全に管理された機能で、Amazon S3 に保存されたログや文書を Amazon OpenSearch Serverless (NextGen) コレクションの検索可能なコンテンツへ変換します。インテリジェント取り込みを使えば、AWS Management Console で数回のクリック、または単一の API 呼び出しで取り込みを設定でき、取り込みインフラの管理は不要です。インテリジェント取り込みは、観測可能性ログと JSON、NDJSON、および JSON 配列形式の構造化データをサポートします。</p>
