# Amazon Bedrock Managed Agentsは、OpenAIを搭載し、現在プレビューで利用可能です。

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月29日 21:10
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/09/bedrock-managed-agents-preview/](https://aws.amazon.com/about-aws/whats-new/2026/09/bedrock-managed-agents-preview/)

## 概要

AWSとOpenAIが共同開発した Bedrock Managed Agents（BMA）は、OpenAIのAgents API のカスタマイズ版を基盤とし、AWSネイティブで AWSリソースと統合されるよう設計されています。すでに使用しているアイデンティティ、権限、ガバナンス管理をそのまま活用しつつ、OpenAIモデル向けに最適化されたエージェントを、完全にAWS内で実行できるように構築できます。

BMA は、モデルが状態を保持し、ツールを選択・使用し、コードを実行し、複数のステップにわたる作業を調整する方法を管理します。
