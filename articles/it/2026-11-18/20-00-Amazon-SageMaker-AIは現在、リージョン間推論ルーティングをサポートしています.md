# Amazon SageMaker AIは現在、リージョン間推論ルーティングをサポートしています

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月18日 20:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/sagemaker-cross-region-routing/](https://aws.amazon.com/about-aws/whats-new/2026/11/sagemaker-cross-region-routing/)

## 概要

今日は、Amazon SageMaker AI がクロスリージョン推論ルーティングを発表します。これにより、あるリージョンの容量不足時にも推論アプリケーションの可用性を維持し、他の AWS リージョンおよび AWS アカウントにデプロイされたエンドポイントへリクエストを送ることができます。加速済みインスタンスで提供されるモデルは、単一のリージョンで容量の限界に達することがあり、エンドポイントの不健全化はエンドユーザーへのスロットリングやエラーにつながる可能性があります。以前は、チームはルーティング、ヘルスチェック、リトライロジックを自ら構築・維持する必要がありました。
