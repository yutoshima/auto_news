# Amazon RDSは現在、スナップショットごとの課金をサポートしています。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月02日 18:43
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-rds-per-snapshot-billing/](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-rds-per-snapshot-billing/)

## 概要

本日より、Amazon RDS は RDS スナップショットごとの課金をサポートします。スナップショットごとの課金により、各個別のスナップショットの費用を把握できます。

これまでは、RDS スナップショットの課金は Cost and Usage レポートおよび Cost Explorer でデータベースインスタンスレベルで集計されていました。つまり、スナップショットの課金を理解する際には、個々のスナップショットまで drill down して見ることはできず、データベースインスタンスの集計ビューしか確認できませんでした。現在は、各スナップショットごとに閲覧できるようになりました。
