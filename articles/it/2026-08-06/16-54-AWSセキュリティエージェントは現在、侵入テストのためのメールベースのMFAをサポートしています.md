# AWSセキュリティエージェントは現在、侵入テストのためのメールベースのMFAをサポートしています

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月06日 16:54
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/aws-security-agent-mfa/](https://aws.amazon.com/about-aws/whats-new/2026/08/aws-security-agent-mfa/)

## 概要

AWSセキュリティエージェント（現在は <a href="http://aws.amazon.com/continuum?refid=77f1fbea-4ad5-4c1d-b16e-e5634ca5086e">AWS Continuum</a> の一部）は、現在、ログイン手続きの一部としてメールベースの多要素認証（MFA）を利用するアプリケーションのペンテストを可能にします。以前は、メールで送信されるワンタイムコードや検証リンクを必要とするアプリケーションは、エージェントがそれらのメッセージを介在して取得する仕組みを持っていなかったため、自動化されたペンテストの対象外でした。今回のリリースにより、ペンテストの対象範囲が拡大されます。
