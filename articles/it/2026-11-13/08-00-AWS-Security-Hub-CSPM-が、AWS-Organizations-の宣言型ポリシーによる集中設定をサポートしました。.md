# AWS Security Hub CSPM が、AWS Organizations の宣言型ポリシーによる集中設定をサポートしました。

## 概要

<p><a href="https://aws.amazon.com/security-hub/cspm/">AWS Security Hub CSPM</a> は現在、AWS Organizations デクララティブポリシーをサポートしています。これを利用して、組織全体のすべてのアカウントとリージョンにわたって Security Hub CSPM を有効にし、有効にするセキュリティ基準とコントロールを定義できます。</p>
<p>ポリシーはすべてのアカウントとリージョンに広く適用することも、特定のアカウントとリージョンの組み合わせを対象にすることもできます。デクララティブポリシーは、各アカウントの設定を、アタッチされたポリシーと整合させるのに役立ちます。</p>
