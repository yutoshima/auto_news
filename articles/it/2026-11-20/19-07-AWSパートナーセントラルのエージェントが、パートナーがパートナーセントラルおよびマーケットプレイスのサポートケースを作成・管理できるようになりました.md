# AWSパートナーセントラルのエージェントが、パートナーがパートナーセントラルおよびマーケットプレイスのサポートケースを作成・管理できるようになりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月20日 19:07
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/partner-central-agents-support/](https://aws.amazon.com/about-aws/whats-new/2026/11/partner-central-agents-support/)

## 概要

AWS Partner Central Agents は、AWS Partners が AWS Partner Central および AWS Marketplace のサポートケースを1か所で作成・管理できるよう支援します。エージェントは24時間365日利用可能で、Partner Central のアカウント情報と AWS から提供される権威あるパートナー固有の知識を活用して、ほとんどの問い合わせを即座に解決します。問い合わせの中にサポートエンジニアが必要なものがあれば、エージェントが詳細を収集しケースを作成します。これにより、パートナーがサポートを探すのに費やす時間が削減され、サポートチームが必要とするコンテキストが提供されます。
