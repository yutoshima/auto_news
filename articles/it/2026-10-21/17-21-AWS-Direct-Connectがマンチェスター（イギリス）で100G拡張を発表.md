# AWS Direct Connectがマンチェスター（イギリス）で100G拡張を発表

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月21日 17:21
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/aws-direct-connect-100g-manchester/](https://aws.amazon.com/about-aws/whats-new/2026/10/aws-direct-connect-100g-manchester/)

## 概要

今日は、英国マンチェスター近郊の Equinix MA3 データセンターにある既存の AWS Direct Connect ロケーションで、MACsec 暗号化機能を備えた10 Gbps および100 Gbps の専用接続を拡張したことを AWS が発表しました。これにより、中国を除くすべての公開 AWS リージョン、AWS GovCloud リージョン、および AWS Local Zones への私設・直接ネットワークアクセスを構築できるようになりました。
