# Amazon EC2は現在、ImdsV1Enabled という CloudWatch 指標を公開しています

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月05日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/ec2-imdsv1enabled-cloudwatch-metric/](https://aws.amazon.com/about-aws/whats-new/2026/11/ec2-imdsv1enabled-cloudwatch-metric/)

## 概要

Amazon EC2 は現在、ImdsV1Enabled CloudWatch 指標をサポートしており、どの EC2 インスタンスがまだインスタンスメタデータサービスバージョン1（IMDSv1）を有効にしているかを把握できます。この指標を使用して、アカウントとリージョン全体での IMDSv2 への移行状況を規模のある状態で追跡できます。

ImdsV1Enabled 指標を用いると、IMDSv1 をまだ許可しているインスタンスを追跡するための CloudWatch ダッシュボードとアラームを設定し、移行ギャップを特定し、是正処置の優先順位を決定できます。
