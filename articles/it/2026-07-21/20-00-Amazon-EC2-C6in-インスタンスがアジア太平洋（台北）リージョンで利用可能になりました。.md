# Amazon EC2 C6in インスタンスがアジア太平洋（台北）リージョンで利用可能になりました。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年07月21日 20:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/07/amazon-ec2-c6in/](https://aws.amazon.com/about-aws/whats-new/2026/07/amazon-ec2-c6in/)

## 概要

本日より、Amazon Elastic Compute Cloud（Amazon EC2）C6in インスタンスが AWS アジア太平洋（台北）で利用可能になりました。第六世代のネットワーク最適化インスタンスで、3世代Intel Xeon Scalable プロセッサを搭載し、AWS Nitro System 上に構築されており、最大200Gbpsのネットワーク帯域幅を提供します。これにより、同等の第5世代インスタンスと比べてネットワーク帯域幅が2倍になります。顧客はC6inインスタンスを使用してネットワークを拡張できます。
