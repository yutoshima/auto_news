# AWS Lambda、Node.js 26およびPython 3.15の公開プレビューで管理ランタイムを導入

## 概要

今日は、AWS Lambda がパブリックプレビューでマネージドランタイムを開始します。まずは Node.js 26 と Python 3.15 からです。これにより、顧客・パートナー・上流の言語コミュニティは、一般提供（GA）リリース前に今後のマネージドランタイムを試用し、Lambda チームへフィードバックを共有する機会を得られます。

以前は、Lambda のマネージドランタイムは GA リリースとして直接提供されていました。ランタイムはすぐに本番ワークロードで使用できるため、Lambda チームはフィードバックを取りまとめる機会を設ける余地がありませんでした。
