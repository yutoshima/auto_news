# Amazon MWAA Serverless で利用できる Apache Airflow UI

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月12日 18:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/airflow-ui-for-mwaa-serverless/](https://aws.amazon.com/about-aws/whats-new/2026/11/airflow-ui-for-mwaa-serverless/)

## 概要

Amazon MWAA Serverless は、ワークフロー用のネイティブ Apache Airflow UI を提供します。ワークフローをブラウズしたり、ワークフロー実行やタスクインスタンスを検査したり、タスクログを読了したり、ワークフローのソースとバージョンを表示したり、ワークフローランを開始したりできます。UI はそれを開く IAM アイデンティティの権限を使用して表示される情報を決定するため、読み取り専用アクセスも可能です。AWS CloudTrail は、UI がそのアイデンティティの下で行う呼び出しを記録します。

Amazon MWAA コンソールから Airflow UI を開くことができます。
