# AWS Secrets Manager は Cisco Security Platform と Netskope のマネージド外部シークレットサポートを追加します。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月25日 07:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/secrets-manager-cisco-netskope/](https://aws.amazon.com/about-aws/whats-new/2026/08/secrets-manager-cisco-netskope/)

## 概要

AWS Secrets Manager は、Cisco Security Platform API キーと Netskope API トークンを含む、マネージド外部シークレット機能を拡張しました。これにより、カスタムのローテーションコードを書くことなく、AWS コンソールから直接これらのサードパーティ認証情報を自動でローテーションできます。

Cisco Security Platform（Security Cloud Control）の場合、Secrets Manager はあなたのスケジュールに従って API キーのリフレッシュトークンをローテーションし、認証情報をアクティブな状態に保ち、Cisco が定期的に新しいリフレッシュトークンを取得します。
