# Amazon Timestream for InfluxDB 3は、異種クラスタをサポートします

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月27日 22:30
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/influxdb-heterogeneous-cluster/](https://aws.amazon.com/about-aws/whats-new/2026/11/influxdb-heterogeneous-cluster/)

## 概要

<p>Amazon Timestream for InfluxDB 3は、異種混合クラスタをサポートするようになりました。これにより、InfluxDB 3 Enterpriseクラスタの各ノードロールに異なるインスタンスサイズを割り当てることができます。ライター、リーダー、コンパクタの各ロールを個別にサイズ設定できます。クラスタを作成する時、または既存クラスタにノードを追加する時に、各ロールのサイズを設定します。設定は、Amazon Timestreamコンソール、AWS CLI、またはAWS SDKを使って行います。</p> 
<p>時系列ワークロードはデータベースのすべての部分を常に負荷するわけではありません</p>
