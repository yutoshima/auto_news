# Amazon MWAAは現在、DuckDBオペレーターをサポートしています

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月09日 18:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-mwaa-supports-duckdb-operators/](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-mwaa-supports-duckdb-operators/)

## 概要

<p>Amazon Managed Workflows for Apache Airflow（Amazon MWAA）は、DuckDBオペレーターを新たにサポートしました。DuckDBは組み込み型の分析データベースで、DuckDBがサポートするデータソース（例：Amazon S3）からデータの品質チェック、要約、変換を実行することができます。</p>
<p>DuckDBのネイティブサポートは、Apache Airflow 3.3.1を実行しているAmazon MWAA Provisioned環境で利用可能です。最新のMWAA Airflow 3.3.1アップデートには、DuckDBが事前インストール済み・AWS接続用に事前設定済みで含まれています。</p>
