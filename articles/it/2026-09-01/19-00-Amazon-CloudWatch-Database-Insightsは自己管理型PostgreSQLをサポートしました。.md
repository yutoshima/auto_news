# Amazon CloudWatch Database Insightsは自己管理型PostgreSQLをサポートしました。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月01日 19:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/database-insights-self-managed-postgresql/](https://aws.amazon.com/about-aws/whats-new/2026/08/database-insights-self-managed-postgresql/)

## 概要

今日は、自己管理の PostgreSQL データベースを Amazon CloudWatch Database Insights でサポートすることを AWS が発表します。CloudWatch Database Insights を使用すると、Amazon EC2 上で実行されている自己管理の PostgreSQL インスタンスを、Amazon RDS および Amazon Aurora とともに監視し、データベースフリートの全体像を1つのコンソールで把握できるようになります。

Amazon CloudWatch Database Insights は、データベースの可観測性ソリューションであり、データベースフリートの健全性を監視するためのキュレーションされた体験を提供します。
