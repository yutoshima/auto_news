# Amazon EC2 C8g インスタンス、追加のリージョンで利用可能に

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月04日 18:57
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-ec2-c8g-instances-additional-regions/](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-ec2-c8g-instances-additional-regions/)

## 概要

本日から、Amazon Elastic Compute Cloud（Amazon EC2）の C8g インスタンスが、AWS Europe（パリ）、AWS Africa（ケープタウン）、AWS Israel（テルアビブ）、AWS Canada West（カルガリー）リージョンで利用可能になります。これらのインスタンスは AWS Graviton4 プロセッサを搭載し、AWS Graviton3 ベースのインスタンスと比べて最大で 30% の性能向上を実現します。Amazon EC2 C8g インスタンスは、ハイパフォーマンスコンピューティング（HPC）やバッチ処理、ゲーム、ビデオエンコード、科学計算など、計算集約型ワークロード向けに設計されています。
