# Amazon EC2 Capacity Manager の新機能

## メタデータ

- **カテゴリ**: it
- **公開日時**: 2026年11月04日 07:00

## 概要

<p>Amazon EC2 Capacity Managerは現在、リアルタイムのサポート性チェックと容量充足メトリクスを提供します。リアルタイムのサポート性チェックは、インスタンスタイプと可用性ゾーンがリクエストをどれだけ適切にサポートできるかをスコア化して、インスタンスを起動または予約することなく容量を見つけるのに役立ちます。容量充足メトリクスは、要求された量に対して実際に提供された容量を示します。</p> 
<p>数千ものワークロードを数百のアカウントにまたがって実行するグローバル企業は、しばしばそれぞれを分散させます</p>
