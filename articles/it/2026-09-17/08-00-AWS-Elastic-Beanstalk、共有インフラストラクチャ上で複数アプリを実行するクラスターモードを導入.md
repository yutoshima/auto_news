# AWS Elastic Beanstalk、共有インフラストラクチャ上で複数アプリを実行するクラスターモードを導入

- **カテゴリ**: it
- **公開日時**: 2026年09月17日 08:00

## 概要

AWS Elastic Beanstalk は、同じアカウントの共有インフラストラクチャ上で複数のアプリケーションを実行・管理できる新しいデプロイメントモード「Cluster Mode」を導入します。ソースコード、Dockerfile、または Amazon ECR のコンテナイメージを提供すれば、Elastic Beanstalk がコンテナ化、プロビジョニング、継続的な運用を行い、既に使っているコンソール・CLI・API から管理できます。さらに、Elastic Beanstalk の新しい GitHub Action により、CI/CD パイプラインの一部としてリポジトリから直接アプリケーションをデプロイします。
