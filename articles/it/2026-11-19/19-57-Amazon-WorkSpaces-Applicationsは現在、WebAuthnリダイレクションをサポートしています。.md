# Amazon WorkSpaces Applicationsは現在、WebAuthnリダイレクションをサポートしています。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月19日 19:57
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-workspaces-applications-webauthn-redirection/](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-workspaces-applications-webauthn-redirection/)

## 概要

<p>Amazon WorkSpaces Applications は WebAuthn リダイレクションをサポートするようになり、ユーザーはストリーミング セッション内のウェブサイトやアプリケーションに、セキュリティ キー、Windows Hello、または Touch ID などのローカルデバイス上の FIDO2 認証機器を使用してサインインできるようになりました。従来は、ユーザーのコンピューターに接続された認証機器はストリーミング セッション内で利用できなかったため、フィッシング対策が強化された多要素認証（MFA）が必要な組織は、より弱いサインイン方法を使用するか、これらのアプリケーションを維持する必要がありました。
