# コロンビア・ボゴタに新しい AWS Local Zone の一般提供開始を発表

- **カテゴリ**: it

## 概要

今日は、コロンビアのボゴタに新しい Local Zone の GA（一般提供開始）を発表します。これにより、エンドユーザーに近い場所で AWS のインフラを提供し、単一桁ミリ秒の遅延を必要とするアプリケーションに対応します。ボゴタ Local Zone は、リアルタイムゲーム、ライブ動画ストリーミング、医療画像処理、金融取引処理などのワークロードに利用できます。

AWS Local Zones は、計算処理、ストレージ、ネットワーキング、その他の選択された AWS サービスを大都市圏の近くに配置するインフラストラクチャ展開です。
