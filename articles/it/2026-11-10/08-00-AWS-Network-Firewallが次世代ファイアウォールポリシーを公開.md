# AWS Network Firewallが次世代ファイアウォールポリシーを公開

## 概要

<p>本日、AWSは「次世代ファイアウォール（NGFW）ポリシー」を発表します。これは、セキュリティチームにとってよりシンプルなポリシー構造と拡張されたルール容量を提供する新しいポリシーモデルです。AWS Network Firewallは、アクセス制御と脅威検知でAmazon VPCを保護するマネージドネットワークセキュリティサービスです。</p>
<p>新しいポリシーモデルは、ファイアウォールとIPSの保護を組み合わせるのではなく、層状に配置することでセキュリティ体制を強化します。これによりポリシーの運用が容易になります。</p>
