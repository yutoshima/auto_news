# Amazon EC2 I8g インスタンスが AWS Europe (Paris)、Asia Pacific (Jakarta) リージョンで利用可能になりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月04日 16:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-ec2-i8g-instances-aws-paris-jakarta-regions/](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-ec2-i8g-instances-aws-paris-jakarta-regions/)

## 概要

AWSは、UTC Europe (Paris) および Asia Pacific (Jakarta) リージョンで、Amazon EC2 Storage Optimized I8g インスタンスの一般提供を発表します。I8g インスタンスは AWS Graviton4 プロセッサーを搭載し、ストレージ集約型ワークロードにおける Amazon EC2 の最高の計算性能を提供します。I8g インスタンスは第3世代 AWS Nitro SSD を使用する、ローカル NVMe ストレージで、TBあたりの実リアルタイムストレージ性能を最大65%向上させ、ストレージ I/O レイテンシを最大50%低く、さらに最大60%低く抑えます。
