# AWS Backupが、9つの追加AWSリージョンでAmazon DocumentDB向けのクロスリージョンバックアップコピーと論理的にエアギャップされたボールトをサポートします

- **カテゴリ**: it

## 概要

AWS Backupは現在、Amazon DocumentDBのバックアップをAWSリージョン間でコピーし、9つの追加AWSリージョンの論理的に空気の隔離されたボルトに保管することをサポートしています：アジア太平洋地域（香港、ジャカルタ、メルボルン、大阪）、ヨーロッパ地域（スペイン、ストックホルム、チューリッヒ）、アフリカ地域（ケープタウン）、イスラエル地域（テルアビブ）。

これらのリージョンでクロスリージョンコピーが利用可能になったことで、バックアップ計画やオンデマンドコピージョブを使用して、DocumentDBのバックアップをこれらのリージョンにコピーしたり、そこからコピーしたりすることができます。これにより、災害復旧やビジネス継続性の要件を満たすのに役立ちます。
