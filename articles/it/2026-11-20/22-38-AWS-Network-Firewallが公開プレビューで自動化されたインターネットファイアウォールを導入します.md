# AWS Network Firewallが公開プレビューで自動化されたインターネットファイアウォールを導入します

- **カテゴリ**: it

## 概要

AWS Network Firewallは、自動化インターネットファイアウォールの公開プレビューを発表します。これは、環境内のすべてのVPC（仮想プライベートクラウド）のインターネットゲートウェイに対して、ネイティブなネットワークアドレス変換（NAT）機能を備えたNetwork Firewallを一元的に構成できる新しい中央制御です。自動化インターネットファイアウォールモードを使用すると、Network Firewallのセキュリティルールを一元的に定義し、VPCのインターネットゲートウェイを通るすべての着信および発信トラフィックに適用することができます。
