# AWS Security Hub は、セキュリティ上の問題を優先付けして修正するリメディエーション計画を導入します。

## 概要

AWS Security Hubは現在、根本原因を共有する関連する露出所見をグループ化する是正計画を提供しています。個々の露出を個別に対処する代わりに、誤設定された設定や過度に許可的なポリシーなど、単一の根本的なリソースを修正することで、複数の露出の重大度を一度に解決または低減できます。

各是正計画には、優先度の指針（Critical、High、Medium、Low）、影響評価、例を含む詳細な手順とステップバイステップの指示が含まれています。
