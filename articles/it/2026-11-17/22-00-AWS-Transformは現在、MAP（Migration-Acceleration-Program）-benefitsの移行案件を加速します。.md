# AWS Transformは現在、MAP（Migration Acceleration Program） benefitsの移行案件を加速します。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月17日 22:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/map-integration-with-aws-transform/](https://aws.amazon.com/about-aws/whats-new/2026/11/map-integration-with-aws-transform/)

## 概要

AWSパートナーは、MAP（Migration Acceleration Program）案件を、資格付与からインセンティブ支払いまで、AWS Transform内のエンドツーエンドの代理業務フローで迅速化できます。パートナーは、取引の資格付与、資金承認、契約締結、移行計画と実行、リソースのタグ付け、インセンティブの支払いを含む、MAPライフサイクル全体をAWS Transformを離れることなく管理できます。

従来、パートナーは機会発見や評価のために別々のシステムを行き来する必要がありました。
