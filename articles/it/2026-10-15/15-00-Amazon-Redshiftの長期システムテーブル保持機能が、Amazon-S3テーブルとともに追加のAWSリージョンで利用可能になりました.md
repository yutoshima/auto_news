# Amazon Redshiftの長期システムテーブル保持機能が、Amazon S3テーブルとともに追加のAWSリージョンで利用可能になりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月15日 15:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/redshift-long-term-system-table-retention-expansion/](https://aws.amazon.com/about-aws/whats-new/2026/10/redshift-long-term-system-table-retention-expansion/)

## 概要

<p><a href="https://aws.amazon.com/redshift/">Amazon Redshift</a> のシステムテーブルデータの長期保持を、ネイティブ統合された <a href="https://aws.amazon.com/s3/features/tables/">Amazon S3 Tables</a> を通じて、追加の AWS リージョンで利用可能になりました。この機能を使うと、現在の7日間の制限を超えるシステムテーブルデータの保持期間を設定し、コンプライアンス、監査、可観測性の要件を満たすことができます。設定を有効にすると、AWS が自動的にシステムテーブルデータを S3 に書き込みます。
