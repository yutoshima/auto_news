## 概要

AWS Security Hubのネットワークスキャン機能は、AWS GovCloud (US) でのサポートを開始しました。  
ネットワークスキャンは、セキュリティグループのルールやルートテーブルだけで「到達可能になり得る」範囲ではなく、インターネットからリソースをスキャンして実際の到達可能性を検出します。公開IPアドレス、仮想マシン、ロードバランサーを横断して探し出し、到達可能なポートを特定し、それらの背後で実行されているサービスを判断します。これは、Security Hubの既存のネットワーク到達性機能を補完します。
