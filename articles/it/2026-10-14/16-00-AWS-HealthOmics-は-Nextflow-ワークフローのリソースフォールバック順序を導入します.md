# AWS HealthOmics は Nextflow ワークフローのリソースフォールバック順序を導入します

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月14日 16:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/aws-healthomics-resource-fallback-for-Nextflow/](https://aws.amazon.com/about-aws/whats-new/2026/10/aws-healthomics-resource-fallback-for-Nextflow/)

## 概要

本日、AWS HealthOmics は Nextflow ワークフロー内のタスクに対するリソースフォールバック指示を導入します。これにより、CPU インスタンスへのフォールバックを含む、好みのアクセラレータ型の有序リストを定義できます。研究者やバイオインフォーマーはこの指示を用いて、アクセラレータの制約による診断や再送信に要する時間を短縮し、生産性の高いワークフローの運用を維持できます。<a href="https://aws.amazon.com/healthomics/">AWS HealthOmics</a> は HIPAA に適合したサービスです。
