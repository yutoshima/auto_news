# AWS HealthOmics、プライベートワークフロー向けのコンテナレジストリサポートを拡張

## 概要

サードパーティのコンテナレジストリに拡張されたサポートにより、Seqera（Wave）、NVIDIA NGC、Google Artifact Registry などのレジストリからのコンテナイメージを AWS HealthOmics で利用できるようになりました。画像を Amazon ECR に手動で移行したり、ワークフロー定義を編集したりすることなく、ワークフローがすでに依存しているコンテナ化ツールを使用できます。 AWS HealthOmics は HIPAA 準拠のサービスで、医療・ライフサイエンス分野の顧客を支援します。
