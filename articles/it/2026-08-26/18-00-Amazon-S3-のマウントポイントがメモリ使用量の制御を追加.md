# Amazon S3 のマウントポイントがメモリ使用量の制御を追加

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月26日 18:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/mountpoint-for-S3-adds-memory-usage-controls](https://aws.amazon.com/about-aws/whats-new/2026/08/mountpoint-for-S3-adds-memory-usage-controls)

## 概要

<p>Amazon S3のマウントポイントは、実行環境に基づいて自動的に、またはユーザーが定義する制限で、メモリ使用量を制限できるようになりました。これにより、機械学習のトレーニングや分析ワークロードなど、メモリを多く消費するアプリケーションと同時にMountpointを実行し、メモリ予算を共有することが可能になります。</p> 
<p>以前は、Mountpointのメモリ使用量が時間とともに使用パターンに基づいて増える可能性があり、他のアプリケーションと競合する際にパフォーマンスや安定性の問題を引き起こすことがありました。</p>
