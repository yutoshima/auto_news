# Amazon Aurora MySQL 8.4.8（MySQL 8.4.8 と互換性あり）が一般利用可能になりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月03日 16:01
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-aurora-mysql-848-available/](https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-aurora-mysql-848-available/)

## 概要

本日より、Amazon Aurora MySQL-互換エディション 8.4 は MySQL 8.4.8 をサポートします。いくつかのセキュリティ強化とバグ修正に加え、Aurora MySQL 8.4.8 には、ポスト量子 TLS（PQ-TLS）鍵交換、トランザクションのタイムアウト、マルチソースレプリケーション、遅延レプリケーションなどの改善が含まれています。PQ-TLS は、データの転送中の暗号化オプションとしてポスト量子暗号を提供します。トランザクションのタイムアウトは、長時間実行されることによって発生するパフォーマンスの問題を防ぐのに役立ちます。
