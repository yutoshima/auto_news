# Amazon FSx for NetApp ONTAP が、バックアップを他のAWSリージョンおよびアカウント間でコピーすることをサポートしました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月27日 17:37
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/fsx-ontap-cross-region-backup-copy/](https://aws.amazon.com/about-aws/whats-new/2026/08/fsx-ontap-cross-region-backup-copy/)

## 概要

<p>NetAppのONTPファイルシステムで構築された完全に管理された共有ストレージサービスであるAmazon FSx for NetApp ONTAPは、AWSリージョン間および同一組織の信頼済みアカウント間でのバックアップのコピーをサポートするようになりました。これにより、主バックアップとは別のリージョンまたはアカウントに二次バックアップを保存する追加の保護層を提供でき、事業継続性、データ保護、コンプライアンス要件を満たしやすくなります。</p>
