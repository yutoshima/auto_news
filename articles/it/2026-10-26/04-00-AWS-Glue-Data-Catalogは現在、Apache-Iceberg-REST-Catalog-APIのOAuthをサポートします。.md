# AWS Glue Data Catalogは現在、Apache Iceberg REST Catalog APIのOAuthをサポートします。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月26日 04:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/glue-catalog-oauth-iceberg-rest/](https://aws.amazon.com/about-aws/whats-new/2026/10/glue-catalog-oauth-iceberg-rest/)

## 概要

<p>AWS Glue Data Catalog は、AWS Sign-In を使用した Apache Iceberg REST Catalog (IRC) API に対する OAuth 2.0 ベアラ トークン認証をサポートします。Apache Iceberg REST Catalog の仕様では OAuth 2.0 を標準認証機構として定義しており、Apache Spark、Trino、Apache Flink などのクエリエンジンはそれをネイティブに実装しています。これらのエンジンと外部統合パートナーは、AWS に加えて、標準の OAuth 2.0 ベアラ トークンを使用して Glue Data Catalog Iceberg エンドポイントへ認証することが可能です。
