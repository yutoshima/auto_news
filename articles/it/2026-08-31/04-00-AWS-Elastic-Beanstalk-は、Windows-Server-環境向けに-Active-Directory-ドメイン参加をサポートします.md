# AWS Elastic Beanstalk は、Windows Server 環境向けに Active Directory ドメイン参加をサポートします

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月31日 04:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/elastic-beanstalk-active-directory-domain-join/](https://aws.amazon.com/about-aws/whats-new/2026/08/elastic-beanstalk-active-directory-domain-join/)

## 概要

AWS Elastic Beanstalk は、環境内の Windows Server インスタンスを、AWS Directory Service で管理する Active Directory ドメインに自動的に参加させるようになりました。従来、Elastic Beanstalk 上でドメイン参加済みの Windows ワークロードを実行するには、維持管理が必要なカスタム参加スクリプトを使用する必要がありました。今回のリリースでは、いくつかの設定オプションを行うだけで、環境内のすべてのインスタンス（オートスケーリングで後から起動したインスタンスを含む）が、アプリケーションデプロイ前のブート時にドメインへ参加します。
