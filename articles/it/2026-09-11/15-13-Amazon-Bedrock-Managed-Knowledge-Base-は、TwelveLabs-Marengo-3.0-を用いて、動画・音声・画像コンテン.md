# Amazon Bedrock Managed Knowledge Base は、TwelveLabs Marengo 3.0 を用いて、動画・音声・画像コンテンツのマルチモーダル埋め込みをサポートします。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月11日 15:13
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-bedrock-managed-knowledge-base-multimodal-embeddings-twelvelabs-marengo/](https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-bedrock-managed-knowledge-base-multimodal-embeddings-twelvelabs-marengo/)

## 概要

AWSは、Amazon Bedrock Managed Knowledge Baseの埋め込みモデルとしてTwelveLabs Marengo 3.0を利用可能にしたと発表しました。これにより、動画・音声・画像コンテンツのマルチモーダルな埋め込みを作成できるようになります。Amazon Bedrock Managed Knowledge Baseはすでに音声・動画を文字へ転写してテキストベースの埋め込みを生成することでメディア検索をサポートしていますが、Marengo 3.0は視覚的シーン、発話、動画の手掛かりを直接マルチモーダル埋め込みへエンコードすることで、文字起こしだけでは捉えきれない意味を捉えます。
