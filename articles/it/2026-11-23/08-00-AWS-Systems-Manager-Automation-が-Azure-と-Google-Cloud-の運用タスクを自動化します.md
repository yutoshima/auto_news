## 概要

AWS Systems Manager Automationは、Microsoft Azure、Google Cloud、およびAWSリソース全体の運用タスクを自動化できるカスタムワークフロー（ランブック）を作成できるようになりました。Automationは、誤設定の修正や使用していないリソースのクリーンアップなど、規模をもって安全に変更を行うのに役立ちます。ランブックは、制御されたバッチで展開し、承認のために一時停止し、閾値を超えるエラーが発生すると停止することができます。各クラウドごとに別々のツールと認証情報を維持する代わりに、チームは現在、作成と実行を行うことができます。
