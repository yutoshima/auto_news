# AWS Secrets Manager、DatabricksとTwilio向けのマネージド外部シークレットサポートを追加

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月12日 07:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/secrets-manager-managed-external-secrets-databricks-twilio/](https://aws.amazon.com/about-aws/whats-new/2026/10/secrets-manager-managed-external-secrets-databricks-twilio/)

## 概要

AWS Secrets Manager は、Databricks と Twilio を含む外部シークレットの管理機能を拡張し、データパイプラインやメッセージングアプリケーションがこれらのサービスを呼び出す際に使用する認証情報を自動的にローテーションできるようにしました。ローテーションは、カスタムのローテーション Lambda 関数を作成・維持することなく、AWS Management Console または API から直接設定できます。

長寿命の認証情報は、ローテーションの設定が難しいことや、安全に配布することが難しいことから、長い間ローテーションされずに放置されることがあります。
