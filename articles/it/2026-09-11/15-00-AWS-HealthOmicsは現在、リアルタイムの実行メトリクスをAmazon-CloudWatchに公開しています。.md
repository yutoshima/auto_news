# AWS HealthOmicsは現在、リアルタイムの実行メトリクスをAmazon CloudWatchに公開しています。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月11日 15:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/09/aws-healthomics-realtime-run-metrics/](https://aws.amazon.com/about-aws/whats-new/2026/09/aws-healthomics-realtime-run-metrics/)

## 概要

AWS HealthOmicsは現在、実行中のワークフローのリソース使用状況を可視化できるリアルタイムの実行指標をAmazon CloudWatchに公開しています。新たに追加された14の実行指標は、CPUおよびGPUの使用率、メモリ使用量、ファイルシステム使用量とI/O指標、ネットワークスループット、エフェメラルストレージの使用量を網羅します。AWS HealthOmicsはHIPAA適格サービスであり、ヘルスケアおよびライフサイエンスのお客様が完全に管理された環境でスケールして科学的ブレークスルーを加速させるのを支援します。
