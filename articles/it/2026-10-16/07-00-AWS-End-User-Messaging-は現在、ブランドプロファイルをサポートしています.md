# AWS End User Messaging は現在、ブランドプロファイルをサポートしています

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月16日 07:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/aws-end-user-messaging-now-supports-brand-profiles](https://aws.amazon.com/about-aws/whats-new/2026/10/aws-end-user-messaging-now-supports-brand-profiles)

## 概要

本日、AWS End User Messaging は Brand Profiles（ブランド・プロファイル）を発表します。これにより、ブランドや会社情報を一度保存して、メッセージ登録の across で再利用できます。SMS、RCS、WhatsApp でメッセージを送信するには、キャリアやメッセージ提供者にブランドを登録しますが、現在は各チャネルと国ごとに、同じ会社情報・住所・連絡先・ユースケースを手動で入力する必要があります。その繰り返し入力は新しい登録のたびに遅延を生み、誤入力やその他のエラーを招く可能性があります。
