# AWS Agent Registryは、4つの追加のAWSリージョンで利用可能になりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月28日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/aws-agent-registry-four-regions/](https://aws.amazon.com/about-aws/whats-new/2026/10/aws-agent-registry-four-regions/)

## 概要

AWS Agent Registryは、Amazon Bedrock AgentCoreを通じて利用可能で、以下の4つの追加AWSリージョンで提供開始されました：ヨーロッパ（ロンドン）eu-west-2、ヨーロッパ（フランクフルト）eu-central-1、US東部（オハイオ）us-east-2、カナダ（中部）ca-central-1。

AWS Agent Registryは、組織全体のリソースを整理・キュレーション・発見するための中央ディスカバリサービスを提供する、完全管理型のリソースカタログです。AWS Agent Registryを使用すると、MCPサーバー、ツール、エージェント、エージェントスキルなどを公開できます。
