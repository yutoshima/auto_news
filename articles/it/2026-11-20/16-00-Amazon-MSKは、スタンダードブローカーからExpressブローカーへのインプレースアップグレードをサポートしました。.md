# Amazon MSKは、スタンダードブローカーからExpressブローカーへのインプレースアップグレードをサポートしました。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月20日 16:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-msk-standard-brokers-to-express-brokers-in-place-upgrade](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-msk-standard-brokers-to-express-brokers-in-place-upgrade)

## 概要

既存の <a href="https://aws.amazon.com/msk/">Amazon MSK</a> Provisioned クラスターを、現行のブローカーを置換する形で、データの完全マイグレーションとアプリケーション変更不要で、標準ブローカーから Express ブローカーへインプレースでアップグレードできます。Express ブローカーは、1ブローカーあたり最大3倍のスループット、最大20倍のスケールアウト速度、最大90%の回復速度向上を実現するよう設計されています。インプレースアップグレードにより、Express ブローカーのパフォーマンスと運用上の利点を、数時間で得ることができます。
