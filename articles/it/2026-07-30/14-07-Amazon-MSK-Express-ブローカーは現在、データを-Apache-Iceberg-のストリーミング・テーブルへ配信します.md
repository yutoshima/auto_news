# Amazon MSK Express ブローカーは現在、データを Apache Iceberg のストリーミング・テーブルへ配信します

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年07月30日 14:07
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/07/aws-msk-streaming-tables-for-apache-iceberg](https://aws.amazon.com/about-aws/whats-new/2026/07/aws-msk-streaming-tables-for-apache-iceberg)

## 概要

Amazon MSK Express brokers は、Apache Iceberg のストリーミングテーブルへデータを提供します。これは、Apache Kafka トピックを Amazon S3 の Apache Iceberg テーブルとして継続的に materialize する新機能です。Amazon MSK のデータ配信をストリーミングテーブルへ行うことで、自己管理デプロイメントと比較して Amazon S3 Tables へのデータ取り込みと提供のコストを最大で約60%削減し、下流のクエリ費用も削減します。
