# Amazon Kinesis Data Streams が、ウォームスループットを利用して取り込み容量をスケールダウンできるようになりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年07月24日 18:55
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/07/kinesis/on-demand-scale-down](https://aws.amazon.com/about-aws/whats-new/2026/07/kinesis/on-demand-scale-down)

## 概要

<p>Amazon Kinesis Data Streams は、サーバーレスのストリーミングデータサービスで、データストリームを任意の規模で簡単に取り込み、処理、保存できるようにします。オンデマンドストリームは、データ取り込みの使用量が増加した際に取り込み能力を自動的に拡張します。オンデマンド・アドバンテージモードでは、暖流 throughput を活用して、データトラフィックの急な変化に備えるためにストリーム容量を前もって管理することができます。暖流 throughput の拡張に加え、取り込み容量を縮小することも可能にすることで、完全な協調運用を実現します。
