## 概要

AWS Lambda は現在、自己運用の Apache Kafka クラスターや Confluent Cloud のようなマネージド提供に対して、自己管理型 Kafka イベントソースマッピング（ESM）で「Kafka のキュー」をサポートしています。顧客はこれにより、トピックのパーティション数を超える Kafka ワークロードの処理を拡張し、スループットを向上させることができます。
