# AWS STS は現在、AWS アイデンティティのためのクロスパーティション・フェデレーションをサポートしています

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月09日 20:03
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/aws-sts-cross-partition](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-sts-cross-partition)

## 概要

AWS Security Token Service (AWS STS)を使えば、ワークロードが同じパーティション内のIAMアイデンティティを利用して、別のパーティションにあるIAMロールの一時的な認証情報を取得できるようになります。長期認証情報を保管する必要がなく、セキュリティ姿勢の向上に役立ちます。パーティションは、商用地域と AWS GovCloud (US) Regions などの AWS Regionsのグループです。
