# Amazon Redshiftのrg.largeインスタンスが、シングルノードクラスターをサポートしました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月03日 16:03
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/09/redshift-rg-large-single-node](https://aws.amazon.com/about-aws/whats-new/2026/09/redshift-rg-large-single-node)

## 概要

<p>Amazon Redshift rg.large インスタンスは、AWS Graviton プロセッサを搭載し、単一ノードクラスタをサポートできるようになりました。rg.large クラスタの単一ノード対応は P204 以降のパッチバージョンで利用可能です。これにより、可用性を高める必要のない小規模なワークロード向けに、コスト効果の高い選択肢として、概念実証やテストを迅速に実施できる単一ノードの rg.large クラスタを作成できます。</p> 
<p>RG インスタンスは、データウェアハウスおよびデータレイクのワークロードを最大2.4倍の速度で実行します。</p>
