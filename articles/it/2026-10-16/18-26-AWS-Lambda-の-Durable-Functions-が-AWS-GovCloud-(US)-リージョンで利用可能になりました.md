# AWS Lambda の Durable Functions が AWS GovCloud (US) リージョンで利用可能になりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月16日 18:26
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/durablefunctions-govcloud/](https://aws.amazon.com/about-aws/whats-new/2026/10/durablefunctions-govcloud/)

## 概要

AWS Lambda の耐久性関数が、AWS GovCloud (US-West) および AWS GovCloud (US-East) リージョンで利用可能になりました。耐久性関数を使うと、Lambda 開発者エクスペリエンス内で信頼性の高い多段階アプリケーションや AI ワークフローを構築できます。

耐久性関数は、イベントハンドラ内の新しいプリミティブ（例：”step” や ”wait”）などを追加することで、進捗のチェックポイント作成、障害からの自動回復、実行の一時停止を実現します。
