# AWS Glue、Apache Spark ジョブの自動バージョンアップグレードを発表

- **カテゴリ**: it

## 概要

<p>AWS Glue は自動バージョンアップグレードを導入しており、手動の調整なしに Apache Spark ジョブを最新の AWS Glue ランタイムへ自動的に更新します。サポートされるランタイムの最新化を維持することで、ジョブには最新のセキュリティパッチ、パフォーマンスの向上、Apache Iceberg などの進化するテーブル形式への対応が提供されます。自動アップグレードには、アップグレード済みランタイムとの互換性をジョブで評価することや、実行前に同意を得ることを含む複数レベルの検証が含まれます。
