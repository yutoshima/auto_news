# Amazon Bedrock Managed Knowledge Base は、ドキュメント単位のアクセス制御のデバッグを支援する API とコンソールのサポートを追加します。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月09日 16:03
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-bedrock-knowledge-base-debugging-document-access-control/](https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-bedrock-knowledge-base-debugging-document-access-control/)

## 概要

AWSは、Amazon Bedrock Managed Knowledge Base向けのCheckIngestedDocumentAclおよびGetIngestedDocumentAcl APIを発表しました。これにより、顧客はドキュメントアクセスの問題を自己解決でデバッグし、ドキュメントレベルの権限を監査することができます。ACL対応データソースの取得結果に期待するドキュメントが表示されない場合、原因がアクセス制御の設定ミスなのか、それとも別の問題なのかを判断するのは難しいことがあります。これらの新しいAPIと、それに伴うコンソール体験は、そのギャップを埋めます。
