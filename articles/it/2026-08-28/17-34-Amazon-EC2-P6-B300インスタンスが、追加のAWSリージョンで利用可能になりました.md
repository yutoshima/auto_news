# Amazon EC2 P6-B300インスタンスが、追加のAWSリージョンで利用可能になりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月28日 17:34
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-ec2-p6-b300-instances-available-additional-regions](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-ec2-p6-b300-instances-available-additional-regions)

## 概要

本日より、Amazon Elastic Cloud Compute（Amazon EC2）P6-B300インスタンスがアジア太平洋地域（ハイデラバード）および南米地域（サンパウロ）で利用可能になります。P6-B300インスタンスは、8基のNVIDIA Blackwell Ultra GPU、2.1 TBの高帯域幅GPUメモリ、6.4 TbpsのEFAネットワーキング、300 Gbpsの専用ENAスループット、そして4 TBのシステムメモリを提供します。

P6-B300インスタンスは、P6-B200インスタンスと比較して、ネットワーク帯域幅を2倍、GPUメモリ容量を1.5倍、FP4（スパース性なし）時のGPUTFLOPSを1.5倍にしています。
