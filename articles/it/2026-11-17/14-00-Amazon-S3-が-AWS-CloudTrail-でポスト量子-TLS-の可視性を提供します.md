# Amazon S3 が AWS CloudTrail でポスト量子 TLS の可視性を提供します

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月17日 14:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-s3-post-quantum-tls-aws-cloudtrail/](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-s3-post-quantum-tls-aws-cloudtrail/)

## 概要

<p>Amazon S3は現在、S3リクエストのAWS CloudTrailにTLS鍵交換アルゴリズムを記録しているため、どのリクエストとクライアントがポスト量子TLS（PQ-TLS）を使用しているかを確認できます。 この可視性により、PQ暗号化で保護されているS3トラフィックの割合を測定し、古典的な鍵交換で接続しておりアップグレードが必要なアプリケーション、SDKのバージョン、およびIAMプリンシパルを特定できます。</p> 
<p>CloudTrailの管理対象のtlsDetailsフィールドに新しいkeyExchange値があります</p>
