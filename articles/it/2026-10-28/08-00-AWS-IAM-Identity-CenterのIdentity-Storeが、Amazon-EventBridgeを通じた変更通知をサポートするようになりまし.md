# AWS IAM Identity CenterのIdentity Storeが、Amazon EventBridgeを通じた変更通知をサポートするようになりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月28日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/aws-identity-store-change-notifications/](https://aws.amazon.com/about-aws/whats-new/2026/10/aws-identity-store-change-notifications/)

## 概要

AWS IAM Identity Center の Identity Store が、ユーザー・グループ・グループ membership、または Identity Store 自体が作成・更新・削除されたときに、リアルタイムイベントを Amazon EventBridge に配信するようになりました。AWS IAM Identity Center Identity Store は、複数の AWS アカウントやアプリケーションに跨るアイデンティティとアクセスを一元管理できるリポジトリで、AWS IAM Identity Center のアイデンティティソースとして機能します。この新機能により、アイデンティティのライフサイクルイベントに自動で対応し、サポートを強化します。
