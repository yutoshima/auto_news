# AWS Elemental MediaConnect Routerは現在、高ビットレートモードをサポートしています

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月19日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/mediaconnect-router-high-bitrate/](https://aws.amazon.com/about-aws/whats-new/2026/10/mediaconnect-router-high-bitrate/)

## 概要

AWS Elemental MediaConnect Routerは、250 Mbpsと500 Mbpsの2つの新しい tierで高ビットレートモードをサポートします。これにより、品質や信頼性を損なうことなく高ビットレートを必要とするプロの放送局が高価値コンテンツを輸送できます。

この機能強化により、放送寄与、コンテンツ配信、リモート制作のためのVSF TR-07準拢のトランスポートストリーム配信など、業界標準のワークフローが可能になります。ハイビットレートモードは、最大2つの冗長ソースをサポートします。
