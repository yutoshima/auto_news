# Amazon SageMaker Unified Studioは現在、データプロファイリングと異常検知をサポートします

## 概要

Amazon SageMaker Unified Studio は現在、AWS Glue Data Quality を活用したデータプロファイリングと異常検出をサポートしています。データ・スチュワード、エンジニア、アナリストは、データの形状と完全性を把握し、これらの統計が時間とともにどのように変化するかを追跡するための統計プロファイルを生成できます。異常検出は、事前に定義された閾値やカスタムルールを必要とせず、データポイントが過去のパターンから逸脱しているかを識別するのに役立ちます。これらの機能は、カタログ内の静止データとともに利用可能です。
