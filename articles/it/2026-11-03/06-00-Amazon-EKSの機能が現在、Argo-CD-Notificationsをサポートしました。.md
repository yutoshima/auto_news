# Amazon EKSの機能が現在、Argo CD Notificationsをサポートしました。

- **カテゴリ**: it
- **公開日時**: 2026年11月03日 06:00

## 概要

<p>Amazon Elastic Kubernetes Service（Amazon EKS） Capability for Argo CDは、Argo CD Notificationsをサポートするようになり、アプリケーションが同期されたとき、失敗したとき、またはヘルスが変化したときに通知を提供します。トリガーとメッセージテンプレートをクラスター内で定義し、アップストリームのArgo CDと同様にアノテーションを付けて個別のアプリケーションを購読します。</p> 
<p>このリリースにより、Slack、PagerDuty、Opsgenie、Amazon SQS、Amazon EventBridge などを含む16の通知サービスに通知を配信できるようになります。</p>
