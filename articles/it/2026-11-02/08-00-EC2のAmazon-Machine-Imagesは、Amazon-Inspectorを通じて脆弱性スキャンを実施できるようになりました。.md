# EC2のAmazon Machine Imagesは、Amazon Inspectorを通じて脆弱性スキャンを実施できるようになりました。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月02日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/ec2-amis-scanned-through-inspector/](https://aws.amazon.com/about-aws/whats-new/2026/11/ec2-amis-scanned-through-inspector/)

## 概要

<p>Amazon Inspectorは脆弱性スキャンをEC2用のAmazon Machine Images（AMIs）にも拡張し、インスタンスを起動したり追加ソフトウェアをインストールしたりすることなく、AMIsに含まれるソフトウェアの脆弱性を特定できるようになりました。これにより、AMIsがフリート全体のインスタンスを起動する前に、根源的な問題を修正できます。</p>
<p>この機能を使えば、継続的な評価を実行してAMIカタログに新たに発見された脆弱性を監視したり、特定の目的に対して一度限りのスキャンを実施したりできます。</p>
