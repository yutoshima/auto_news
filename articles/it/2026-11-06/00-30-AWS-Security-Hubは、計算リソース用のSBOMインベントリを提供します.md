# AWS Security Hubは、計算リソース用のSBOMインベントリを提供します

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月06日 00:30
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/security-hub-sbom-inventory/](https://aws.amazon.com/about-aws/whats-new/2026/11/security-hub-sbom-inventory/)

## 概要

本日、AWSは AWS Security Hub がソフトウェア部品表（SBOM）インベントリを提供するようになり、中央のセキュリティチームが組織全体のコンピュートリソースにインストールされたソフトウェアパッケージやアプリケーションを継続的に更新されるビューで確認できるようになったと発表しました。

Security Hub は、Amazon Inspector が Amazon EC2 インスタンス、Amazon ECR コンテナイメージ、AWS Lambda 関数向けに生成する SBOM からインベントリを作成し、追加の設定は不要です。SBOM ページには各パッケージが一覧表示されます。
