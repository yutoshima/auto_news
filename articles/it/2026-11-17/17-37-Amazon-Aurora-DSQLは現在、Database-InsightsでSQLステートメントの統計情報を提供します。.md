# Amazon Aurora DSQLは現在、Database InsightsでSQLステートメントの統計情報を提供します。

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月17日 17:37

## 概要

<文><a href="https://aws.amazon.com/rds/aurora/dsql/">Amazon Aurora DSQL</a> は、クラスターが実行する各SQL文の統計情報を記録し、それらを Amazon CloudWatch OpenTelemetry (OTel) 指標として公開します。これらは Amazon CloudWatch Database Insights で閲覧できます。文ごとに、実行回数、所要時間、スキャン / 返却 / 変更される行数、使用する DPUs を確認できます。</文> 
<p>文の統計情報は、活動のサンプリングではなく、すべての成功した文を測定します。これらを使用してください</p>
