# AWS Key Management Serviceは現在、ポスト量子暗号化の鍵封筒化のためのML-KEMをサポートしています。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月26日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/kms-ml-kem-post-quantum/](https://aws.amazon.com/about-aws/whats-new/2026/10/kms-ml-kem-post-quantum/)

## 概要

AWS Key Management Service（KMS）は、NIST FIPS 203の下でのポスト量子暗号標準であるモジュール・ラティス基盤の鍵封じ込み機構（ML-KEM）をサポートするようになりました。ML-KEMは、2者が共通の秘密を確立できる機構です。NISTは、古典的な鍵確立方式であるDH/ECDHの鍵合意やRSAベースの鍵転送を、戦略的暗号設計ロードマップで置き換えるためにML-KEMを設計しました（詳細は以下を参照：https://csrc.nist.gov/）
