# AWS Glueが人気のSaaSアプリケーション向けのネイティブコネクタを100個追加しました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月09日 21:33
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/aws-glue-adds-100-new-native-connectors/](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-glue-adds-100-new-native-connectors/)

## 概要

AWS Glueは現在、人気のあるSaaSやREST APIベースのアプリケーションのデータへのアクセスを簡易化する100の新しいネイティブコネクタを提供しています。従来は、SaaSアプリケーションのデータをAWSに取り込むにはカスタムコードを作成する必要がありました。今後は、AWS Glue Data Catalogに1度接続を作成すれば、同じ権限モデルを使用している限り、ETLジョブ間で再利用できます。

新しいコネクタは、ジェネレーティブAI、金融、決済、マーケティング、プロダクト分析、人事、エンジニアリングなどの分野をカバーします。
