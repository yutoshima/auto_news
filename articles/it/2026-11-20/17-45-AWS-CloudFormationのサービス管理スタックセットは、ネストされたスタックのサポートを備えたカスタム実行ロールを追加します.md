# AWS CloudFormationのサービス管理スタックセットは、ネストされたスタックのサポートを備えたカスタム実行ロールを追加します

- **カテゴリ**: it
- **公開日時**: 2026年11月20日 17:45
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/stacksets-custom-execution-roles/](https://aws.amazon.com/about-aws/whats-new/2026/11/stacksets-custom-execution-roles/)

## 概要

<AWS CloudFormation StackSets> は現在、サービス管理スタックセット用のカスタム実行ロールをサポートしており、各ターゲット AWS アカウントで StackSets が使用する権限を限定できるようになりました。StackSets は、1 回の操作で数千のアカウントとリージョンにまたがる同じインフラストラクチャ（ネットワーク設定やセキュリティ設定 など）を展開します。カスタム実行ロールを使用して、展開に使われる権限を細かく制御できます。
