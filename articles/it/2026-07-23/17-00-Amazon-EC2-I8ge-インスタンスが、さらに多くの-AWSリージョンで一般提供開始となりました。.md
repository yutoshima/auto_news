# Amazon EC2 I8ge インスタンスが、さらに多くの AWSリージョンで一般提供開始となりました。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年07月23日 17:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/07/aws-i8ge-additional-regions/](https://aws.amazon.com/about-aws/whats-new/2026/07/aws-i8ge-additional-regions/)

## 概要

Amazon Web Services（AWS）は、AWS Europe（London）および Canada（Central）リージョンで Amazon EC2 I8ge インスタンスの提供を開始したことを発表します。I8ge インスタンスは AWS Graviton4 プロセッサを搭載し、前世代の Graviton2 ベースのストレージ最適化型 Amazon EC2 インスタンスと比較して、計算性能を最大で60%向上させます。I8ge インスタンスは第3世代の AWS Nitro SSD、ローカル NVMe ストレージを使用し、前世代と比較してTB当たりのリアルタイムストレージ性能を最大で55%向上させます。
