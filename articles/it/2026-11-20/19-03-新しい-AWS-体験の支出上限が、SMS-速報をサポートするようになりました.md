# 新しい AWS 体験の支出上限が、SMS 速報をサポートするようになりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月20日 19:03
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/sms/](https://aws.amazon.com/about-aws/whats-new/2026/11/sms/)

## 概要

新しい AWS エクスペリエンスを利用している Paid プランのビルダーは、既存のメール通知に加えて、SMS（テキストメッセージ）で spending limit アラートを受け取ることができます。支出上限とは、プロジェクトの月額上限コストを設定する機能です。通知は、プロジェクトが上限に近づいたときに送信され、上限に達すると AWS が自動的にプロジェクトを停止します。SMS は、プロジェクトのコスト状況を把握するためのもう一つの手段となります。

メール通知は、ビルダーが受信箱を離れている場合に見逃されることがあります。
