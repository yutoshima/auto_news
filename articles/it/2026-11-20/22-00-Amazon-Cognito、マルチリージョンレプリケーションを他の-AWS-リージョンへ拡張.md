# Amazon Cognito、マルチリージョンレプリケーションを他の AWS リージョンへ拡張

## 概要

<p><a href="https://aws.amazon.com/cognito/">Amazon Cognito</a> のマルチリージョンレプリケーション（MRR）は、追加のAWSリージョンをサポートし、MRRのレジリエンス機能をより多くのワークロードへ拡張します。Amazon Cognitoは、ユーザー、AIエージェント、マイクロサービスのためのセキュアなサインインとアクセス制御を数分で実装するのに役立ち、MRRを使えば、認証情報、ユーザープールの設定、フェデレーション設定などを含むユーザーおよびマシンのアイデンティティデータを、待機リージョンとして指定したセカンダリのユーザープールへ同期することができます。
