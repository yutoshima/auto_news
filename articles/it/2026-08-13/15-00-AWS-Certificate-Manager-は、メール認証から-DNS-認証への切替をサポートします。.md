# AWS Certificate Manager は、メール認証から DNS 認証への切替をサポートします。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月13日 15:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/AWS-Certificate-Manager-Email-DNS-Switch](https://aws.amazon.com/about-aws/whats-new/2026/08/AWS-Certificate-Manager-Email-DNS-Switch)

## 概要

ACM（AWS Certificate Manager）は、既に発行済みの公開TLS証明書のドメイン検証方法を、証明書を再発行したりARNを変更したりせずに「メール」から「DNS」に変更できるようになりました。CA/Bフォーラム（Certification Authority/Browser Forum）の、公開信頼証明書に対するメールベースのドメイン検証の廃止が義務付けられたことに伴い、2028年3月15日をもってACMはメール検証のサポートを段階的に終了します。
