# AWS DataSync 強化モードは、Google CloudおよびMicrosoft Azure向けにOpenID Connect（OIDC）をサポートします。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月04日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/datasync-enhanced-oidc-google-azure/](https://aws.amazon.com/about-aws/whats-new/2026/11/datasync-enhanced-oidc-google-azure/)

## 概要

<p>AWS DataSync Enchancedモードは現在、Google Cloud StorageとMicrosoft Azure Blob Storageのロケーションに対してOpenID Connect (OIDC) 認証をサポートしています。DataSyncはAWS IAMロールを使用してGoogle CloudまたはMicrosoft Entra IDから短命な認証情報を取得し、それを自動で更新するため、転送が中断なく実行されます。</p>
<p>長期認証情報（ハッシュベースなど）を使わずに、DataSyncを使ってGoogle Cloud StorageとAzure Blob Storageへアクセスできるようになりました。</p>
