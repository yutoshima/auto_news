## 概要

今日は、AWS Billing and Cost Management の Data Hub のプレ previews を発表します。Data Hub は、SQL でコストと使用量データを照会できる管理済みデータレイヤーで、AWS FinOps Agent が利用できます。プレビュー版では Data Hub は AWS FinOps Agent に提供され、エージェントはコスト変動の背後にある個々のリソースを特定し、チーム別またはコスト配分タグごとに支出を内訳表示し、リソースのコストと使用量が時間ごとにどのように変化するかを示すことができます。AWS FinOps Agent と Data Hub を組み合わせると、顧客はデータベースの設定なしでこれらの問いに答えを得られます。
