# AWS Backup が Amazon EBS Snapshots Archive の論理的にエアギャップされた保管庫サポートを追加しました。

## 概要

AWS Backup の論理的にエアギャップ化されたボールトが、Amazon EBS Snapshots Archive をサポートしました。論理的にエアギャップ化されたボールトは、バックアップをアカウント間および AWS Organizations 全体で安全に共有でき、データ損失イベントからの回復時間を短縮するための直接復元をサポートする、AWS Backup ボールトの一種です。

これにより、論理的にエアギャップ化されたボールトに格納されている Amazon EBS バックアップを、ほとんどアクセスしないスナップショット用の低コスト階層である Amazon EBS Snapshots Archive にアーカイブできるようになりました。論理的にエアギャップ化されたボールトは、改ざんのない状態を保つための保護を提供します。
