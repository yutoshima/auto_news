# AWS MCPサーバーは、追加の6つのAWSリージョンで利用可能になりました。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月02日 08:00

## 概要

AWS MCPサーバーは、シンガポール、シドニー、東京、アイルランド、ロンドン、オレゴンの6つの追加AWSリージョンで利用可能になりました。AWS MCPサーバーは、AWS向けエージェントツールキットの一部である「Agent Toolkit for AWS」に属する、AWS APIへアクセスするための統一インターフェースをAIコーディングエージェントに提供する管理されたModel Context Protocolサーバーです。これによりエージェントはビルドインなしでAWSサービスを発見し、呼び出すことができます。
