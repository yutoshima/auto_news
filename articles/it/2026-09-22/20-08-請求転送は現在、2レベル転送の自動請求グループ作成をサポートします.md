# 請求転送は現在、2レベル転送の自動請求グループ作成をサポートします

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月22日 20:08
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/09/aws-billing-transfer-supports-automatic-billing-group-creation/](https://aws.amazon.com/about-aws/whats-new/2026/09/aws-billing-transfer-supports-automatic-billing-group-creation/)

## 概要

AWS Billing Transfer ユーザーは、二段階請求転送の構成での手動の請求グループ設定を排除する、新しい AWS Billing Conductor の設定「Auto-Billing Transfer Billing Group Creation」を有効にできます。下流の販売パートナーとそのエンド顧客の請求を管理する AWS ディストリビューター向けに設計されたこの機能は、エンド顧客が下流の販売パートナーから請求転送を受け入れた際に自動的に請求グループを作成し、仮想コストデータが確保されることを保証します。
