# AWS Lambda MicroVM が、追加で7つのAWSリージョンで利用可能になりました。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月20日 16:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/aws-lambda-microvms-7-regions](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-lambda-microvms-7-regions)

## 概要

AWS Lambda MicroVMs が、新たに7つのAWSリージョンで利用可能になりました：アジア太平洋地域（大阪）、アジア太平洋地域（ソウル）、カナダ（中部）、ヨーロッパ（ロンドン）、ヨーロッパ（パリ）、南米（サンパウロ）、米国西部（ノースカロライナ）。この開始により、合計21のAWSリージョンで Lambda MicroVMs を利用できます。

Lambda MicroVMs は、VM レベルの分離性、ほぼ即時の起動・再開速度、ユーザーまたは AI が生成したコードを実行する際の状態保持を提供する、サーバーレスコンピュートのプリミティブです。
