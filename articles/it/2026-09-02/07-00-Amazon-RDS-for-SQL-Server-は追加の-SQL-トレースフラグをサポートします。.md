# Amazon RDS for SQL Server は追加の SQL トレースフラグをサポートします。

- **カテゴリ**: it
- **公開日時**: 2026年09月02日 07:00

## 概要

<p><a href="https://aws.amazon.com/rds/sqlserver/" rel="noopener noreferrer" target="_blank">SQL Server用 Amazon RDS</a> は、データベースパラメータグループを通じて有効化できる18個の追加の SQL トレースフラグをサポートします。トレースフラグは、クエリオプティマイザの基数推定、ロックエスカレーション、統計情報の管理、メモリ処理など、SQL Server エンジンの動作を変更する設定スイッチであり、データベース管理者がパフォーマンスを微調整し、ワークロード固有の要件に対応できるようにします。
