# AWS Resilience Hubが推奨するレジリエンステストを提供します

## メタデータ

- **カテゴリ**: it
- **公開日時**: 2026年08月03日 19:02
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/aws-resilience-hub/](https://aws.amazon.com/about-aws/whats-new/2026/08/aws-resilience-hub/)

## 概要

<p>AWS Resilience Hubは、プラットフォームエンジニアリングおよびサイト信頼性エンジニアリング（SRE）チームが、サービスが既知の障害シナリオにどのように対応し、回復するかを検証するのを支援する推奨のレジリエンステストを提供します。</p>
<p>Resilience Hubは、サービスのアーキテクチャ、構成、レジリエンスポリシーに基づいて事前設定されたテストを提供します。AWS Fault Injection Service（FIS）を使用して制御された障害を注入し、定義した回復目標内でサービスが回復するかどうかを評価します。</p>
