# AWS Lambdaは現在、Amazon SQS FIFOキューのバッチサイズを最大10,000件までサポートしています。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月20日 19:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/aws-lambda-10K-batch-size-SQSFIFO/](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-lambda-10K-batch-size-SQSFIFO/)

## 概要

AWS Lambda は、Amazon Simple Queue Service（Amazon SQS）の FIFO キューをイベントソースマッピング（ESM）として provisioned mode で利用する場合、バッチサイズを最大10,000件のメッセージまでサポートするようになりました（従来は10件）。より大きなバッチにより、金融取引、注文処理、在庫更新など、ボリュームが多く、順序性が重要なワークロードを、呼び出し回数を減らして処理できます。
