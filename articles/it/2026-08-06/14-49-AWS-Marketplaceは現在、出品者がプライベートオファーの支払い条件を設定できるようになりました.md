# AWS Marketplaceは現在、出品者がプライベートオファーの支払い条件を設定できるようになりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月06日 14:49
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/aws-marketplace-net-payment-terms-for-private-offers](https://aws.amazon.com/about-aws/whats-new/2026/08/aws-marketplace-net-payment-terms-for-private-offers)

## 概要

AWS Marketplaceは現在、プライベートオファーに対してネット支払条件を設定可能にしました。選択肢にはNet 30、Net 45、Net 60、Net 90が含まれます。これまでのリリース前は、AWS Marketplaceの全購入でネット支払条件が一律で、AWSとの買い手の支払条件に基づいていました。新機能により、売り手は支払期日を設定できるため、請求書の支払期日が買い手と売り手の交渉内容と一致します。これにより、買い手は支払期日を事前に把握でき、より柔軟に対応することが可能になります。
