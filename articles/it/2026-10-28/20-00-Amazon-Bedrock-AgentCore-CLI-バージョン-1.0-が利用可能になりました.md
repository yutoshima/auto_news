# Amazon Bedrock AgentCore CLI バージョン 1.0 が利用可能になりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月28日 20:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-bedrock-agentcore-cli-version-1-0-available/](https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-bedrock-agentcore-cli-version-1-0-available/)

## 概要

AWSは Amazon Bedrock AgentCore CLI バージョン 1.0（@aws/agentcore 1.0.0）の一般提供を発表しました。起動を高速化し、コマンド構造を一貫させ、より多くのAgentCoreリソースをサポートする形にリビルドされています。このCLIは、端末からAIエージェントと関連リソースを作成・開発・デプロイ・運用するための支援を提供します。

バージョン1.0では、開発者はプロジェクトのワークフローを使用するか、またはハーネス、ランタイム、メモリ、アイデンティティ、ゲートウェイ、支払いといった要素を、最初に追加することなく直接扱うことができます。
