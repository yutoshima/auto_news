# AWS Client VPNは現在、MacOS 27 Golden Gateをサポートしています。

- **カテゴリ**: it

## 概要

AWS Client VPNは、MacOS 27 Golden Gateクライアント（バージョン6.0以降）をサポートしました。最新のMacOSバージョンでAWS提供のVPNクライアントを利用できます。AWS Client VPNのデスクトップクライアントは無料で提供されており、以下からダウンロードできます：https://aws.amazon.com/vpn/client-vpn-download/

AWS Client VPNは、リモートワークフォースをAWSまたはオンプレミスのネットワークへ安全に接続するマネージドサービスです。MacOS、Windows x64、Windows Arm64、Uのデスクトップクライアントをサポートします。
