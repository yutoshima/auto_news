# AWS IAM Identity CenterのIdentity Storeが、Amazon EventBridgeを通じた変更通知をサポートしました

- **カテゴリ**: it
- **公開日時**: 2026年10月28日 08:00

## 概要

AWS IAM Identity CenterのIdentity Storeは、ユーザー、グループ、グループメンバーシップ、またはIdentity Store自体が作成、更新、削除されたときに、リアルタイムイベントをAmazon EventBridgeへ配信します。 AWS IAM Identity Center Identity Storeは、AWSアカウントとアプリケーション全体でアイデンティティとアクセスを管理できる中央リポジトリで、AWS IAM Identity Centerのアイデンティティソースとして機能します。この新機能により、アイデンティティのライフサイクルイベントに自動的に対応し、サポートを強化します。
