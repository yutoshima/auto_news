# Amazon EC2 R9g および R9gd メモリ最適化インスタンスが利用可能になりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月31日 18:08
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-ec2-r9g-and-r9gd-memory-optimized-instances-are-now-available/](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-ec2-r9g-and-r9gd-memory-optimized-instances-are-now-available/)

## 概要

本日より、AWS Graviton5 プロセッサを搭載した Amazon Elastic Compute Cloud（Amazon EC2） R9g および R9gd インスタンスが一般提供開始となります。AWS Graviton5 プロセッサは、カスタム設計の第5世代CPUで、Amazon EC2 上で実行されるメモリ集約型ワークロードにおいて、最良の価格性能を提供します。

R9g インスタンスは、データベース、インメモリキャッシュ、リアルタイムのビッグデータ分析、コンテナ化およびマイクロサービスを含む Linux ベースのワークロードなど、メモリ集約型のワークロードに最適です。
