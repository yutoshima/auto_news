# Amazon RDS for Oracleは現在、ダウンタイムを抑えるためのReplica First Patchニングに対応しています

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月20日 22:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/rds-oracle-replica-first-patching/](https://aws.amazon.com/about-aws/whats-new/2026/11/rds-oracle-replica-first-patching/)

## 概要

Amazon Relational Database Service (Amazon RDS) for Oracleは現在、Replica First Patchingをサポートしています。これにより、小規模バージョンアップグレード時のダウンタイムを減らすことができます。Replica First PatchingはEnterprise EditionのDBインスタンスで利用可能です。Replica First Patchingでは、プライマリDBインスタンスが引き続きトラフィックを処理している間に、同じAWSリージョン内のレプリカへ先にミニバージョンアップを適用し、準備が整い次第レプリカへ切り替えます。
