# AWS HealthOmics は現在、WDLワークフローのタスクレベルのタイムアウトをサポートします

- **カテゴリ**: it

## 概要

<p>AWS HealthOmicsは現在、Workflow Description Language (WDL)ワークフローに対してタスク単位のタイムアウトをサポートしており、個々のタスクの最大実行時間を設定できます。<a href="https://aws.amazon.com/healthomics/">AWS HealthOmics</a>はHIPAA適合サービスで、ヘルスケアおよびライフサイエンスの顧客が完全管理されたバイオインフォマティクスワークフローを用いて科学的ブレークスルーを大規模に加速させるのを支援します。&nbsp;</p> 
<p>タスク単位のタイムアウトを利用すると、個々のWDLタスクに対して時間の境界を定義し、実行時間を制御できます。</p>
