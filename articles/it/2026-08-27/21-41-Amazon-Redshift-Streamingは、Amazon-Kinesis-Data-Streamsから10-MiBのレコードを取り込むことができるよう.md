# Amazon Redshift Streamingは、Amazon Kinesis Data Streamsから10 MiBのレコードを取り込むことができるようになりました。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月27日 21:41
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/redshift-streaming-supports-kds-10mib-records](https://aws.amazon.com/about-aws/whats-new/2026/08/redshift-streaming-supports-kds-10mib-records)

## 概要

Amazon Redshiftは現在、Amazon Kinesis Data Streams（KDS）のレコードサイズを最大10 MiBまでサポートしています。これは以前の1 MiBのリミットから10倍の拡大で、KDSの拡張された最大レコードサイズに完全に対応しています。つまり、レコードを分割することなく、はるかに大きなペイロードを直接Amazon Redshiftへストリーミングできるため、取り込みパイプラインの簡素化と、大量・大容量レコードワークロードの新たなユースケースの解放が可能になります。
