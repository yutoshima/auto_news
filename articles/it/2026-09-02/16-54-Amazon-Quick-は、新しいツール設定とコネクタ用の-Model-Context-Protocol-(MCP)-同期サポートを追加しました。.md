# Amazon Quick は、新しいツール設定とコネクタ用の Model Context Protocol (MCP) 同期サポートを追加しました。

## 概要

<p>Amazon Quick は、Outlook、Slack、Salesforce、Jira、社内開発の MCP サーバーなどのツールやサービスを、チャット、エージェント、アプリ、フロー、深層リサーチといったワークフローに直接組み込むことを可能にします。今日、Amazon Quick は新しいツール設定と MCP 同期のサポートを導入し、管理者とコネクタ所有者がコネクタのデプロイ方法や最新状態の維持をより細かくコントロールできるようにしました。</p> 
<p>コネクタの所有者と管理者は、コネクタ内の個々のツールを選択的に有効化または無効化できるようになりました</p>
