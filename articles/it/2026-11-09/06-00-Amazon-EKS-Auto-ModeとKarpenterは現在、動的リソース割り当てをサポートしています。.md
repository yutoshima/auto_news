# Amazon EKS Auto ModeとKarpenterは現在、動的リソース割り当てをサポートしています。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月09日 06:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-eks-auto-mode-karpenter-dra/](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-eks-auto-mode-karpenter-dra/)

## 概要

<p>Amazon Elastic Kubernetes Service（Amazon EKS）は、Amazon EKS Auto ModeとKarpenterを使用する場合、NVIDIA GPUとElastic Fabric Adapter（EFA）ネットワークデバイスの Dynamic Resource Allocation（DRA）をサポートします。DRAを使用して、Kubernetesワークロードに必要なデバイス属性を定義し、Pod間でGPUデバイスを共有し、トポロジーに整列したGPUおよびEFAデバイスを割り当てることができます。これらは、Amazon EKS Auto ModeとKarpenterがワークロードの需要に応じてAmazon EC2インスタンスを動的にスケールする間に実行されます。</p>
