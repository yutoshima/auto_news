# AWS HealthOmics が IAM セッションポリシーをサポートしました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月17日 18:32
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/09/omics-iam-session-policy/](https://aws.amazon.com/about-aws/whats-new/2026/09/omics-iam-session-policy/)

## 概要

AWS HealthOmicsは現在、IAMセッションポリシーをサポートしており、複数のIAMロールを作成・管理することなく、個々の実行に対する権限を制限できるようになりました。これまでは単一の実行の権限を動的に絞る方法がなく、テナントまたは実行ごとに別のIAMロールを作成する必要がありました。AWS HealthOmicsはHIPAA適格なサービスで、完全管理型のバイオインフォマティクスワークフローを用いて、医療・生命科学の顧客が科学的ブレークスルーを加速させるのを支援します。
