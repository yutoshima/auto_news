# Amazon CloudWatch EKS Container Insights は、オープンソースの Kubernetes ツール向けの組み込みモニタリングを提供するようになりました。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月20日 20:47
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/cloudwatch-eks-kubernetes-tools/](https://aws.amazon.com/about-aws/whats-new/2026/11/cloudwatch-eks-kubernetes-tools/)

## 概要

今日は、Open sourceツールがAmazon EKSクラスター上で実行されている場合の組み込みモニタリングを、Karpenter、KEDA、vLLM、KServe、SGLang、Ray、Knative Servingを含む形で Amazon CloudWatch が提供します。PrometheusやGrafanaを自分で実行することなく、すでに使用しているツールのダッシュボードを利用できます。

モニタリングは、OTel Container Insights を有効にすると自動的に開始されます。AI推論ワークロードでは、各モデルサーバーごとに待機中のリクエスト、最初のトークンまでの時間、KVキャッシュの使用量を確認できます。
