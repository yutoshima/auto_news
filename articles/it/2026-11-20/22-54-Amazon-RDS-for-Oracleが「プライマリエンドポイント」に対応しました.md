# Amazon RDS for Oracleが「プライマリエンドポイント」に対応しました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月20日 22:54
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/rds-oracle-primary-endpoint-v2/](https://aws.amazon.com/about-aws/whats-new/2026/11/rds-oracle-primary-endpoint-v2/)

## 概要

<Amazon Relational Database Service (Amazon RDS) for Oracle> は現在、複製構成における現在のプライマリ DB インスタンスを常に解決する DNS 名である「プライマリ エンドポイント」を提供します。Oracle のレプリカへスイッチオーバーすると、Amazon RDS はプライマリ エンドポイントを新しいプライマリ DB インスタンスに指すため、アプリケーションの接続文字列を変更する必要はありません。以前は、各スイッチオーバー後に接続文字列や DNS を更新する必要がありました。
