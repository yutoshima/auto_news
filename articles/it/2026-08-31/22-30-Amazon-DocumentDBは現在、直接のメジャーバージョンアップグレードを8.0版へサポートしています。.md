# Amazon DocumentDBは現在、直接のメジャーバージョンアップグレードを8.0版へサポートしています。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月31日 22:30
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/documentdb-major-version-upgrade-8-0/](https://aws.amazon.com/about-aws/whats-new/2026/08/documentdb-major-version-upgrade-8-0/)

## 概要

Amazon DocumentDB（MongoDB互換版）は、エンジンバージョン3.6および4.0から直接、インプレースのメジャーバージョンアップ（MVU）をサポートします。これにより、中間バージョンへのアップグレードを行う必要がなくなり、3.6または4.0のクラスターをデータ・設定・クラスター設定を保持したままアップグレードできます。

バージョン8.0へのアップグレードは、最新のセキュリティパッチ、パフォーマンス向上、および新しい開発者機能へのアクセスを提供します。
