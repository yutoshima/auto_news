# AWS Security Hub は優先順位付けのためのリソースの重要度をサポートするようになりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月14日 01:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/security-hub-resource-criticality/](https://aws.amazon.com/about-aws/whats-new/2026/10/security-hub-resource-criticality/)

## 概要

本日、AWS Security Hubは露出の優先度付けに資源の重要度を追加し、中央のセキュリティチームが最も重要なビジネス資源を脅かす露出に集中できるようにします。

自動化ルールを設定して重要度を指定できます。たとえば、特定のアカウント内のすべての計算リソースを「非常に高い」とマークする、などです。このルールは、すでにインベントリにあるリソースと Security Hub が新たに検出するリソースの両方に適用されます。Security Hubはリソースのタグやリソース自体からも重要度を推定します。
