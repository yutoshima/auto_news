# Amazon Kinesis Data Streams は現在、APIリクエストを検証するためのドライラン機能をサポートしています

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月01日 19:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-kinesis-data-streams-api/](https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-kinesis-data-streams-api/)

## 概要

<p>Amazon Kinesis Data Streams は、操作を実行せずに API リクエストが成功するかどうかを確認できるドライラン機能を新たにサポートします。顧客は 이제 新しい任意パラメータ「DryRun」を true に設定することで、ストリームと本番環境での操作に先立ち、権限を検証できます。</p>
<p>以前は、アプリケーションがストリームへアクセスする権限を正しく持っているかを安全にテストする手段がありませんでした。彼らはしばしば、権限を確認した後、失敗するように設計されたリクエストを送信していました。</p>
