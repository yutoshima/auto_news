# Amazon EC2 P6-B200 インスタンスが、AWS アジア太平洋 (ハイデラバード) リージョンで利用可能になりました。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月03日 19:14
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-ec2-p6-b200-instances-available-asia-pacific-hyderabad](https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-ec2-p6-b200-instances-available-asia-pacific-hyderabad)

## 概要

本日より、NVIDIA Blackwell GPU によって高速化された Amazon Elastic Compute Cloud（Amazon EC2） P6-B200 インスタンスが AWS アジア太平洋（ハイデラバード）リージョンで利用可能になります。これらのインスタンスは、AI のトレーニングおよび推論において P5en インスタンスと比較して最大 2 倍のパフォーマンスを提供します。

P6-B200 インスタンスには 1440 GB の高帯域 GPU メモリを搭載した Blackwell GPU 8 台と、P5en、第5世代 Intel Xeon プロセッサ（Emerald Rapids）と比較して GPU メモリ帯域幅を最大 60% 向上させ、最大 3.2 テラフロップスの性能を発揮します。
