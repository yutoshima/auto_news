# AWS LambdaがPython 3.15をサポートしました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月20日 14:59
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/aws-lambda-python-315/](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-lambda-python-315/)

## 概要

AWS Lambdaは、Python 3.15を利用したサーバーレスアプリケーションの作成をサポートします。Python 3.15はLambdaのイベント関数向けには一般提供が開始され、Lambda Web Functionsの公開プレビューでは利用可能です。これまでWeb FunctionsはNode.jsのみをサポートしていましたが、今回のリリースでPythonがWeb Functionsの初のランタイムとなります。これにより、開発者はWeb Functions上でPythonを用いたウェブアプリケーションやAPIの構築も可能になります。開発者は、Python 3.15をマネージドランタイムとしても、ベースコンテナイメージ（イベント関数のみ）としても使用できます。
