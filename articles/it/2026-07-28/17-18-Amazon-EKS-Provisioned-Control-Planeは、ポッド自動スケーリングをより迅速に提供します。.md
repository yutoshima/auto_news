# Amazon EKS Provisioned Control Planeは、ポッド自動スケーリングをより迅速に提供します。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年07月28日 17:18

## 概要

<p><a href="https://aws.amazon.com/pm/eks">Amazon EKS</a> は、Provisioned Control Plane クラスター全体で、Horizontal Pod Autoscaler (HPA) の同期同時実行数をデフォルトの Kubernetes 値の最大40倍に引き上げることで、より迅速なポッド自動スケーリングを実現します。これにより、HPA によって駆動されるワークロードの所要時間が短縮されます。</p>
