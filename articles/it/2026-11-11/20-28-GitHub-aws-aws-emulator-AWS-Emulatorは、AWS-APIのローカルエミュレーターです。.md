## 概要

AWS Emulator は AWS API のローカルエミュレーターです。これは、AWS に実際に呼び出すことなく、開発用マシンや開発サーバ、継続的インテグレーション（CI）環境でソフトウェアをテストするために使用します。AWS アカウントは不要です。リクエストはエミュレーターへ送られ、AWS には送信されません。つまり、エミュレートされたリソースを扱うことになります。
