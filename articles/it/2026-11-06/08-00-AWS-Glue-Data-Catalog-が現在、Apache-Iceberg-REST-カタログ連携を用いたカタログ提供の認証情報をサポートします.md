# AWS Glue Data Catalog が現在、Apache Iceberg REST カタログ連携を用いたカタログ提供の認証情報をサポートします

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月06日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/glue-catalog-vended-credentials-iceberg/](https://aws.amazon.com/about-aws/whats-new/2026/11/glue-catalog-vended-credentials-iceberg/)

## 概要

<p>AWS Glue Data Catalog は現在、外部カタログのベンドされた資格情報を Apache Iceberg REST カタログ連携でサポートしています。外部 Iceberg カタログ内の粗粒度のテーブル権限を使用して、Amazon Athena、Amazon EMR、Amazon Redshift、そして AWS Glue から外部 Iceberg テーブルを読み取ることができます。</p>
<p>Glue Data Catalog はすでに、外部 Iceberg REST カタログへ AWS IAM ロールを介して連携しており、そのロールには Amazon S3 バケットへのアクセス権が設定されています。この Glue Data Catalog の強化により、外部 Iceberg カタログへの連携機能がさらに拡張されます。</p>
