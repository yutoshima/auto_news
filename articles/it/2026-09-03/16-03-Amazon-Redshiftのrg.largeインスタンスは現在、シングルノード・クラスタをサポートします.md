# Amazon Redshiftのrg.largeインスタンスは現在、シングルノード・クラスタをサポートします

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月03日 16:03
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/09/redshift-rg-large-single-node](https://aws.amazon.com/about-aws/whats-new/2026/09/redshift-rg-large-single-node)

## 概要

<p>Amazon Redshift rg.large インスタンスは、AWS Graviton プロセッサを搭載し、単一ノードクラスタをサポートするようになりました。rg.large クラスターの単一ノードサポートは P204 以降のパッチバージョンで利用可能です。高可用性を必要としない小規模なワークロード向けに、シングルノードの rg.large クラスターを作成できるようになり、コンセプト検証やテストを迅速に実施するための費用対効果の高いオプションを提供します。</p> 
<p>RG インスタンスは、データウェアハウスおよびデータレイクのワークロードを実行時に最大 2.4 倍の高速化を実現します。</p>
