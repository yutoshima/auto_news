# AWS AppConfigがネイティブAIモデルとAIプロンプトの設定管理をサポート開始

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月19日 05:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/aws-appconfig-native-ai-model-invocation-prompt-configurations/](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-appconfig-native-ai-model-invocation-prompt-configurations/)

## 概要

今日は、AWS AppConfig が生成系 AI アプリケーションの設定を管理するための新しい構成プロファイルタイプとして、AI モデル呼び出し設定とAI プロンプト設定を2つ追加しました。アプリケーションを再デプロイすることなく、実行中にモデル設定やプロンプトを変更できるようになりました。これらの更新は、段階的なロールアウトと自動ロールバックを含む AWS AppConfig の安全なデプロイ方法を使用しています。これにより、より迅速かつ安全に進めることができ、予期せぬ挙動を回避できます。
