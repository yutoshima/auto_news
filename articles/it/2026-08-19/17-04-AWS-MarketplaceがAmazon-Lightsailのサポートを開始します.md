# AWS MarketplaceがAmazon Lightsailのサポートを開始します

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月19日 17:04

## 概要

<p>本日、AWS Marketplaceは、特定のAmazon Machine Images（AMIs）をAmazon Lightsailで起動することをサポートすることを発表します。シンプルで予測可能な料金と、手間のかからないインスタンス作成体験を求める顧客は、数回のクリックだけで該当するAWS MarketplaceのAMIsをAmazon Lightsailに容易にデプロイできます。Lightsailのインスタンス・バンドルには、計算資源、ストレージ、および固定月額料金での十分なデータ転送枠が含まれます。Lightsailは、マネージドデータベース、コンテナ、ロードバランサーなども提供します。
