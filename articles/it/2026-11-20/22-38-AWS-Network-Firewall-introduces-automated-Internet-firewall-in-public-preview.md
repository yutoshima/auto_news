# AWS Network Firewall introduces automated Internet firewall in public preview

## メタデータ

## 概要

AWS Network Firewallは、インターネットゲートウェイ全体の環境内の全VPCに対して、ネイティブのネットワークアドレス変換（NAT）機能を備えた新しい集中制御「自動化インターネットファイアウォール」の公開プレビューを発表します。自動化インターネットファイアウォールモードを使用すると、 Network Firewallのセキュリティルールを中央で定義し、VPCのインターネットゲートウェイを通るすべての着信・発信トラフィックに対して適用できます。
