# AWS Healthはソフトウェアライフサイクル管理のためのバージョンカタログを導入します

## 概要

<p>本日、AWS Health は、ソフトウェアバージョンのライフサイクル情報を AWS サービス全体で一元的に提供する「バージョンカタログ」を発表します。バージョンカタログは、顧客がバージョンアップグレードとサポート終了リスクの管理を反応的から予防的へと移行できるよう支援します。AWS Health ダッシュボードで利用でき、Business Support Plus、Enterprise Support、または Unified Operations の顧客は AWS Health API を用いてライフサイクルデータを運用ワークフローに組み込むことができます。</p>
