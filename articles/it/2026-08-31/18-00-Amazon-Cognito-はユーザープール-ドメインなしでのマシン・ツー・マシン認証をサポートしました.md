# Amazon Cognito はユーザープール ドメインなしでのマシン・ツー・マシン認証をサポートしました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月31日 18:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-cognito-get-client-token/](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-cognito-get-client-token/)

## 概要

<p>Amazon Cognito は現在、GetClientToken API 操作をサポートしており、アプリクライアントがユーザープールのドメインを設定することなく、AWS SDK、CLI、または API を通じて機械同士の認証（M2M）用のアクセストークンを直接取得できるようになりました。これにより、アプリケーション、マイクロサービス、自動化ワークロードのサービス間通信を承認する追加の経路が提供されます。</p>
<p>新しい GetClientToken API 操作を使用すると、アプリクライアントはクライアントIDとシークレットで認証してアクセストークンを受け取ることができます。</p>
