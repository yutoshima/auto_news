# Amazon EVSがr7i.metalインスタンス、外部プリンシパルストレージ、そしてエージェントスキルのサポートを開始します。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月17日 17:27
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-evs-r7i-agent-skill-support/](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-evs-r7i-agent-skill-support/)

## 概要

本日、Amazon Elastic VMware Service（Amazon EVS）が、VMware Cloud Foundation（VCF）9.xデプロイメント向けのr7i.metal-24xlおよびr7i.metal-48xlのAmazon Elastic Compute Cloud（EC2）ベアメタルインスタンスタイプをサポートすることを発表します。EC2 r7iインスタンスはメモリ最適化タイプで、カスタムの第4世代Intel Xeon Scalable（Sapphire Rapids）プロセッサを搭載し、外部ストレージの使用を想定して設計されています。これらのインスタンスはローカルNVMeディスクを搭載していないため、Amazon EVSはVCFの外部ストレージをサポートします。
