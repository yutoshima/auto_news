# Amazon MWAAは現在、DuckDBオペレーターをサポートします。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月09日 18:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-mwaa-supports-duckdb-operators/](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-mwaa-supports-duckdb-operators/)

## 概要

<p>Amazon Managed Workflows for Apache Airflow（Amazon MWAA）は、DuckDBオペレーターをサポートするようになりました。DuckDBは組み込み型の分析データベースで、データの品質チェック、サマリー、変換をDuckDBがサポートするデータソース（S3を含む）から実行することができます。</p>
<p>ネイティブサポートは、Apache Airflow 3.3.1を実行しているAmazon MWAA Provisioned環境で利用可能です。最新のMWAA Airflow 3.3.1アップデートには、DuckDBがAWS接続のために事前インストールおよび事前構成されています。</p>
