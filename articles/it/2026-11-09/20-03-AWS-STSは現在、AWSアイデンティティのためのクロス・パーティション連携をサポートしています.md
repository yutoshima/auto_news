# AWS STSは現在、AWSアイデンティティのためのクロス・パーティション連携をサポートしています

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月09日 20:03
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/aws-sts-cross-partition](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-sts-cross-partition)

## 概要

AWS Security Token Service (AWS STS) により、ワークロードが自分の IAM ID を1つのパーティション内で使用して、別のパーティションにある IAM ロールの一時的な認証情報を取得できるようになりました。長期的な認証情報を保存する必要がなく、セキュリティ態勢の向上に役立ちます。パーティションは、商用Regionと AWS GovCloud (US) Regions などの AWS Regions のグループです。
