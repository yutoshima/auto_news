# AWS Network Firewall が Route 53 解決済み IP の検証をサポートします

- **カテゴリ**: it

## 概要

<p>AWS Network Firewall now supports IP validation, extending domain-based filtering beyond HTTP/HTTPS to protocols such as SFTP and SSH. This new capability validates that a connection's destination IP address was resolved through your VPC's Amazon Route 53 VPC Resolver, closing security gaps where clients could bypass domain rules.</p> 
<p>This feature enables Network Firewall customers to implement domain filtering rules for any protocol, not just HTTP/HTTPS, providing more flexible security</p> 

→

AWS Network Firewallは現在、IP検証をサポートしており、HTTP/HTTPSだけでなくSFTPやSSHなどのプロトコルへとドメインベースのフィルタリングを拡張します。新機能は、接続先のIPアドレスがVPCのAmazon Route 53 VPC Resolverを経由して解決されたことを検証し、クライアントがドメインルールを回避できるセキュリティ上のギャップを閉じます。

この機能により、Network Firewallの顧客はHTTP/HTTPSだけでなく任意のプロトコルに対してドメインフィルタリングルールを適用できるようになり、より柔軟なセキュリティを提供します。
