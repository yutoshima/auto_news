# AWS Lambdaは現在、カスタマー管理ランタイムをサポートしており、プラットフォームチームがランタイムの内容と更新を一元管理できるようになりました。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月18日 15:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/aws-lambda-customer-managed-runtimes/](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-lambda-customer-managed-runtimes/)

## 概要

<p>AWS Lambdaは現在、Lambda Event Functions（旧称 Lambda functions）の顧客管理ランタイムをサポートしています。顧客管理ランタイムは独立したリソースタイプで、ランタイム管理と関数デプロイを完全に切り離します。プラットフォームチームは、ランタイムの内容、更新、アクセス、ライフサイクルを一元的に制御できるようになり、共有コンポーネントへの更新を関数ごとに再デプロイすることなく適用する能力を含みます。アプリケーションチームは、サムから自分の関数でランタイムを利用します。
