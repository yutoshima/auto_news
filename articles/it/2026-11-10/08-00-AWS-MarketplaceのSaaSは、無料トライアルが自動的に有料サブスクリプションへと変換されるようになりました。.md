# AWS MarketplaceのSaaSは、無料トライアルが自動的に有料サブスクリプションへと変換されるようになりました。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月10日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/aws-marketplace-free-trial-conversion/](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-marketplace-free-trial-conversion/)

## 概要

本日、<a href="https://aws.amazon.com/marketplace">AWS Marketplace</a>は、従量課金型のソフトウェア・アズ・ア・サービス（SaaS）製品の無料トライアルが自動的に有料購読に移行できるようになったと発表します。無料トライアルが終了すると、購入者の購読は販売者の従量課金制の料金で継続されるため、購入者はトライアル後に実際に使用した分だけ支払うことになります。これにより、販売者はより多くのトライアル利用者を支払顧客へと転換しやすくなります。購入者は、購入前にソフトウェアを評価するためのシンプルな方法を得られ、追加の手間は不要です。
