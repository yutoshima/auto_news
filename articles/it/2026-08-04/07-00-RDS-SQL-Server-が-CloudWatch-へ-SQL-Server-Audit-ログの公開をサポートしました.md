## 概要

<a href="https://aws.amazon.com/rds/sqlserver/" target="_blank">Amazon Relational Database Service (Amazon RDS) for SQL Server</a> は、CloudWatch への SQL Server Audit ログの公開をサポートします。SQL Server Audit は、データベースエンジン上で発生するイベントを追跡・記録するネイティブな SQL Server の機能です。Amazon RDS では、オンプレミスの SQL Server データベースサーバーで作成するのと同じ方法で、監査と監査仕様を作成できます。  
今後は、監査ログを公開できるようになります。
