# Amazon EC2 Capacity Manager の新機能

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月04日 07:00

## 概要

<p>Amazon EC2 Capacity Manager は現在、リアルタイムのサポート性チェックと容量充足メトリクスを提供します。リアルタイムのサポート性チェックは、インスタンスの起動や予約を行うことなく、各インスタンスタイプとアベイラビリティゾーンがリクエストをどれだけ支えられるかをスコア化して、容量を見つけるのに役立ちます。容量充足メトリクスは、リクエストした量に対してどれだけの容量が提供されたかを示します。</p> 
<p>数千のワークロードを数百のアカウントにまたがって実行するグローバル企業は、しばしばそれぞれを広く分散させています</p>
