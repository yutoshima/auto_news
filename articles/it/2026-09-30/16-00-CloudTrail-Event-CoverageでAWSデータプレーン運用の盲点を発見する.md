# CloudTrail Event CoverageでAWSデータプレーン運用の盲点を発見する

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月30日 16:00

## 概要

AWS CloudTrailは「イベントカバーエッジ（Event Coverage）」という新しいコンソール体験を導入します。これにより、アカウント単位および組織レベルでデータプレーンの運用カバー率を可視化できます。現在、環境内のどのAWSサービスとリソースタイプでデータイベントのログ記録が有効になっているか、また有効でないかを確認できるようになりました。これにより、組織内のアカウントを手動でスキャンすることなく、ログ記録状況のギャップを迅速に特定できます。

データイベントを有効にすると、AWSサービスのデータプレーン操作を追跡できます。
