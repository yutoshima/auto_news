# AWSデータエクスポートは、標準化されたAmazon Bedrock製品メタデータを提供します

## 概要

今日は、Bedrock の費用を理解するための標準化された製品メタデータを AWS Data Exports（コストと使用量レポート）で発表します。FinOps チームやクラウド管理者が Bedrock の費用を理解するための、一貫性のある構造化属性を提供します。AWS Data Exports を使うと、AWS のコストと使用量データのカスタマイズされたエクスポートを作成し、それを Amazon S3 に配信して Amazon Athena でのクエリやデータウェアハウスへの取り込みが可能です。これらの属性を用いることで、カスタムロジックを構築することなく Bedrock の支出を算定できます。
