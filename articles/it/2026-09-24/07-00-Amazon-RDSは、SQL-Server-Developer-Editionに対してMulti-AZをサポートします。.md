# Amazon RDSは、SQL Server Developer Editionに対してMulti-AZをサポートします。

## メタデータ

## 概要

Amazon RDS for SQL Server は、SQL Server Developer Edition の Always On Availability Groups を使用した Multi-AZ 展開をサポートします。Multi-AZ 展開は、別の可用性ゾーンに同期スタンバイレプリカを保持し、インフラ障害時に自動フェイルオーバーを提供します。この機能を使って、非本番環境で高可用性構成の構築・検証を行うことができます。
