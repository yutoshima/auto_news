# AWS IAM Identity Centerが現在、クロスリージョンでの信頼されたアイデンティティ伝搬をサポートしました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月26日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/aws-iam-identity-center-cross-region-tip/](https://aws.amazon.com/about-aws/whats-new/2026/10/aws-iam-identity-center-cross-region-tip/)

## 概要

信頼されたアイデンティティ伝播は、リクエストとともにユーザーのアイデンティティを伝えます。これにより、AWSサービスはユーザーが誰であるかとその基盤となるグループの関連付けに基づいて権限を付与し、監査のためにそのユーザーのアクセスを記録します。クロスリージョンサポートにより、このアイデンティティコンテキストを異なるAWSリージョンで実行されているAWSサービスに伝播できるようになり、AWSリージョン全体での設計・展開の柔軟性が向上します。

顧客は、多くの場合、AWSリージョン間でワークロードを分散します。
