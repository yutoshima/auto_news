# アマゾン・トランスクライブが同期転記APIを発表

## メタデータ

- **カテゴリ**: it
- **公開日時**: 2026年11月20日 20:00

## 概要

Amazon Transcribe は現在、同期転写 API の TranscribeAudio を提供しています。1 回のリクエストで完全な音声ファイルを送信すると、同じレスポンス内ですべての書き起こしを受け取ることができます。開始するジョブはなく、ポーリングするステータスも、管理する接続もありません。転写は Amazon Transcribe のバッチ転写と同じくらい高精度で、音声アシスタント、エージェント支援ツール、オンデマンドの「このクリップを文字起こしして」のような対話型アプリケーションに、迅速かつ正確な音声認識を追加できます。
