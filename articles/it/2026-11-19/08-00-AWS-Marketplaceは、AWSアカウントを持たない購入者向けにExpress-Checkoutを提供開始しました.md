# AWS Marketplaceは、AWSアカウントを持たない購入者向けにExpress Checkoutを提供開始しました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月19日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/aws-marketplace-express-checkout/](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-marketplace-express-checkout/)

## 概要

今日は、既存の AWS アカウントを持っていない企業が、既存ベンダーのソフトウェアを AWS Marketplace で購入できる、よりシンプルな方法として「AWS Marketplace Express Checkout」を発表します。  

Express Checkout は、現在 AWS を利用していない企業がソフトウェアを購入したいだけの場合に最適です。クラウドの設定は不要で、購入者はメールアドレスでサインインします。
