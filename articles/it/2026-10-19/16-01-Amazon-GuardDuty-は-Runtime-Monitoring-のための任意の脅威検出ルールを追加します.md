# Amazon GuardDuty は Runtime Monitoring のための任意の脅威検出ルールを追加します

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月19日 16:01
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/guardduty-runtime-optional-detection-rules/](https://aws.amazon.com/about-aws/whats-new/2026/10/guardduty-runtime-optional-detection-rules/)

## 概要

Amazon GuardDuty は現在、実行時モニタリングの検出ルールを任意で追加できるようになりました。50件を超える実行時モニタリングルールを有効化でき、特定の環境では日常的な動作かもしれないが、別の環境では侵害の兆候となる可能性があるプロセス、ファイル、ネットワーク活動を検出します。たとえば sudoers ファイルの変更や監査ログの無効化などです。

新しいルールは、EC2 インスタンス、Amazon EKS、Amazon ECS の検出を、EC2 上と AWS Fargate 上の両方で提供し、MITRE ATT&CK に対応する 13 種類のファインディングにまたがります。
