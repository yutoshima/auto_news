# AWS ユーザーエクスペリエンスのカスタマイズ（UXC）は、すべての商用 AWS リージョンで利用可能になりました

- **カテゴリ**: it
- **公開日時**: 2026年09月02日 13:00

## 概要

AWS ユーザーエクスペリエンスのカスタマイズ（UXC）は、すべての商用 AWS リージョンで利用可能になりました。UXC を使用すると、アカウント管理者がカスタムアカウントカラーを設定し、AWS Management Console に表示されるサービスとリージョンを制御できます。

これまで UXC は US East（N. Virginia）のみで利用可能で、これらの設定をプログラム的に管理する顧客は、単一のリージョンへ API コールを向ける必要がありました。今回の拡張により、顧客は任意の商用 AWS リージョンからアカウントのカスタマイズを管理できるようになりました。
