# Amazon RDS for Oracle がセルフ管理型 Active Directory での Kerberos 認証をサポートしました。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月05日 10:30
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/rds-oracle-kerberos-self-managed-ad/](https://aws.amazon.com/about-aws/whats-new/2026/11/rds-oracle-kerberos-self-managed-ad/)

## 概要

<p>Amazon Relational Database Service (Amazon RDS) for Oracle (<a href="https://aws.amazon.com/rds/oracle/">Amazon Relational Database Service (Amazon RDS) for Oracle</a>) は、顧客が自分で管理する Microsoft Active Directory (AD) ドメインに、RDS for Oracle DB インスタンスを直接参加させることを可能にしました。自分で管理する AD は、オンプレミス、Amazon EC2 上、または別のクラウドプロバイダー上で実行できます。AD ドメイン内のユーザーは、Kerberos を使用して RDS for Oracle DB インスタンスに認証できます。</p>
