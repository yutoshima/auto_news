# Amazon CloudFrontは現在、起源としてAWS Lambda Web Functionsをサポートしています。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月12日 23:10
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/cloudfront-lambda-web-functions-origin/](https://aws.amazon.com/about-aws/whats-new/2026/10/cloudfront-lambda-web-functions-origin/)

## 概要

本日より、AWS Lambda Web Functionsで作成したウェブアプリケーションを、CloudFrontのグローバルエッジネットワーク経由で配信できます。

Lambda Web Functionの前にCloudFrontを置くことで、エッジでのTLS終端による低遅延・高速接続、キャッシュによるパフォーマンス向上、管理TLS証明書付きのカスタムドメインが利用できます。アプリケーションコードの変更は不要です。CloudFront Origin Access Control（OAC）は、Lambda Web Functionをエッジ経由のみで到達可能に制限します。
