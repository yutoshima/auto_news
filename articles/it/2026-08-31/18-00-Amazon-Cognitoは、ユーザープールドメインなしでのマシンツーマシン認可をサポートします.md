# Amazon Cognitoは、ユーザープールドメインなしでのマシンツーマシン認可をサポートします

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月31日 18:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-cognito-get-client-token/](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-cognito-get-client-token/)

## 概要

Amazon Cognitoは現在、GetClientToken API オペレーションをサポートしています。これにより、ユーザープールドメインを設定せずに、アプリクライアントが AWS SDK、CLI、または API を通じて機械対機械（M2M）認証用のアクセストークンを取得できるようになります。これにより、アプリケーション、マイクロサービス、自動化ワークロードのサービス間通信を認可する追加の経路が提供されます。

新しい GetClientToken API オペレーションを使用すると、アプリクライアントはクライアントIDとシークレットで認証して、アクセスを受け取ることができます。
