# Amazon EC2 Auto Scaling は CloudFormation でインスタンス更新をサポートします

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年07月29日 21:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/07/ec2-auto-scaling-instance-refresh-cloudformation](https://aws.amazon.com/about-aws/whats-new/2026/07/ec2-auto-scaling-instance-refresh-cloudformation)

## 概要

<p>Amazon EC2 Auto Scalingは、インスタンスの置換を伴う新しい AWS CloudFormation の更新ポリシー「Instance Refresh」に対応しました。新しい AutoScalingInstanceRefresh 更新ポリシーを設定し、インスタンスの置換を必要とする更新プロパティを更新すると、CloudFormation が自動的に Instance Refresh を開始します。</p>
<p>この連携により、インスタンスの入れ替えや置換、マイグレーションの前置起動、アラームベースの監視、ベイク（下準備）時間を含むチェックポイントなど、Instance Refresh の機能を利用できるようになります。</p>
