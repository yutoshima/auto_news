# AWS DataSyncのEnhancedモードは、Amazon EFSおよびAmazon FSx for Lustreをサポートするようになりました。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年07月28日 10:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/07/aws-datasync-amazon-efs-fsx-lustre/](https://aws.amazon.com/about-aws/whats-new/2026/07/aws-datasync-amazon-efs-fsx-lustre/)

## 概要

<p>AWS DataSyncのEnhancedモードは、ソースまたはデスティネーションとしてAmazon EFSおよびAmazon FSx for Lustreをサポートします。</p>
<p>AWS DataSyncは、ネットワーク経由でのデータ転送を安全かつ高速に行うサービスで、データ移動を簡素化します。Enhancedモードはデータを並列処理し、ファイル数の制限を撤廃し、詳細な転送メトリクスを提供します。以前は、EFSまたはFSx for Lustreへデータを移動する場合、Basicモードのみを使用する必要がありました。現在はこれらのロケーションでもEnhancedモードを使用できます。</p>
