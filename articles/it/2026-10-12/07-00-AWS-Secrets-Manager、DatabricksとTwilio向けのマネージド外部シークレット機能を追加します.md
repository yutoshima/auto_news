# AWS Secrets Manager、DatabricksとTwilio向けのマネージド外部シークレット機能を追加します

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月12日 07:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/secrets-manager-managed-external-secrets-databricks-twilio/](https://aws.amazon.com/about-aws/whats-new/2026/10/secrets-manager-managed-external-secrets-databricks-twilio/)

## 概要

AWS Secrets Managerは、DatabricksとTwilioを含む管理対象の外部シークレット機能を拡張し、データパイプラインやメッセージングアプリケーションがこれらのサービスを呼び出す際に使用する認証情報を自動的にローテーションできるようにしました。カスタムのローテーションLambda関数を作成・保守することなく、AWSマネジメントコンソールまたはAPIから直接ローテーションを設定できます。

長期にわたる認証情報は、ローテーションの設定が難しく、安全に配布するのも難しいため、ローテーションされないまま放置されがちです。
