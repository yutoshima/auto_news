# AWS Resilience Hub は推奨耐障害性テストを提供するようになりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月03日 19:02
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/aws-resilience-hub/](https://aws.amazon.com/about-aws/whats-new/2026/08/aws-resilience-hub/)

## 概要

AWS Resilience Hub は、プラットフォームエンジニアリングとサイト信頼性エンジニアリングのチームが、既知の障害シナリオに対するサービスの応答と回復を検証するのに役立つ推奨のレジリエンステストを提供します。

Resilience Hub は、サービスのアーキテクチャ、構成、レジリエンスポリシーに基づいた事前設定のテストを提供します。これにより、AWS Fault Injection Service（FIS）を使用して制御された障害を注入し、定義した回復目標内でサービスが回復するかどうかを評価します。
