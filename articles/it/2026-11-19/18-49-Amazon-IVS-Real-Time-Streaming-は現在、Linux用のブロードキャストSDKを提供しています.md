# Amazon IVS Real-Time Streaming は現在、Linux用のブロードキャストSDKを提供しています

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月19日 18:49
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-ivs-real-time-streaming-linux-broadcast-sdk](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-ivs-real-time-streaming-linux-broadcast-sdk)

## 概要

<p>Amazon Interactive Video Service（Amazon IVS）のLinuxブロードキャストSDKは、IVS Real-Time Streaming用に利用可能になりました。Linux上で動作するアプリケーションはIVSステージに参加し、参加者の音声をリアルタイムで受信し、ステージへ音声を返すことができます。SDKはC APIとGo言語のバインディングを提供します。</p>
<p>LinuxブロードキャストSDKは、音声を処理してライブストリームを高度化するAIアプリケーション（文字起こし、翻訳、コンテンツモデレーションなど）や、音声アシスタントを含む音声ベースのユースケースに最適です。</p>
