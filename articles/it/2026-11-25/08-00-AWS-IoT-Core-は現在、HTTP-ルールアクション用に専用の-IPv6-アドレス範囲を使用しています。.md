# AWS IoT Core は現在、HTTP ルールアクション用に専用の IPv6 アドレス範囲を使用しています。

- **カテゴリ**: it
- **公開日時**: 2026年11月25日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/aws-iot-core-dedicated-ipv6-ranges/](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-iot-core-dedicated-ipv6-ranges/)

## 概要

<p><a href="https://aws.amazon.com/iot-core/">AWS IoT Core</a>は、専用の公開IPv6アドレス範囲内のHTTPSエンドポイントへトラフィックを送信できるようになりました。この新機能を利用すると、HTTPSエンドポイントをAWS IoT Coreからのリクエストのみ受け付けるように設定し、他のすべてのトラフィックをブロックすることで、エンドポイントの公衆インターネットへの露出を低減できます。</p>
<p>AWS IoT Coreは、IoTデバイスを大規模に安全にAWSクラウドへ接続し、IoTデバイスデータをAWSおよびサードパーティへルーティングする、完全管理型のサービスです。</p>
