# Amazon EC2 X8i インスタンスは、アジア太平洋（ニュージーランド）リージョンで利用可能になりました。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月23日 23:21
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-ec2-x8i-new-zealand/](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-ec2-x8i-new-zealand/)

## 概要

本日より、Amazon Elastic Compute Cloud（Amazon EC2） X8i インスタンスが Asia Pacific (New Zealand) リージョンで利用可能になります。これらのインスタンスは AWS 専用のカスタム Intel Xeon 6 プロセッサにより動作します。X8i インスタンスは SAP 認証を受けており、クラウド環境で同等の Intel プロセッサの中で最高のパフォーマンスと最速のメモリ帯域を実現します。従来世代と比較して最大43%のパフォーマンス向上、メモリ容量1.5倍（最大6TB）、メモリ帯域幅3.3倍を実現します。
