# AWSセキュリティエージェントは現在、ペネトレーションテストのためのメールベースのMFAをサポートします。

- **カテゴリ**: it

## 概要

AWS Security Agent（現在は AWS Continuum の一部） は、メールベースの MFA をログインフローに組み込んでいるアプリケーションのペネトレーションテストを実行できるようになりました。以前は、メールで送信されるワンタイムコードや検証リンクを介して認証するアプリケーションは、エージェントにそれらのメッセージを傍受する仕組みがなかったため、自動化されたペンテストの対象外でした。今回のリリースにより、ペンテストの対象範囲が拡大されます。
