# AWS Lambda MicroVMs が、追加で7つの AWS リージョンで利用可能になりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月20日 16:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/aws-lambda-microvms-7-regions](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-lambda-microvms-7-regions)

## 概要

AWS Lambda MicroVMs が新たに7つのAWSリージョンで利用可能になりました：アジア太平洋（大阪）、アジア太平洋（ソウル）、カナダ（中部）、ヨーロッパ（ロンドン）、ヨーロッパ（パリ）、南米（サンパウロ）、US西部（北カリフォルニア）。このリリースにより、合計21のAWSリージョンで Lambda MicroVMs を利用できます。

Lambda MicroVMs は、VMレベルの分離性、ほぼ瞬時の起動・再開速度、ユーザーまたはAI生成コードの実行時の状態保持を提供するサーバーレス計算プリミティブです。
