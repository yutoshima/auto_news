# G7e インスタンスの SageMaker AI 推論におけるリージョン拡張を発表します

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年07月23日 15:04
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/07/g7e-sagemaker-ai/](https://aws.amazon.com/about-aws/whats-new/2026/07/g7e-sagemaker-ai/)

## 概要

私たちは、Amazon SageMaker AI 推論で Asia Pacific (Seoul)、Europe (London)、および Asia Pacific (Tokyo) での <a href="https://aws.amazon.com/ec2/instance-types/g7e/">Amazon EC2 G7e インスタンス</a> の利用可能性をお知らせします。G7e インスタンスは、GPU あたり最大 96 GB のメモリを搭載した最大 8 台の NVIDIA RTX PRO 6000 Blackwell Server Edition GPU、5 世代目 Intel Xeon プロセッサ、1000 Gbps を超える Elastic Fabric Adapter ネットワーク帯域を実現し、推論性能を最大で約 2.3 倍に向上させます。
