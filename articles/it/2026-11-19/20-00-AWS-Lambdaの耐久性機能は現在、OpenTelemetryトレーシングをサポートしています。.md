# AWS Lambdaの耐久性機能は現在、OpenTelemetryトレーシングをサポートしています。

- **カテゴリ**: it
- **公開日時**: 2026年11月19日 20:00

## 概要

AWS LambdaがLambda耐久関数に対するOpenTelemetry（OTel）サポートを発表しました。耐久実行を追跡し、Amazon CloudWatchや他の業界標準の可観測性ツールへトレースを出力できるようになります。これにより、システムのボトルネックを特定し、障害の根本原因をより速く突き止め、実運用環境でのワークフローの挙動を把握するのに役立ちます。

Lambda耐久関数を使用すると、堅牢で多段階のアプリケーションやAIワークフローを、最大1年間実行できるように、組み込みのチェック機能とともに構築できます。
