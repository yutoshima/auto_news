# CloudWatch PromQL アラームは現在 EC2 および Application Auto Scaling をサポートします

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月10日 03:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-cloudwatch-alarms-autoscaling-group-actions](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-cloudwatch-alarms-autoscaling-group-actions)

## 概要

<p>Prometheus Query Language（PromQL）を使用する Amazon CloudWatch アラームが、Amazon EC2 および Application Auto Scaling のステップおよびシンプルスケーリングポリシーをトリガーできるようになりました。ダッシュボードやアラートで使用しているのと同じ種類の PromQL クエリを用いて CloudWatch の OpenTelemetry 指標で EC2 Auto Scaling グループをスケールすることができます。</p> 
<p> </p> 
<p>本リリースでは、PromQL アラームは EC2 Auto Scaling のシンプルおよびステップスケーリングポリシーもサポートします。ターゲットトラッキングは現時点で PromQL 版のポリシータイプとしてサポートされていません。</p>
