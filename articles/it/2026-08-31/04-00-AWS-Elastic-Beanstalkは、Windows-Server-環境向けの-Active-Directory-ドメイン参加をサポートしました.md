# AWS Elastic Beanstalkは、Windows Server 環境向けの Active Directory ドメイン参加をサポートしました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月31日 04:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/elastic-beanstalk-active-directory-domain-join/](https://aws.amazon.com/about-aws/whats-new/2026/08/elastic-beanstalk-active-directory-domain-join/)

## 概要

AWS Elastic Beanstalkは現在、お客様がAWS Directory Serviceで管理するActive Directoryドメインに、環境内のWindows Serverインスタンスを自動的に参加させます。以前は、Elastic Beanstalk上でドメイン参加済みのWindowsワークロードを実行するには、維持管理が必要なカスタム参加スクリプトが必要でした。このリリースにより、いくつかの設定オプションを設定するだけで、環境内のすべてのインスタンス（自動スケーリングによって後から起動されるインスタンスも含む）が、アプリケーションのデプロイ前にブート時にドメインへ参加します。
