# AWS Agent Registry は現在、命名機能と公開ディスカバリ機能を提供します。

- **カテゴリ**: it
- **公開日時**: 2026年11月20日 08:00

## 概要

<p>AWSエージェントレジストリは現在、公開命名機能を提供しており、検証済みのドメイン名をエージェントやAIツールに容易に紐付けることができます。開発者やネットワーク管理者は、ドメイン所有権を証明するためのドメイン検証を実施し、検証済みドメイン名をエージェントに関連付けて、レジストリやAWSアカウントの範囲を超えた公開表示を促進します。</p>
<p>以前は、開発者がエージェント同士の発見・接続方法を手動で設定する必要があり、これが複雑さを増していました。</p>
