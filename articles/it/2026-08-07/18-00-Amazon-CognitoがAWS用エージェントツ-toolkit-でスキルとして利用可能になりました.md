# Amazon CognitoがAWS用エージェントツ toolkit でスキルとして利用可能になりました

## 概要

Amazon Cognito が現在、<a href="https://aws.amazon.com/products/developer-tools/agent-toolkit-for-aws/">Agent Toolkit for AWS</a> のコアスキル（aws-auth）として利用可能になりました。ツールキットを用いるAIコーディングエージェントは、ベストプラクティスのワークフローを使って Amazon Cognito の設定・構成・セキュリティ強化・トラブルシューティングを行い、ユーザー・AIエージェント・マイクロサービスの安全なサインインフローをより速く実装できるようになります。

Amazon Cognito (aws-auth) スキルは、ユーザープールとアプリクライアントの機能をカバーします。
