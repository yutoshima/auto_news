# AWS Organizationsは、組織ごとのRCP上限を2,000に引き上げました。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年07月22日 17:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/07/aws-organizations-resource-control-policy-limit-increase-2000](https://aws.amazon.com/about-aws/whats-new/2026/07/aws-organizations-resource-control-policy-limit-increase-2000)

## 概要

<p>AWS Organizationsは現在、1つの組織あたり最大2,000のリソースコントロールポリシー（RCP）をサポートしており、以前の1,000の上限を倍増させました。RCPは、組織のメンバーアカウント全体でリソースに対して利用可能な最大権限を集中管理することを可能にします。この割り当て上限の引上げにより、複雑で大規模なマルチアカウント環境を管理する顧客は、ポリシー上限に遭遇することなく、より細かいリソースアクセス制御を定義できるようになります。&nbsp;</p> 
<p>RCPを使用すると、外部プリンシパルの制限ができます</p>
