# Amazon RDS for SQL Serverが現在、M8idおよびR8idインスタンスをサポートします

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月12日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/rds-sqlserver-supports-m8id-r8id-instances](https://aws.amazon.com/about-aws/whats-new/2026/11/rds-sqlserver-supports-m8id-r8id-instances)

## 概要

<a href="https://aws.amazon.com/rds/sqlserver/" rel="noopener noreferrer" target="_blank">Amazon Relational Database Service (Amazon RDS) for SQL Server</a> は、現在 M8id および R8id インスタンスをサポートしています。これらのインスタンスは、AWS 専用のカスタム Intel Xeon 6 プロセッサーを搭載し、ローカル NVMe SSD ストレージを備えています。最大で 384 vCPU、3 TiB のメモリ、22.8 TB のローカル NVMe SSD ストレージにスケールします。これは、M5d および R5d インスタンスの vCPU数とメモリを4倍、ローカルストレージを6倍超に相当します。
