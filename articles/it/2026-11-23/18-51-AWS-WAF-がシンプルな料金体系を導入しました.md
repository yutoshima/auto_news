# AWS WAF がシンプルな料金体系を導入しました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月23日 18:51
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/aws-waf-introduces-simplified-pricing/](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-waf-introduces-simplified-pricing/)

## 概要

AWS WAFは、設定方法ではなく、保護している対象に合わせた簡易な料金体系を提供するようになりました。以前は、各Web ACL、各ルール、ルールグループの購読、キャパシティティアごとに別料金が発生し、セキュリティの意思決定がすべて請求計算になっていました。現在は、請求が三つの指標に基づくようになっています：保護するリソース、AWS WAFが検査するトラフィック、適用する保護レベル。これにより費用対効果の比較が容易になり、ルールの追加や変更も簡単になりました。
