# AWS Backup は現在、Amazon EKS の復元時にリソース修飾子をサポートしています

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月12日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/aws-backup-resource-modifiers-eks/](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-backup-resource-modifiers-eks/)

## 概要

本日、AWS Backupは Amazon Elastic Kubernetes Service（Amazon EKS）バックアップの復元時にリソース修飾子のサポートを発表します。リソース修飾子を使うと、復元時に Kubernetes リソースを変換できるため、復元済みクラスターをターゲット環境に適合させることができます。

EKS バックアップをアカウント間または AWSリージョン間でコピーして復元すると、復元済みクラスターには、ソース環境に結びついた参照（例：IAM ロール、データベースエンドポイント、Amazon ECR リポジトリなど）を保持することがあります。
