# アマゾン・ベドロックが OpenAI GPT モデル向けの Web 検索を開始

## 概要

本日、Amazon Bedrock上のWeb Searchの一般提供を発表します。これは完全にAWS内部で実行される組み込みのサーバー側ツールで、OpenAIモデル（GPT-5.4、GPT-5.5、GPT-5.6 Sol/Terra/Luna）が最新のWeb知識を元に回答を根拠づけられるようにし、データをAWS環境内で安全に保持しつつデータ流出ゼロを実現します。以前はウェブ根拠付けを行うには第三者の検索プロバイダーを導入し、別々のAPIキーと課金管理を行う必要がありましたが、現在はその手間が不要です。
