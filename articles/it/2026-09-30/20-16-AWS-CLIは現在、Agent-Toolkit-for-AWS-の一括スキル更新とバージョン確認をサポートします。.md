## 概要

今日は、AWS が AWS Command Line Interface (CLI) のコマンドを、<a href="https://docs.aws.amazon.com/agent-toolkit/latest/userguide/what-is-agent-toolkit.html" rel="noopener noreferrer" target="_blank">Agent Toolkit for AWS</a> の新機能2つで拡張しました。これにより、エージェントのスキルを最新の状態に保ちやすくなります。顧客は現在、aws agent-toolkit check-skill-updates を実行して、インストール済みのすべてのスキルをレジストリにある最新バージョンと比較できるようになり、aws agent-toolkit update- で更新を行えます。
