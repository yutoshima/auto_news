# Amazon CloudWatch Observability EKS アドオンは、カスタムの OpenTelemetry および Prometheus テレメトリをサポートするようになりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月20日 20:05
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/cloudwatch-eks-addon-custom-telemetry/](https://aws.amazon.com/about-aws/whats-new/2026/11/cloudwatch-eks-addon-custom-telemetry/)

## 概要

<p>本日、Amazon CloudWatch は CloudWatch Observability EKS アドオン内で自分のアプリケーションのテレメトリをサポートする機能を発表します。すでに実行している CloudWatch エージェントは、アプリケーションからのメトリクス、トレース、ログを受け付けるようになり、CloudWatch に取り込むための別のコレクターをデプロイおよび運用する必要がなくなります。</p> 
<p>OpenTelemetry SDK を使用して計測されたアプリケーションは、エージェントがデフォルトで各ノード上で提供する OTLP エンドポイントへ送信します。メトリクスは PromQL でクエリ可能な CloudWatch メトリクスとして到着します。</p>
