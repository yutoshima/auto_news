# Amazon Bedrock Advanced Prompt Optimizationは、プロンプトの短縮をサポートしました

## 概要

<p>Amazon Bedrock Advanced Prompt Optimizationは現在、プロンプトを短縮するオプション設定をサポートしています。これは評価スコアを維持または向上させながら、プロンプトの長さを短くします。Advanced Prompt Optimizationは、Amazon Bedrock上の任意のモデルに対して、独自の評価基準に基づいてプロンプトを最適化します。これまでの最適化は品質のみを重視しており、最適化後のプロンプトは元のものより長くなることが多かったです。長いプロンプトは入力トークンコストを上げ、ファーストトークンまでの時間を増やす可能性があります。</p>
