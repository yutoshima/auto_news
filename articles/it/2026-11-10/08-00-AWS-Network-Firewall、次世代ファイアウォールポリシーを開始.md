# AWS Network Firewall、次世代ファイアウォールポリシーを開始

## 概要

今日は、AWSが AWS Network Firewall の次世代ファイアウォール（NGFW）ポリシーを発表します。新しいポリシーモデルは、セキュリティチームにとってよりシンプルなポリシー構造と増加したルール容量を提供します。AWS Network Firewall は、アクセス制御と脅威検知で Amazon VPC を保護するマネージドなネットワークセキュリティサービスです。

新しいポリシーモデルは、ファイアウォールと IPS の保護を組み合わせるのではなく、層状にすることによってセキュリティ体制を強化し、ポリシーの管理をより容易にします。
