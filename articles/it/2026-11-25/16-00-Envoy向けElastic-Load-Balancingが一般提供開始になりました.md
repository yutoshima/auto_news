# Envoy向けElastic Load Balancingが一般提供開始になりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月25日 16:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/elastic-load-balancing-for-envoy-generally-available](https://aws.amazon.com/about-aws/whats-new/2026/11/elastic-load-balancing-for-envoy-generally-available)

## 概要

今日は、Envoy用のELBの正式提供を発表します。これは、オープンソースのEnvoyプロキシを実行する新しいロードバランサタイプで、Elastic Load Balancing（ELB）上で提供されます。Envoyを自前で運用するプラットフォームチームは、アップグレード、セキュリティパッチ適用、AZ間の容量を管理しますが、Envoy用ELBはこの作業を肩代わりします。各ロードバランサは専用のAmazon EC2インスタンス上でプロキシを実行し、AWS Nitro Systemからのハードウェア分離を確保しているため、Envoyのゼロデイ脆弱性がそのまま影響することはありません。
