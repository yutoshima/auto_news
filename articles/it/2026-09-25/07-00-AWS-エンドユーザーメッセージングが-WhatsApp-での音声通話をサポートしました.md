# AWS エンドユーザーメッセージングが WhatsApp での音声通話をサポートしました

- **カテゴリ**: it
- **公開日時**: 2026年09月25日 07:00

## 概要

<p><a href="https://aws.amazon.com/end-user-messaging/">AWS End User Messaging</a>は、企業が顧客との音声通話を、すでにメッセージングに使用しているのと同じ検証済みビジネスIDを使って、WhatsApp内で直接行えるようにしました。WhatsAppの音声通話を使えば、チャットスレッドから音声通話へと会話をシームレスに移動でき、別のチャネルやアプリに切り替える必要がないため、文脈を失うことはなく、顧客は会話が続くメッセージスレッド内に留まります。
