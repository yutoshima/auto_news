# Amazon WorkSpaces が NVIDIA Blackwell GPU インスタンスをサポート追加

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月16日 17:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-workspaces-nvidia-blackwell-gpu-instances/](https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-workspaces-nvidia-blackwell-gpu-instances/)

## 概要

Amazon WorkSpaces Personal と Amazon WorkSpaces Core は、NVIDIA RTX PRO 4500 Blackwell Server Edition GPU および Intel Xeon 6 プロセッサを搭載した Graphics G7 バンドルをサポートします。Graphics G7 は、前世代の Graphics G6 バンドルと比較して、グラフィックス集約型ワークロードで最大約2.1倍の性能を提供します。8 vCPU／32 GB メモリ／1 GPU から、48 vCPU／192 GB メモリ／2 GPU まで、4 つのバンドルサイズが用意されています。

Graphics G7 を使用すると、要求の厳しいプロフェッショナル作業を実行できます。
