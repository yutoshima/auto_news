# Amazon CloudFrontの標準ロギングは、CMCDと追加のログフィールドをサポートするようになりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月18日 19:28
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/cloudfront-standard-logging-cmcd-fields](https://aws.amazon.com/about-aws/whats-new/2026/11/cloudfront-standard-logging-cmcd-fields)

## 概要

<p>Amazon CloudFront の標準ログは、以前は CloudFront のリアルタイムログでのみ利用可能だった追加のアクセスログフィールドをサポートするようになりました。これらのフィールドを標準ログに含め、追加でリアルタイムログ用のデータストリームを設定することなく、Amazon S3、Amazon CloudWatch Logs、または Amazon Data Firehose に配信できます。</p>
<p>新しいフィールドには、リクエストを処理した CloudFront サーバーの IP アドレスや、トラフィックを一次配布網で区別する識別子などが含まれます。
