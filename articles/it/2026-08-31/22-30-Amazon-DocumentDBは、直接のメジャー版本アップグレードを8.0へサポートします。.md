# Amazon DocumentDBは、直接のメジャー版本アップグレードを8.0へサポートします。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月31日 22:30
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/documentdb-major-version-upgrade-8-0/](https://aws.amazon.com/about-aws/whats-new/2026/08/documentdb-major-version-upgrade-8-0/)

## 概要

<p>Amazon DocumentDB（MongoDB互換）では、現在、エンジンバージョン3.6および4.0から直接8.0へ、インプレースのメジャーバージョンアップ（MVU）をサポートしています。このアップグレード機能により、中間バージョンへのアップグレードを行う必要がなくなり、3.6または4.0のクラスタをデータ・設定・クラスタ設定を維持したままアップグレードできます。</p>
<p>8.0へアップグレードすると、最新のセキュリティパッチ、パフォーマンスの改善、そして新しい開発者機能を利用できます。</p>
