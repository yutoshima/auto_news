# AWS Neuron 2.33 はネイティブ PyTorch 対応、Neuron Observer、その他の新機能を追加します

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月21日 15:00

## 概要

AWS Neuron 2.33 が公開ベータ版で利用可能になり、AWS Trainium のネイティブ PyTorch バックエンドである TorchNeuron を導入します。標準の PyTorch API で書かれたモデルを、Amazon EC2 Trn2 および Trn3 インスタンス上で、イーガーモードまたは torch.compile を使用して実行できます。本リリースでは、Trainium のヘルス問題を1秒未満で検知し、影響を受けるノードまたはデバイスを特定する Neuron Observer も公開ベータ版として登場します。
