# Amazon EMRが Apache Spark 4.1 の長期サポートを導入

## 概要

Amazon EMRはLong Term Support（LTS）リリースを導入します。初期は emr-spark-8.1.0 および Apache Spark 4.1 です。LTSでは、Apache Spark 用 AWS ランタイムの指定バージョンに対して36か月のサポートが提供されます。Amazon EMRは、重大かつ高リスクのセキュリティ、バグ、およびデータ破損の問題に対する修正を含むLTSリリースを、入手可能性の範囲内で提供します。LTSを利用すれば、1つのリリースを長く本番の Spark ワークロードで実行し、自分のスケジュールに合わせてアップグレードできるため、追加コストは発生しません。
