# AWS Security Hub は、インストール済みソフトウェアと使用状況からリソースの重要性を推定します。

## メタデータ

- **カテゴリ**: it

- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/security-hub-resource-criticality/](https://aws.amazon.com/about-aws/whats-new/2026/11/security-hub-resource-criticality/)

## 概要

今天、AWS Security Hub はリソースの重要度のシグナルとして、インストール済みソフトウェアとリソース使用量を追加します。重要度はリソースがビジネスにとってどれだけ重要かを示すもので、Security Hub は重要度を用いて露出検出をランク付けします。こうして中央のセキュリティチームは最も重要なリソースへ影響する露出を優先できます。

Security Hub はすでにリソースのタグや名称から重要度を推定していますが、タグ付けが不十分なリソースはしばしば重要度が「不明」のままとなり、それらの影響を評価するのが難しくなります。
