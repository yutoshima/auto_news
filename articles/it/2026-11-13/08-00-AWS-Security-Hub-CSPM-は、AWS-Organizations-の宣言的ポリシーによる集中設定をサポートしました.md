# AWS Security Hub CSPM は、AWS Organizations の宣言的ポリシーによる集中設定をサポートしました

## 概要

<p><a href="https://aws.amazon.com/security-hub/cspm/">AWS Security Hub CSPM</a>は現在、AWS Organizationsの宣言型ポリシーをサポートしています。これを使用して、組織内のすべてのアカウントとリージョンに対してSecurity Hub CSPMを有効にし、どのセキュリティ標準とコントロールを有効にするかを定義できます。</p>
<p>ポリシーはすべてのアカウントとリージョンに広く適用することも、特定のアカウントとリージョンの組み合わせを対象とすることもできます。宣言型ポリシーは、各アカウントの設定をそのアカウントに紐づくポリシーと整合させるのに役立ちます。</p>
