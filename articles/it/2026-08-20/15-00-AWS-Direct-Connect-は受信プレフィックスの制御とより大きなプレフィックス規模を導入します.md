# AWS Direct Connect は受信プレフィックスの制御とより大きなプレフィックス規模を導入します

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月20日 15:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/aws-direct-connect-new-prefix-controls](https://aws.amazon.com/about-aws/whats-new/2026/08/aws-direct-connect-new-prefix-controls)

## 概要

今日は AWS Direct Connect がインバウンドプレフィックス制御を発表しました。これは、プライベートおよびトランジット VIF（仮想インターフェイス）のインバウンドルートプレフィックス割り当てを、ワークロードのニーズに基づいて管理できる新機能です。専用接続およびホスト済み接続の VIF に対して、IPv4 と IPv6 のそれぞれ最大 1,000 個のプレフィックスを割り当てられるようになりました。

以前は、Direct Connect VIF は、プライベートまたはトランジット VIF へ AWS に対してオンプレミスネットワークから広告されるルートプレフィクスを最大 100 個まで受け付けていました。
