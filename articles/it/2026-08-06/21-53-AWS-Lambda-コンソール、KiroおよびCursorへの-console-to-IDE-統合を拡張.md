# AWS Lambda コンソール、KiroおよびCursorへの console-to-IDE 統合を拡張

## 概要

AWS Lambda コンソールは、Kiro および Cursor IDE のサポートを追加したコンソール-to-IDE 統合を拡張しました。この拡張は、VS Code での既存のコンソール-to-IDE 移行をベースにしており、サーバーレス開発者がこれらの人気IDEを使用してクラウドとローカル開発環境をシームレスに切り替えられるようにします。

拡張されたコンソール-to-IDE 統合により、開発者は Lambda コンソールから始め、ガイド付きセットアップに従って Kiro または Cursor でのローカル開発を開始できます。
