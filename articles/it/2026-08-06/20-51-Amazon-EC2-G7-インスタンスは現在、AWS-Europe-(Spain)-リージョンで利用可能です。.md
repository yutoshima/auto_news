# Amazon EC2 G7 インスタンスは現在、AWS Europe (Spain) リージョンで利用可能です。

## 概要

Amazon Elastic Compute Cloud（Amazon EC2）G7インスタンスは、NVIDIA RTX PRO 4500 Blackwell Server Edition GPUを搭載し、ヨーロッパ（スペイン）リージョンで提供開始されました。G7インスタンスは、G6インスタンスと比較してAI推論性能を最大4.6倍、グラフィックス性能を最大2.1倍向上させます。G7インスタンスは、GPU加速データ分析ワークロードのパフォーマンスも向上させます。

顧客は、言語翻訳、動画および画像分析、音声認識などのAIモデルを展開するためにG7インスタンスを利用できます。
