# Grok 4.7 が AWS GovCloud (US) の Amazon Bedrock で利用可能になりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月19日 13:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-bedrock-grok-4-7-govcloud/](https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-bedrock-grok-4-7-govcloud/)

## 概要

<p>Amazon Bedrockは現在、SpaceXAI Grok 4.7をサポートしています。これは、AWS GovCloud (US) でのコーディング、エージェント的タスク、知識作業向けのフロンティアモデルです。</p>
<p>Grok 4.7はGrok 4.6を土台に、複数文書の取り扱いを改良し、計画とエラー回復機能を備えたリポジトリ規模のコーディングをより安定させ、フォーム入力やポータルナビゲーションのためのブラウザ使用エージェントを強化しました。</p>
<p>Grok 4.7の開始方法は、<a href="https://console.amazonaws-us-gov.com/bedrock/">Amazon Bedrockコンソール</a>またはプログラム的に行えます。</p>
