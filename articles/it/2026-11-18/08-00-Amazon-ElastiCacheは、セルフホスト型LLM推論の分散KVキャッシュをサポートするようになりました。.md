# Amazon ElastiCacheは、セルフホスト型LLM推論の分散KVキャッシュをサポートするようになりました。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月18日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/announcing-distributed-kv-caching-for-self-hosted-llms-with-amazon-elasticache/](https://aws.amazon.com/about-aws/whats-new/2026/11/announcing-distributed-kv-caching-for-self-hosted-llms-with-amazon-elasticache/)

## 概要

Amazon ElastiCache for Valkeyは現在、完全に管理された分散KVキャッシュを提供します。新機能として、セルフホスト型の大規模言語モデル（LLM）の推論コストを最大40%削減し、ファーストトークンまでの時間（TTFT）を最大80%短縮します。セルフホストでLLMを運用する顧客は、各サーバーにある小さく孤立したキャッシュが成長するコンテキストを保持・共有できないため、冗長なGPU作業に対して費用を支払います。AIエージェントやチャットアプリが再送するデータの増大に対応できないからです。
