# Claude Opus 5 は現在 AWS GovCloud (US) で利用可能です

## 概要

AWS GovCloud (US)は現在、Claude Opus 5を提供します。これまでで最も高度なOpusモデルであり、データ保持ゼロ（ZDR）に対応しているため、最高レベルでのチーム開発を可能にするコーディング、長時間実行されるエージェント、そして複雑な専門作業に新たな一歩をもたらします。Claude Opus 5は、AWS GovCloud (US)の両地域でbedrock-runtimeエンドポイントを通じて利用可能で、さらにAWS GovCloud (US-Westのbedrock-mantleエンドポイント)を通じても利用可能です。

Claude Opus 5は、コーディングと理解の進歩をもたらします。
