# Amazon RDSは現在、ストレージボリュームの初期化状況を可視化します

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月06日 16:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-rds-storage-volume-initialization-visibility](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-rds-storage-volume-initialization-visibility)

## 概要

<p>Amazon RDS は、スナップショットから作成されたデータベースストレージボリュームの初期化状況を可視化できるようになりました。この状態を用いて、復元後にストレージが完全に初期化され、レイテンシに敏感なデータベースワークロードを完全に提供可能なパフォーマンスでサポートできる状態になる時期を判断できます。<br /> <br /> データベースインスタンスをポイントインタイムへ復元する場合、リードレプリカの作成、または Single-AZ から Multi-AZ への変換を行う場合、Amazon RDS はストレージボリュームを作成します。
