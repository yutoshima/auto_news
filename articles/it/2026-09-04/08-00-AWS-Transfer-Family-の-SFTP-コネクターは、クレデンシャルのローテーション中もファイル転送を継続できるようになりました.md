# AWS Transfer Family の SFTP コネクターは、クレデンシャルのローテーション中もファイル転送を継続できるようになりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月04日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/09/transfer-family-sftp-credential-rotation/](https://aws.amazon.com/about-aws/whats-new/2026/09/transfer-family-sftp-credential-rotation/)

## 概要

<p>AWS Transfer Family SFTP コネクターは、リモート SFTP サーバーの認証に使用する資格情報を回転させても、ファイル転送を継続して実行します。資格情報が回転するたびに新しいシークレットバージョンを指すようコネクターを更新する手動の手順が不要になり、回転ウィンドウ中の転送失敗を回避するのに役立ちます。</p>
<p>コネクターは現在のバージョンや前のバージョンなど、AWS Secrets Manager のバージョンステージの並べ替えられたリストから資格情報を取得できるようになりました。</p>
