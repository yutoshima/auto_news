# Amazon GameLift Streams は、ストリーム URL を共有する機能に対応しました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月03日 20:24
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-gamelift-streams/](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-gamelift-streams/)

## 概要

<p>Amazon GameLift Streamsは現在、ストリームURLを提供します。これにより、対応ブラウザで playable なストリームセッションへ、エンドユーザーが一時的かつ認証不要でアクセスできます。受信者はAWSアカウントも認証情報も、ソフトウェアのインストールも不要です。</p>
<p> playable なストリームを共有するには、ストリームグループとそのアプリケーションのストリームURLを作成し、ストリームURLの有効期間と開始できるセッション数を設定してリンクを送信します。リンクを開く各人は、それぞれ独立したストリームセッションを開始します。</p>
