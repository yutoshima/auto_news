# Amazon ECSは、EC2コンピュートタイプに対するS3ファイルのサポートを拡張します

## 概要

<p><a href="https://aws.amazon.com/ecs/">Amazon Elastic Container Service</a>（Amazon ECS）は、Amazon EC2 起動タイプで実行されるタスク向けに Amazon S3 Files をサポートするようになり、コンテナ化されたアプリケーションを Amazon S3 のデータへ共有ファイルシステムとして直接接続できるようになりました。このリリースにより、EC2 インスタンス上で ECS ワークロードを実行する顧客は、標準的なファイルシステムの挙動を用いて S3 データを扱えるようになり、ファイルベースのアプリケーション、AI エージェント、データ処理ワークロードが S3 上で動作します。</p>
