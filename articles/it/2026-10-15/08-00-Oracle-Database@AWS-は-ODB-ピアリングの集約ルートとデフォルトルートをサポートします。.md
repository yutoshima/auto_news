# Oracle Database@AWS は ODB ピアリングの集約ルートとデフォルトルートをサポートします。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月15日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/oracle-database-aws-aggregate-routes-odb/](https://aws.amazon.com/about-aws/whats-new/2026/10/oracle-database-aws-aggregate-routes-odb/)

## 概要

Oracle Database@AWS（ODB）は現在、Amazon VPC内のアプリケーション間でのODBピアリングを設定し、ODBネットワークのデータベースに対して広告された集約ルートとデフォルトルート（0.0.0.0/0）をサポートしています。これにより、顧客が新しいVPCやオンプレミスネットワークを拡張してデータベースに到達する際、それぞれのネットワークがODBネットワークに接続するために広告するCIDRを個別に更新する必要がなく、ネットワーク運用が簡素化されます。

以前は、ODBネットワークに到達する各ネットワークを広告する必要がありました。
