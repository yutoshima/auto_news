# AWS Storage Gateway は、テープおよびボリューム ゲートウェイの FIPS 準拠プライベート接続をサポートします。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月19日 10:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/storage-gateway-fips-privatelink/](https://aws.amazon.com/about-aws/whats-new/2026/08/storage-gateway-fips-privatelink/)

## 概要

<p>AWS Storage Gatewayは、Tape GatewayとVolume Gateway向けに、AWS PrivateLink経由のFIPS 140-3認証エンドポイントをサポートしました。これまでFIPSエンドポイントは公開インターネット経由のみ利用可能でした。これにより、FIPS準拙なトラフィックをプライベートなAWSネットワーク内にとどめ、規制のあるワークロード用にStorage Gatewayの利用を容易にします。</p> 
<p>このローンチにより、Tape GatewayおよびVolume Gatewayは、VPC内のインターフェース型VPCエンドポイントを介して、Storage Gatewayのサービスエンドポイントにプライベートに到達できるようになります。</p>
