# AWS Network Firewallは現在、Route 53解決済みIP検証に対応しています。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月21日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/network-firewall-route-53-ip-validation/](https://aws.amazon.com/about-aws/whats-new/2026/10/network-firewall-route-53-ip-validation/)

## 概要

<p>AWS Network Firewall は現在、IP 検証をサポートしており、HTTP/HTTPS のみならず SFTP や SSH などのプロトコルに対してもドメインベースのフィルタリングを拡張します。この新機能は、接続先の IP アドレスが VPC の Amazon Route 53 VPC Resolver を通じて解決されたことを検証し、クライアントがドメインルールを回避できたセキュリティ上のギャップを埋めます。</p> 
<p>この機能により、Network Firewall の顧客は HTTP/HTTPS のみならず、任意のプロトコルに対してドメリ ンフィルタリングルールを実装できるようになり、より柔軟なセキュリティを提供します。</p>
