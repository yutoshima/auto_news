# ギリシャ・アテネに新しい AWS Local Zone の一般提供開始を発表します

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年07月20日 14:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/07/aws-local-zone-athens-greece/](https://aws.amazon.com/about-aws/whats-new/2026/07/aws-local-zone-athens-greece/)

## 概要

本日、AWSはギリシャ・アテネに新しいローカルゾーンの正式提供を発表します。アテネのローカルゾーンはEMEAで2番目のローカルゾーンで、Amazon Simple Storage Service（Amazon S3）およびAmazon Elastic Block Store（Amazon EBS）ローカルスナップショットをサポートしており、データをギリシャ国内に保存・処理することで地域データ居住要件の遵守を支援します。

アテネのローカルゾーンは、C7i、M7i、R7iインスタンスを搭載したAmazon Elastic Compute Cloud（Amazon EC2）、およびAmazon S3をサポートします。
