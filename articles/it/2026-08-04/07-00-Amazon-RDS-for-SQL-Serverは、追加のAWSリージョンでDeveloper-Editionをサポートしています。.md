# Amazon RDS for SQL Serverは、追加のAWSリージョンでDeveloper Editionをサポートしています。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月04日 07:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/07/rds-sql-server-supports-developer-edition-in-additional-aws-regions/](https://aws.amazon.com/about-aws/whats-new/2026/07/rds-sql-server-supports-developer-edition-in-additional-aws-regions/)

## 概要

Amazon Relational Database Service（Amazon RDS） for SQL Server Developer Edition が、以下の13地域で利用可能になりました：アジア太平洋地域（香港、台北、ハイデラバード、ジャカルタ、マレーシア、メルボルン、ニュージーランド、タイ）／カナダ西部（カルガリー）／ヨーロッパ（ミラノ、スペイン）／イスラエル（テルアビブ）／メキシコ（セントラル）。 SQL Server Developer Edition には Enterprise Edition のすべての機能が含まれます。
