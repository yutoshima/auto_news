# AWS DevOps Agent は現在、Slack のコードチャンネルと Microsoft Teams の双方向会話をサポートします。

## 概要

AWS DevOps Agentは、専用のSlackコードチャンネルとMicrosoft Teamsでの双方向会話をサポートするようになりました。これにより、オンコールのエンジニアやDevOpsチームが、すでに共同作業しているインシデントを調査・解決できます。AWS DevOps Agentは、AWS、マルチクラウド、オンプレミス環境全体のインシデントを調査します。

Slackコードチャンネルは、各調査に専用のチャンネルを提供します。調査カードで「Open in code channel」を選択すると、チームとエージェントがその調査に取り組みます。
