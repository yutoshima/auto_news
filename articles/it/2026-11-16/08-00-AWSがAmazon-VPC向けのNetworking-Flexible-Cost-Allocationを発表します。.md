# AWSがAmazon VPC向けのNetworking Flexible Cost Allocationを発表します。

## メタデータ

- **カテゴリ**: it
- **公開日時**: 2026年11月16日 08:00

## 概要

Amazon Virtual Private Cloud（VPC）は現在、Networking Flexible Cost Allocation（FCA）をサポートしています。FCA は、実際に費用を生み出すリソースごとに共有ネットワーク費用を分割するため、各チームやアプリケーションの利用状況を把握できます。これまでは、CUR（Cost and Usage Report、AWS Cost and Usage Report）、および AWS Data Exports の CUR 2.0 を含むものが、ネットワークの利用を1つの項目として表示しており、ほとんどの顧客はカスタムスクリプトでチームごとに分けていました。
