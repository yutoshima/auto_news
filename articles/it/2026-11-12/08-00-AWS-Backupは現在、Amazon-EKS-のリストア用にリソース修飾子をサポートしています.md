# AWS Backupは現在、Amazon EKS のリストア用にリソース修飾子をサポートしています

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月12日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/aws-backup-resource-modifiers-eks/](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-backup-resource-modifiers-eks/)

## 概要

本日、AWS Backupは Amazon Elastic Kubernetes Service（Amazon EKS）のバックアップを復元する際のリソース修飾子のサポートを発表します。リソース修飾子は復元中に Kubernetes リソースを変換できるため、復元されたクラスターをターゲット環境に適合させることができます。

アカウント間または AWS リージョン間でコピーされた EKS バックアップを復元する場合、復元後のクラスターにはソース環境に結びついた参照情報（IAM ロール、データベースエンドポイント、Amazon ECR の参照など）が含まれることがあります。
