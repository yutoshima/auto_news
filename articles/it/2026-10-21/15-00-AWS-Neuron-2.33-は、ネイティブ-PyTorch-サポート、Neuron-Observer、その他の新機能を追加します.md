# AWS Neuron 2.33 は、ネイティブ PyTorch サポート、Neuron Observer、その他の新機能を追加します

## 概要

AWS Neuron 2.33 が公開ベータとして利用可能になり、AWS Trainium のネイティブ PyTorch バックエンドである TorchNeuron を導入します。標準の PyTorch API で書かれたモデルを、Amazon EC2 Trn2 および Trn3 インスタンス上で、イ―ジャー実行モードまたは torch.compile を用いて実行できます。本リリースには公開ベータの Neuron Observer も導入されており、Trainium のヘルス問題を1秒未満で検知し、影響を受けるノードやデバイスを特定します。
