# CloudWatch PromQL アラームは現在、EC2 と Application Auto Scaling をサポートしています。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月10日 03:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-cloudwatch-alarms-autoscaling-group-actions](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-cloudwatch-alarms-autoscaling-group-actions)

## 概要

Amazon CloudWatch のアラームで Prometheus Query Language（PromQL）を使用すると、Amazon EC2 および Application Auto Scaling のステップおよびシンプルスケーリングポリシーをトリガーできるようになりました。CloudWatch の OpenTelemetry 指標で、ダッシュボードやアラートで使用するのと同じタイプの PromQL クエリを使用して、EC2 Auto Scaling グループをスケールできます。

このリリースでは、PromQL アラームは EC2 Auto Scaling のシンプルおよびステップスケーリングポリシーもサポートします。ターゲットトラッキングは現時点では PromQL のポリシータイプとしてサポートされていません。
