# AWS Glue Data Catalogは、カタログとデータベースのデータ品質モニタリングを導入します。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月20日 19:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/glue-catalog-data-quality-monitoring/](https://aws.amazon.com/about-aws/whats-new/2026/11/glue-catalog-data-quality-monitoring/)

## 概要

AWS Glue Data Catalogは、AWS Glue Data Qualityによって推進されるカタログとデータベースのデータ品質モニタリングを導入します。単一の設定からカタログ規模でテーブルをプロファイルし評価します。カタログやデータベース、あるいは単一テーブルに対してデータ品質チェックを一度定義すれば、AWS Glue Data Qualityが対象範囲内のすべてのテーブル（後から追加されたテーブルも含む）を、選択したペースで評価します。品質の問題はデータに変化が生じた際に表面化し、テーブルごとの設定や手動実行を必要とせず、継続的な品質監視を実現します。
