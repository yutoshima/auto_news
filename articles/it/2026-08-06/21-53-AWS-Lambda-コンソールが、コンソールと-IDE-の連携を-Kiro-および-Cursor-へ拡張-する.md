# AWS Lambda コンソールが、コンソールと IDE の連携を Kiro および Cursor へ拡張 する

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月06日 21:53
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/aws-lambda-ide-kiro-cursor/](https://aws.amazon.com/about-aws/whats-new/2026/08/aws-lambda-ide-kiro-cursor/)

## 概要

AWS Lambda コンソールは、Kiro および Cursor IDE のサポートに向けて、コンソールと IDE の統合機能を拡張しました。これは、既存の Visual Studio Code（VS Code）向けのコンソール-to-IDE 移行を土台に、これらの人気 IDE を使用するサーバーレス開発者がクラウドとローカル開発環境をシームレスに切り替えられるようにするものです。

拡張されたコンソール-to-IDE 統合により、開発者は Lambda コンソールから開始し、Kiro または Cursor でのローカル開発を開始するためのガイド付き設定を進めることができます。
