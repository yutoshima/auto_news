# Amazon S3 Tablesは、Apache Iceberg V3 に対してVariantデータ型をサポートしました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年07月28日 07:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/07/amazon-s3-tables-variant-iceberg-v3/](https://aws.amazon.com/about-aws/whats-new/2026/07/amazon-s3-tables-variant-iceberg-v3/)

## 概要

<p>Amazon S3 Tablesは現在、Apache Iceberg Version 3（V3）仕様で定義されたVariantデータ型をサポートしています。事前に固定スキーマを定義することなく、JSONのような半構造化データを直接S3 Tablesに書き込めるようになり、より速くデータを格納しつつ、効率的な分析クエリのパフォーマンスを維持できます。<br /> <br /> Variantデータ型を使うと、Apache Iceberg V3対応のエンジンが半構造化データを書き込み時に隠し列として分解し、Parquetのカラム列の形で生成します</p>
