# AWS HealthOmics は現在、IAMセッションポリシーをサポートしています。

- **カテゴリ**: it
- **公開日時**: 2026年09月17日 18:32

## 概要

<p>AWS HealthOmics は現在 IAMセッションポリシーをサポートしており、複数の IAMロールを作成・管理することなく、個々の実行の権限を制限できるようになりました。これまでは、単一の実行に対して動的に権限を絞る方法がなく、テナントごとまたは実行ごとに別々の IAM ロールを作成する必要がありました。AWS HealthOmics は HIPAA適格サービスで、医療・ライフサイエンスのお客様が完全管理のバイオインフォマティクスワークフローを活用して科学的なブレークスルーを加速するのを支援します。</p>
