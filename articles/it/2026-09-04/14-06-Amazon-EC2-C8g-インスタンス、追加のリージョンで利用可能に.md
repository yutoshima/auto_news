# Amazon EC2 C8g インスタンス、追加のリージョンで利用可能に

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月04日 14:06
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-ec2-c8g-instances-additional-regions/](https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-ec2-c8g-instances-additional-regions/)

## 概要

本日より、Amazon Elastic Compute Cloud（Amazon EC2）の C8g インスタンスが AWS アジア太平洋（台北・ニュージーランド）および AWS GovCloud（US-East）リージョンで利用可能になります。これらのインスタンスは AWS Graviton4 プロセッサを搭載し、AWS Graviton3 ベースのインスタンスと比較して最大で約30%のパフォーマンス向上を実現します。Amazon EC2 C8g インスタンスは、計算集約型ワークロード（HPC、バッチ処理、ゲーム、ビデオエンコード、科学的モデリング、分散アプリケーションなど）向けに設計されています。
