# Amazon EMR 7.14 が利用可能になりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月22日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-emr-7-14-available/](https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-emr-7-14-available/)

## 概要

<p>Amazon EMR 7.14 が、EC2 上の Amazon EMR、EKS 上の Amazon EMR、Serverless の各分野で新機能を追加するとともに、他のアプリケーションのバージョンアップを含みます。今回のリリースでは、Apache Spark を 3.5.8、Apache Iceberg を 1.10.1へアップグレードします。</p>
<p>Apache Iceberg のマテリアライズド・ビューは、更新および削除があったテーブルでのデータ変更を読み取る際に、変更データキャプチャを用いて変更に影響を受けたデータファイルのみを読み込むようになり、再計算の速度が向上します。Amazon EMR on EKS では、クラスターが Spark Connect エンドポイントをサポートするようになりました。</p>
