# AWS DataSyncのEnhancedモードは、Google CloudおよびMicrosoft Azure用のOpenID Connect (OIDC)をサポートします。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月04日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/datasync-enhanced-oidc-google-azure/](https://aws.amazon.com/about-aws/whats-new/2026/11/datasync-enhanced-oidc-google-azure/)

## 概要

AWS DataSyncのEnhancedモードは、Google Cloud StorageおよびMicrosoft Azure Blob StorageのロケーションでOpenID Connect（OIDC）認証をサポートしました。DataSyncはAWS Identity and Access Management（IAM）ロールを使用して、Google CloudまたはMicrosoft Entra IDから短命クレデンシャルを取得し、それらを自動的に更新して、転送が途切れず実行されるようにします。

これにより、長期間有効なクレデンシャル（ハッシュベースなど）を使用せずに、DataSyncを使ってGoogle Cloud StorageおよびAzure Blob Storageにアクセスできるようになりました。
