# AWS Lambda Durable Functions が実行についてのライブ テレメトリをエクスポートするようになりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月28日 18:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/lambda-durable-telemetry/](https://aws.amazon.com/about-aws/whats-new/2026/10/lambda-durable-telemetry/)

## 概要

AWS Lambdaは、Lambda耐久関数向けのDurable Execution Telemetry Exporterプラグインを発表します。この新しい可観測性プラグインは、耐久実行の逐次履歴をキャプチャし、それを任意の1つまたは複数の宛先へ送信します。エクスポートされたデータを活用して運用・ビジネスの洞察を得たり、標準の保持期間を超えて履歴を保持したりすることができます。また、AIエージェント（例：Kiro）などがエクスポートデータを照会できるModel Context Protocol（MCP）サーバーの対になるコンパニオンもリリースします。
