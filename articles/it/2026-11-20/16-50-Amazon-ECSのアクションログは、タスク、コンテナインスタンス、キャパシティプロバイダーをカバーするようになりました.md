# Amazon ECSのアクションログは、タスク、コンテナインスタンス、キャパシティプロバイダーをカバーするようになりました

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月20日 16:50
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-ecs-action-logs-expanded-troubleshooting](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-ecs-action-logs-expanded-troubleshooting)

## 概要

<p><a href="https://aws.amazon.com/ecs/">Amazon Elastic Container Service</a>（Amazon ECS）は現在、アクションログの対象をタスク、コンテナインスタンス、クラスター、キャパシティプロバイダまで拡張しました。これにより、なぜタスクが失敗したのか、なぜクラスターが期待通りにスケールしなかったのかを確認できます。アクションログは、Amazon ECS があなたに代わって実行するアクションの、詳細でタイムスタンプ付きの記録を提供します。これまでの対象はサービスのデプロイとマネージドデーモンの更新のみでしたが、覆われる範囲が拡大したことで、タスクの失敗を診断することが可能になります。
