# AWS LambdaのマイクロVMがx86 CPUアーキテクチャに対応しました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月11日 18:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/aws-lambda-microvms-x86-architecture/](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-lambda-microvms-x86-architecture/)

## 概要

AWS Lambda MicroVMsがx86 CPUアーキテクチャをサポートするようになったため、再コンパイルやポーティングを行わずに、既存のx86アプリケーション、ツール、ソフトウェア依存関係を実行できます。MicroVMイメージを作成する際には、x86とArm（AWS Graviton）のいずれかを選択でき、ワークロードが使用するアーキテクチャで各ユーザーまたはジョブに分離されたMicroVMを提供します。

Lambda MicroVMsは、VMレベルの分離、ほぼ瞬時の起動と再開、状態の保存を提供するサーバーレス計算プリミティブです。
