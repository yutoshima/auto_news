# AWS IAM Identity Center が、マルチリージョン対応をより多くの AWS リージョンに拡張します。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月01日 07:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/aws-iam-identity-center-extends-multi-region-support-to-more-aws-regions](https://aws.amazon.com/about-aws/whats-new/2026/10/aws-iam-identity-center-extends-multi-region-support-to-more-aws-regions)

## 概要

IAM Identity Centerは、職員のIDを一度だけAWSに接続し、AWSアカウントやアプリケーションへのアクセス管理を簡素化します。現在、IAM Identity Centerを複製してAWS Regionsにオプトインすること、そしてAWS GovCloud (US) および AWS China Regions間でRegion間の複製を行うことが可能です。以前は、有効化済みの商用AWS Regionsでのみマルチリージョンのサポートが利用可能でした。これにより、AWSアカウントへのユーザーアクセスのレジリエンスを向上させ、AWS Regions内でAWSアプリケーションを展開することができます。
