# AWS Marketplace経由で購入したUbuntu Proのライセンス型の変換を、AWS License Managerが現在サポートします

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月14日 17:04
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/aws-license-manager-conversions-ubuntu-pro-marketplace/](https://aws.amazon.com/about-aws/whats-new/2026/10/aws-license-manager-conversions-ubuntu-pro-marketplace/)

## 概要

<AWS License Manager> は現在、EC2 の Ubuntu LTS（長期サポート）インスタンスを AWS Marketplace で利用可能な Ubuntu Pro へインプレースアップグレードすることをサポートしています。これにより、顧客は fleet の再構築やワークロードを新しいインスタンスや AMI に移行することなく、セキュリティ体制を強化し、コンプライアンス要件を満たすことができます。Ubuntu Pro のサブスクリプションにより、最大10年間のセキュリティパッチが提供され、15年まで延長可能です。
