# AWS Transform for mainframe は、再構想を取り入れたモダナライゼーションのワークフローを改善します。

## 概要

AWS Transform for mainframeは、メインフレーム上のビジネス機能をフィールドレベルの精度で検出し、評価と再構想のワークフローで新しい要求カバレッジレポートを生成します。以前は、同じ表やファイルを使用するビジネス機能がまとめられており、AWS Transformのアーティファクトから自分でトレーサビリティレポートを作成する必要がありました。今回のローンチにより、ビジネス機能のより正確なカタログを基にz/OS COBOLおよびPL/Iのワークロードをモダナイズし、要求事項のカバレッジを検証できるようになります。
