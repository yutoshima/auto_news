# Amazon S3 Tablesは、データレイクの近代化に向けたシンプルで費用対効果の高い道を提供します

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月04日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-s3-tables-managed-migration-hive-to-iceberg/](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-s3-tables-managed-migration-hive-to-iceberg/)

## 概要

<p>Amazon S3 Tables は、Apache Hive テーブルを Apache Iceberg に移行するためのマネージド移行を提供します。Iceberg はデータ レイクに ACID トランザクション、スキーマ進化、タイムトラベルを追加しますが、Hive からの移行には通常、テーブルごとの移行パイプラインを構築する必要があり、数週間かかることがあります。今後は S3 Tables に移行を任せることができ、データが増えるほど最適化されたままクエリ対応の Iceberg テーブルを作成できます。</p> 
<p>S3 Tables は、本番ワークロードを維持しつつ、データを検証・変換・コピーします</p>
