# AWS Entity Resolutionは、リアルタイム高度マッチングをサポートします。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年07月22日 19:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/07/aws-entity-resolution/](https://aws.amazon.com/about-aws/whats-new/2026/07/aws-entity-resolution/)

## 概要

AWS Entity Resolutionは現在、進んだマッチングワークフローを用いたリアルタイムマッチングをサポートしており、GenerateMatchId APIを通じて複雑なルールセットを用いてミリ秒単位でレコードを照合できるようになりました。これまではリアルタイムマッチングはシンプルなルールベースのワークフローに限定されており、ExactやExactManyToManyなどのオペレーターをAND/OR論理と組み合わせた高度なルールセットは、数分から数時間かかるバッチ処理でのみ使用可能でした。これにより、再照合を必要とする顧客にとって重要なギャップが生じていました。
