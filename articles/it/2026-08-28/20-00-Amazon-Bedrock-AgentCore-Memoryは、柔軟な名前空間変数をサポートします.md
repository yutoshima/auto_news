# Amazon Bedrock AgentCore Memoryは、柔軟な名前空間変数をサポートします

## 概要

<p>Amazon Bedrock AgentCore Memory では、開発者が組織、テナント、チーム、環境など、アプリケーション固有の次元に沿って長期メモリのスコープを定義する柔軟な名前空間変数を利用できるようになりました。これにより、重複する戦略を作成したり組み込み変数を過負荷させたりすることなく、マルチテナントおよび複雑な階層構造を持つアプリケーションに対して、メモリの整理・分離・アクセス方法を細かく制御できます。<br /> <br /> メモリリソース上にキーを定義し、それをストラテジ内で参照します。
