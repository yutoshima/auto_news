# Amazon RDS for MySQLは現在、MySQLのメジャー バージョン9.7に対応しています。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月18日 17:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-rds-mysql-974-available/](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-rds-mysql-974-available/)

## 概要

本日より、MySQL用Amazon RDSはMySQLメジャー Version 9.7をサポートします。これはMySQLコミュニティの最新のLong-Term Supportリリースです。RDS for MySQL 9.7はコミュニティMySQL 9.7.4で登場します。このリリースには、Replication Applier Metricsコンポーネント、JSON Duality Views、Hypergraph Optimizerのサポートが追加されます。

Replication Applier Metricsは、パフォーマンススキーマの2つのテーブルを追加して、チャンネルごとのアプライヤのバックログ、スループット、待機時間を報告することにより、レプリケーションの遅延を診断するのに役立ちます。
