# AWS Lambda デュラブル関数がカスタマー管理鍵暗号化をサポートしました

- **カテゴリ**: it

## 概要

<p>AWS Lambda の耐久的関数は now supports encryption of durable execution data with an AWS Key Management Service (AWS KMS) customer managed key. <a href="https://docs.aws.amazon.com/lambda/latest/dg/durable-functions.html">Lambda durable functions</a> は、長時間実行される信頼性のあるワークフローを、自動的な状態管理を備えた Lambda 関数コード内で直接構築できるようにします。Lambda はデフォルトで所有者キーを用いて実行状態を静止時に暗号化します。今後 AWS KMS のサポートにより、ユーザー管理キーを使用して暗号化できます。
