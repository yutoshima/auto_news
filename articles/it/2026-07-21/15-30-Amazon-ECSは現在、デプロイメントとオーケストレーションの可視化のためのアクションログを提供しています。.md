# Amazon ECSは現在、デプロイメントとオーケストレーションの可視化のためのアクションログを提供しています。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年07月21日 15:30
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/07/amazon-ecs-action-logs/](https://aws.amazon.com/about-aws/whats-new/2026/07/amazon-ecs-action-logs/)

## 概要

今日、<a href="https://aws.amazon.com/ecs/">Amazon Elastic Container Service</a>（Amazon ECS）は、新しい可観測性機能「Action Logs」を発表します。これは、サービスのデプロイや ECS Managed Daemon の更新中に、顧客の代わりに Amazon ECS が実行するアクションの、詳細でタイムスタンプ付きの記録を提供します。これまで見えなかったサービス側の操作を可視化することで、Action Logs は AWS サポートに問い合わせることなく、また手動での相関付けを行うことなく、 workloads の監視とトラブルシューティングを直接支援します。
