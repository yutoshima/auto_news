# Amazon Rekognition Face Liveness からフィードバックコードが返されるようになりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月28日 20:41
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/09/rekognition-liveness-feedback-codes/](https://aws.amazon.com/about-aws/whats-new/2026/09/rekognition-liveness-feedback-codes/)

## 概要

<p>Amazon Rekognition Face Livenessは現在、低いスコアを受けた理由とユーザーが再試行して成功するための方法を理解するのに役立つフィードバックコードを返します。これらのコードはGetFaceLivenessSessionResults APIのレスポンスで返され、照明不足、顔の遮蔽、目を閉じている状態、低い映像品質など、低スコアに寄与した具体的な条件を特定します。顧客はこれらのコードをエンドユーザーに提示することができ、エンドユーザーはターゲットを絞った修正を行うことができます。
