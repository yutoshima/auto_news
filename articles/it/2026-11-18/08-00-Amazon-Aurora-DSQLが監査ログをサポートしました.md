# Amazon Aurora DSQLが監査ログをサポートしました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月18日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-aurora-dsql-audit-logging/](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-aurora-dsql-audit-logging/)

## 概要

<a href="https://aws.amazon.com/rds/aurora/dsql/?refid=f1097432-a884-4027-abe8-3dbd6d9c5cdc">Amazon Aurora DSQL</a> は現在、データベース内監査ログをサポートしています。クラスタ内で実行されたSQL文を記録する、完全にマネージドの機能です。以前は AWS CloudTrail で誰が DSQL クラスターに接続したかは分かっても、内部で何をしたかは分かりませんでした。これにより、金融機関や規制対象の企業は、DDL・DML・DCL・SELECT 文をキャプチャすることで、運用のコンプライアンス要件を満たすことが可能になります。
