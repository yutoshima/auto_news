# AWS DataSync Enhancedモードは、FSx for OpenZFS、NFS 4.2、およびオブジェクトメタデータのコントロールをサポートするようになりました。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月13日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/datasync-enhanced-openzfs-nfs42-metadata/](https://aws.amazon.com/about-aws/whats-new/2026/10/datasync-enhanced-openzfs-nfs42-metadata/)

## 概要

AWS DataSync Enhancedモードは、Amazon FSx for OpenZFSをソースまたは宛先ロケーションとして、オンプレミスNFSサーバーおよび FSx for OpenZFSファイルシステムに対してNFSバージョン4.2をサポートするようになりました。さらに、オブジェクトストレージ転送向けの新しいObjectMetadataオプションも追加されました。以前は、FSx for OpenZFSへデータを転送する場合はBasicモードに制限されていました。

NFS 4.2を使えば、最新バージョンのNFSサーバーから再構成せずに旧プロトコルバージョンへ変換することなくデータを転送できます。ObjectMetadataオプションは、オブジェクトストレージ転送に関連します。
