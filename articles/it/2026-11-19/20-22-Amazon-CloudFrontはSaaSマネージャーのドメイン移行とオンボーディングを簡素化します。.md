# Amazon CloudFrontはSaaSマネージャーのドメイン移行とオンボーディングを簡素化します。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月19日 20:22
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/cloudfront-domain-moves-distribution-tenants](https://aws.amazon.com/about-aws/whats-new/2026/11/cloudfront-domain-moves-distribution-tenants)

## 概要

<p>Amazon CloudFront は、ウェブ開発プラットフォームや SaaS 提供者が、顧客のドメインをプラットフォームへ単一のリクエストで移行し、TLS 証明書を設定している間もドメインへのリクエストを処理できるようになりました。CloudFront のマルチテナント配信は、これらのプラットフォームが共通の設定から多数の顧客ドメインを提供できるようにします。これらの機能を組み合わせることで、既存の AWS ユーザーをマルチテナント配信へ移行させても、トラフィックへ影響を与えずに済みます。</p>
