# AWS Backup は、Amazon Neptune の論理的にエアギャップされたボールト対応を、3つの追加のAWSリージョンに拡張します。

- **カテゴリ**: it
- **公開日時**: 2026年08月06日 07:00

## 概要

AWS Backup の論理的エアギャップ付きボールト機能が、Amazon Neptune のサポート地域として、アジア太平洋（メルボルン）、ヨーロッパ（スペイン）、ヨーロッパ（チューリッヒ）の3つの追加リージョンで利用可能になりました。

この拡張により、これらのリージョンの論理的エアギャップ付きボールトに Neptune のバックアップを保存できます。論理的エアギャップ付きボールトは不変で、デフォルトでロックされており、AWS が所有するキーまたは顧客管理キーを用いて暗号化されています。バックアップをアカウント間・リージョン間でコピーしたり、リカバリのためにボールトを共有したりすることができます。
