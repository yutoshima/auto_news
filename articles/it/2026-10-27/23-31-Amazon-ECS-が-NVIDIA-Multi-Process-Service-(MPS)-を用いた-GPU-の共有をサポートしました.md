# Amazon ECS が NVIDIA Multi-Process Service (MPS) を用いた GPU の共有をサポートしました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月27日 23:31
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-ecs-gpu-sharing-nvidia-mps/](https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-ecs-gpu-sharing-nvidia-mps/)

## 概要

<p><a href="https://aws.amazon.com/ecs/" target="_blank">Amazon Elastic Container Service</a>（Amazon ECS）は現在、NVIDIA Multi-Process Service（MPS）を使用したGPU共有をサポートしており、1つのNVIDIA GPU上で複数のAmazon ECSタスクを同時に実行できます。GPU共有は、GPU全体容量の一部のみを使用するワークロード（小規模モデル推論、AV/ADASシミュレーション、埋め込み生成、マルチモデルサービングなど）に対してGPUの利用率を高め、インフラストラクチャコストを削減するのに役立ちます。</p>
