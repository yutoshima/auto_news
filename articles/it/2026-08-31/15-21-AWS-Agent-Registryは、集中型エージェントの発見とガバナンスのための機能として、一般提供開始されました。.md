## 概要

AWS Agent Registryは一般提供を開始しました。これは、組織内のエージェント、ツール、スキル、MCPサーバー、カスタムリソースのための私有かつ統治されたカタログとディスカバリ層を提供します。チームはAIの全体像を完全に把握できるため、ゼロから再構築するのではなく既存の機能を発見できます。AWS Agent Registryコンソール、AWS CLI、または AWS SDK からアクセスできます。Amazon Bedrock AgentCore、Amazon Quick（およびその他のサービス）からレジストリリソースを発見して利用することも可能です。
