# Amazon ElastiCache for Valkey が OpenTelemetry メトリクスと詳細モニタリングをサポートしました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月02日 07:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-elasticache-valkey-opentelemetry-metrics-detailed-monitoring](https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-elasticache-valkey-opentelemetry-metrics-detailed-monitoring)

## 概要

<p><a href="https://aws.amazon.com/elasticache/">Amazon ElastiCache</a> for Valkey は、ノードベースのクラスター向けに OpenTelemetry 指標を Amazon CloudWatch に公開するようになり、各指標には Prometheus Query Language（PromQL）式でフィルタリング・集計できる属性が含まれます。ElastiCache は現在、2 つの監視モードを提供します。従来の標準監視は現行の体験で、CloudWatch Metrics（Classic）を 60 秒ごとに公開し続け、さらにコアの OpenTelemetry 指標セットを公開します。
