# Amazon VPC Flow Logs が現在、Amazon EKS のメタデータをサポートします

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月19日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-vpc-flow-logs-amazon-eks-metadata/](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-vpc-flow-logs-amazon-eks-metadata/)

## 概要

<p>Amazon VPC Flow Logs は現在、フローログレコードに Amazon Elastic Kubernetes Service（Amazon EKS）のメタデータを追加します。各レコードは、トラフィックを送信または受信したポッドと、それが所属するクラスター、名前空間、ラベルを特定します。これにより、セキュリティイベントの調査、トラフィックパターンの把握、EKS クラスタ内のネットワーク問題のトラブルシュートを、ノード上でモニタリングソフトウェアを実行することなく、より迅速に行えるようになります。</p>
<p>Amazon EKS は、ノードと呼ばれる Amazon EC2 インスタンス上でポッドを実行します。多くのポッドが共有する</p>
