# Amazon EMR on EKS が IPv6 対応の Amazon EKS クラスタをサポートしました。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月23日 15:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-emr-eks-ipv6-support](https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-emr-eks-ipv6-support)

## 概要

本日、AWSは Amazon EMR on EKS が IPv6 対応の Amazon Elastic Kubernetes Service (Amazon EKS) クラスター上でのワークロード実行をサポートするようになったことを発表します。EMR on EKS はデータプラットフォームおよび分析チームが Apache Spark や Apache Flink などのオープンソースのビッグデータフレームワークを Amazon EKS 上で実行できるようにします。IPv6 対応により、大規模に運用するチームは IPv6 のクラスター上でこれらのワークロードを実行できるようになり、分析ワークロードが拡大するにつれてはるかに広いアドレス空間を活用できます。
