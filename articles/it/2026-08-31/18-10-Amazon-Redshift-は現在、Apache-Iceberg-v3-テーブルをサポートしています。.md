# Amazon Redshift は現在、Apache Iceberg v3 テーブルをサポートしています。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月31日 18:10
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-redshift-supports-apache-iceberg-v3](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-redshift-supports-apache-iceberg-v3)

## 概要

<p>Amazon Redshiftは現在、データレイク内のApache Iceberg v3テーブルの読み取りと書き込みをサポートしています。Apache Icebergはオープンなテーブル形式で、v3リリースにはいくつかの新機能が追加されています。本リリースにより、Amazon Redshiftはデフォルト列値、行系譜、削除ベクトルのサポートを導入します。デフォルト列値を使えば、値が提供されない場合に適用される初期値を定義でき、既存のテーブルへ列を追加する際のスキーマ進化を容易にします。
