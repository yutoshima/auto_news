# Amazon EC2 C8gインスタンスが他のリージョンで利用可能になりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月04日 14:06
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-ec2-c8g-instances-additional-regions/](https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-ec2-c8g-instances-additional-regions/)

## 概要

本日より、Amazon Elastic Compute Cloud（Amazon EC2）の C8g インスタンスが AWS Asia Pacific（台北／ニュージーランド）と AWS GovCloud（US-East）リージョンで利用可能になります。これらのインスタンスは AWS Graviton4 プロセッサを搭載し、AWS Graviton3 ベースのインスタンスと比較して最大で約30%の性能向上を実現します。Amazon EC2 C8g インスタンスは、高性能計算（HPC）、バッチ処理、ゲーム、動画エンコード、科学的モデリング、分散システムなど、計算集約型ワークロード向けに設計されています。
