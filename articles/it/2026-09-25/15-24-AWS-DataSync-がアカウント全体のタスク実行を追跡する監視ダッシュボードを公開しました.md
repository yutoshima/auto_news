# AWS DataSync がアカウント全体のタスク実行を追跡する監視ダッシュボードを公開しました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月25日 15:24
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/09/datasync-monitoring-dashboard](https://aws.amazon.com/about-aws/whats-new/2026/09/datasync-monitoring-dashboard)

## 概要

AWS DataSync は現在、DataSync コンソールに監視ダッシュボードを提供しており、アカウント全体のデータ転送の状況を可視化します。各タスク実行について、ステータス、データとファイル転送速度、所要時間、転送されたデータ量とファイル数を確認できます。実行をステータス、タスク、タスクモード、実行ID、開始時刻でフィルタリングして、特定の実行セットに絞り込むことも可能です。ダッシュボードは、フィルタリング後の結果を要約し、成功した実行数と失敗した実行数などを示します。
