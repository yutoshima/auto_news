# AWS Security Hubは現在、計算リソースのSBOMインベントリを提供しています

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月06日 00:30
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/security-hub-sbom-inventory/](https://aws.amazon.com/about-aws/whats-new/2026/11/security-hub-sbom-inventory/)

## 概要

本日、AWSは AWS Security Hub が SBOM（Software Bill of Materials）インベントリを提供開始したことを発表しました。これにより、中央のセキュリティチームは組織全体で、計算リソースにインストールされているソフトウェアパッケージやアプリケーションを継続的に更新されるビューで把握できます。

Security Hub は、Amazon Inspector が Amazon EC2 インスタンス、Amazon ECR コンテナイメージ、AWS Lambda 関数向けに生成する SBOM からインベントリを構築します。追加の設定は不要です。SBOM ページには各パッケージが一覧表示されます。
