# AWS WAF、Amazon CloudFront 配布用の自動 SDK 統合を発表

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月30日 15:57
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/aws-waf-automatic-sdk-integration-amazon-cloudfront/](https://aws.amazon.com/about-aws/whats-new/2026/10/aws-waf-automatic-sdk-integration-amazon-cloudfront/)

## 概要

AWS WAFは、Amazon CloudFront分配に対する自動SDK統合を発表します。有効にすると、CloudFrontは提供するHTMLにAWS WAF JavaScript SDKのスクリプトタグを追加します。これにはアプリケーションコード、ビルドプロセス、デプロイに変更は伴いません。SDKは、3つのAWS WAFマネージドルールグループが使用するクライアントサイドのシグナルを提供します。対象検査レベルでのBot Control、アカウント乗っ取り防止（ATP）、アカウント作成詐欺防止（ACFP）です。
