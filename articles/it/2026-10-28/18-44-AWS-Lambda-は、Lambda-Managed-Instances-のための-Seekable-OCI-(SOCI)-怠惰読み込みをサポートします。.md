# AWS Lambda は、Lambda Managed Instances のための Seekable OCI (SOCI) 怠惰読み込みをサポートします。

## メタデータ

- **カテゴリ**: it
- **公開日時**: 2026年10月28日 18:44

## 概要

AWS Lambdaは現在、Open Container Initiative (OCI) イメージとしてパッケージ化されたイベント関数を遅延読み込みするための Seekable OCI（SOCI）をサポートしています。これらは Lambda Managed Instances 上で実行されます。SOCI のサポートにより、実行環境の起動段階ごとに必要なファイルだけを取得し、全ファイルをダウンロードするのを回避します。
