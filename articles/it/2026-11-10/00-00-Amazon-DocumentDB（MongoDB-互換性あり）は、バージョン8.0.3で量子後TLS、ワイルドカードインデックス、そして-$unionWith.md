## 概要

<p>Amazon DocumentDB（MongoDB 互換性を備えた）8.0.3 は、TLS の量子後対応のハイブリッド鍵交換、ワイルドカードインデックス、$unionWith 集約ステージ、および新しい変更ストリームイベントを追加します。量子後TLS は、現在記録され、後に量子コンピュータで復号される可能性のあるトラフィックからデータを転送中に保護します。新しい MongoDB API を使えば、アプリケーションコードを変更することなく、より多くの MongoDB ワークロードを Amazon DocumentDB へ移行できます。</p>

 <li><p>量子後 TLS：TLS 1.3 接続</p></li>
