# Amazon S3 Tablesは、データレイクのモダナイゼーションに向けた、シンプルで費用対効果の高い道を提供します。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月04日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-s3-tables-managed-migration-hive-to-iceberg/](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-s3-tables-managed-migration-hive-to-iceberg/)

## 概要

<p>Amazon S3 Tablesは、Apache HiveテーブルをApache Icebergへ移行するマネージド移行機能を提供します。IcebergはデータレイクにACIDトランザクション、スキーマ進化、タイムトラベルを追加しますが、Hiveを離れる移行には通常、各テーブルごとに移行パイプラインを構築する必要があり、数週間かかることがあります。今はS3 Tablesに移行を任せることができ、データが増えても最適化されたままクエリ準備完了のIcebergテーブルを得られます。</p> 
<p>S3 Tablesは、データを検証・変換・コピーしつつ、生産ワークロードを停止させずに処理します。</p>
