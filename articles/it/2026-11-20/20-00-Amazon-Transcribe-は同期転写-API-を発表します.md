# Amazon Transcribe は同期転写 API を発表します

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月20日 20:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-transcribe-sync-api/](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-transcribe-sync-api/)

## 概要

Amazon Transcribeは現在、同期転写API「TranscribeAudio」を提供しています。1回のリクエストで完結した音声ファイルを送信すると、同じレスポンスで完全な文字起こしを受け取れます。開始するジョブはなく、ポーリングするステータスもなく、管理する接続もありません。文字起こしはAmazon Transcribeのバッチ転写と同じく高い精度を持つため、音声アシスタントやエージェント支援ツール、オンデマンドの「このクリップを文字起こしして」のような対話型アプリケーションに迅速で正確な音声認識を組み込むことができます。
