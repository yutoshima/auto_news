# Amazon EC2 C9g インスタンスが、追加のリージョンで利用可能になりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月25日 16:17
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-ec2-c9g-instances-additional-regions/](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-ec2-c9g-instances-additional-regions/)

## 概要

本日より、Amazon EC2（Amazon Elastic Compute Cloud）の C9g インスタンスが、アジア太平洋（シドニー）、ヨーロッパ（アイルランド、スペイン）、南米（サンパウロ）リージョンで利用可能になります。これらのインスタンスは、AWS Graviton5 プロセッサを搭載しており、カスタム設計の CPU の第5世代で、Amazon EC2 上で実行される幅広いワークロードに対して、最高の価格性能を提供します。

C9g インスタンスは、最大で 25% のベターなコンピュート性能を提供します。
