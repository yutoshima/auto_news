# Amazon Bedrock AgentCore Memoryは、細かなアクセス制御に対応しました。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月28日 20:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/agentcorememory-fine-grained-access-control](https://aws.amazon.com/about-aws/whats-new/2026/08/agentcorememory-fine-grained-access-control)

## 概要

<p>Amazon Bedrock AgentCore Memoryは現在、細粒度のアクセス制御（FGAC）をサポートしており、AgentCore Gatewayを介してカスタム承認ロジックを構築することなく、ユーザーごと・テナントごとのメモリ分離を強制できます。</p>
<p><br /> FGACを使用すると、OAuth（JWT）認証を設定したAgentCore GatewayでMemoryリソースを保護し、認証された呼び出し元の身元情報に基づいてアクセスを制限する Cedar ポリシーを結合することができます。各ユーザーが自分自身のデータにだけアクセスすることを強制できます。
