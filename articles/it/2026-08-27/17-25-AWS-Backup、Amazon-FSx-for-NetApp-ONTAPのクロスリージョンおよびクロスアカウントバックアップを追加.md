# AWS Backup、Amazon FSx for NetApp ONTAPのクロスリージョンおよびクロスアカウントバックアップを追加

- **カテゴリ**: it

## 概要

AWS Backupは現在、Amazon FSx for NetApp ONTAPのバックアップをAWSリージョン間およびアカウント間でコピーできるようになりました。ポリシーベースのバックアップ計画またはオンデマンドのコピー作業を使用して、FSx for NetApp ONTAPのバックアップを別のAWSリージョン、別のAWSアカウント、またはその両方へコピーできます。

バックアップを別のリージョンへコピーすることは、クロスリージョンの災害復旧と事業継続性の目標を満たすのに役立ちます。一方、別のアカウントへコピーすることは、誤削除、運用上のエラー、またはアカウントのリスクからバックアップを保護するのに役立ちます。
