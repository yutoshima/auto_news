# Amazon WorkSpaces Applications は NVIDIA Blackwell GPU インスタンスをサポートに追加しました

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月03日 17:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-workspaces-applications-nvidia-blackwell-gpu-instances/](https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-workspaces-applications-nvidia-blackwell-gpu-instances/)

## 概要

<p>Amazon WorkSpaces Applications は現在、NVIDIA RTX PRO 4500 Blackwell Server Edition GPU と Intel Xeon Scalable（第6世代）プロセッサを搭載した Graphics G7 インスタンスをサポートしています。G7 インスタンスは、前世代の G6 インスタンスと比較して、グラフィックス集約型ワークロードのパフォーマンスを最大で 2.1 倍向上させます。</p> 
<p>Graphics G7 を使用すると、CAD/CAM、3D レンダリング、科学的ビジュアライゼーション、ビデオ編集、AI アシスト設計ワークフローなど、 demanding なプロフェッショナルアプリケーションを高精細でストリーミングできます。</p>
