# AWS EC2 Auto Scaling がアカウントレベルで Launch Before Terminate をサポートし、インスタンスを置き換えられるようになりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月26日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/ec2-auto-scaling-launch-before-terminate/](https://aws.amazon.com/about-aws/whats-new/2026/10/ec2-auto-scaling-launch-before-terminate/)

## 概要

AWS EC2 Auto Scaling は、すべての Auto Scaling グループでデフォルトの置換動作として Launch Before Terminate を有効にできるようになりました。有効化すると、Auto Scaling は置換用のインスタンスを起動し、それがヘルスチェックを通過するまで待機してから、置換元のインスタンスを終了します。これにより、インスタンス置換イベント中もアプリケーションの容量と可用性を保持できます。これは、インスタンスのリフレッシュ、再バランス、ヘルスチェック、最大値などの置換イベントに適用されます。
