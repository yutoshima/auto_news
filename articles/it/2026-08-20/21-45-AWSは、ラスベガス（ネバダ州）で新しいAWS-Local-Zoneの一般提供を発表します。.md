## 概要

ラスベガス（ネバダ州）の AWS Local Zone が一般提供開始されました。新しい AWS Local Zone は、Amazon EC2 の C7i、M7i、R7i、C8gn インスタンス、EBS ボリュームタイプ gp3、gp2、io1、sc1、st1、Amazon ECS、Amazon EKS、Application Load Balancer、そして AWS Direct Connect をサポートします。

AWS Local Zones は、コアサービスを拡張する AWS のインフラストラクチャ配置です。
