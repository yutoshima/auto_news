# AWS Console Homeは現在、AWS European Sovereign Cloud（ドイツ）リージョンのコストと使用量のウィジェットをサポートします。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年07月28日 16:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/07/aws-console-home-cost-and-usage-eu-sovereign-cloud](https://aws.amazon.com/about-aws/whats-new/2026/07/aws-console-home-cost-and-usage-eu-sovereign-cloud)

## 概要

AWS Console Home は現在、AWS European Sovereign Cloud（ドイツ）リージョンの Cost and Usage ウィジェットをサポートしており、Cost Explorer や Cost Optimization Hub のインサイトを Console Home ダッシュボードに表示できます。

Cost and Usage ウィジェットを使うと、月初来実績費用と予測費用を追跡し、節約機会を特定し、サービス別の支出の推移を把握できます。

開始するには、以下にサインインしてください: https://console.amazonaws-eusc.eu/
