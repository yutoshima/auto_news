## 概要

Amazon Relational Database Service (Amazon RDS) for SQL Server は、読み取り専用レプリカ インスタンス上で直接DBスナップショットを作成できるようになりました。これまではスタンドアロンおよびプライマリDBインスタンスのみでスナップショットを作成できました。読み取り専用レプリカを先に昇格させることなくスナップショットを作成できるようになり、バックアップおよび災害復旧（DR）ワークフローの柔軟性が向上します。
