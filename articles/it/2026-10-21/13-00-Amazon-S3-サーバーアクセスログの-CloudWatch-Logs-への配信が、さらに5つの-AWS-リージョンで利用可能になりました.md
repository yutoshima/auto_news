# Amazon S3 サーバーアクセスログの CloudWatch Logs への配信が、さらに5つの AWS リージョンで利用可能になりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月21日 13:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-s3-server-access-logs-cloudwatch-logs-regions/](https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-s3-server-access-logs-cloudwatch-logs-regions/)

## 概要

<p>Amazon S3 サーバーアクセスログの CloudWatch Logs への配信は、AWS GovCloud (US) リージョン、AWS European Sovereign Cloud、そして AWS China リージョンで利用可能になりました。CloudWatch Logs にアクセスログを格納すれば、到着時にクエリを実行したり、アラームを設定したり、AWS Key Management Service (AWS KMS) キーで暗号化したりできます。この新しい配信経路は、既存の S3 一般用途バケットへのサーバーアクセスログ配信を補完するもので、アクセスの監視と分析の柔軟性を高めます。
