# Amazon Route 53は現在、Advanced Hosted Zonesを提供しています。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月20日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/route-53-offers-advanced-hosted-zones/](https://aws.amazon.com/about-aws/whats-new/2026/11/route-53-offers-advanced-hosted-zones/)

## 概要

<p>Amazon Route 53は現在、「Advanced Hosted Zones」という新しいホステッドゾーン階層を提供しています。これは追加のガードレール、可視性、耐障害性機能を備えたものです。Advanced Hosted Zonesには、誤ってレコードを削除してしまうのを防ぐ変更ガードレール、レコード単位の変更履歴、プライベートホステッドゾーンでの公開DNSフォールバックが含まれます。</p>
<p>DNSの1つの誤った変更だけで、まだトラフィックを受けているレコードを削除したり、解決に使用されているデリゲーションを削除したりするなど、ドメインの一部をオフラインにしてしまうことがあります。</p>
