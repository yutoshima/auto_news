# Amazon Bedrock での Web 検索の外部 Web アクセスを開始する

- **カテゴリ**: it

## 概要

今月初めに、Amazon Bedrock 上の Web 検索を公開しました。これは、現在のウェブ知識を用いてモデルの回答を補強しつつ、データを安全な AWS 環境内に保持し、データの外部送信を行わない組み込みのサーバーサイドツールです。本日、外部ウェブアクセスを許可する external_web_access パラメータを有効にして Web 朜索が直接コンテンツを取得できるよう、Web 検索を拡張します。
