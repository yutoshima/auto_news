## 概要

AWS Systems Manager Parameter Storeは、5つのAPI操作のデフォルトスループット制限を引き上げました。高スループット設定を有効にしているアカウントでは、TPS（秒間取引数）は以下のとおり変更されました。

- GetParametersByPath（100から500 TPSへ）
- PutParameter（10から50へ）
- DeleteParameter（5から50へ）
