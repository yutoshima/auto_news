# AWS GovCloud (US)リージョンで、イベントホールドを伴うAmazon S3オブジェクトロックの可変保持機能が利用可能になりました。

## 概要

Amazon S3 Object Lock のイベント保留を伴う可変保持対応が、AWS GovCloud (US-East) および AWS GovCloud (US-West) で利用可能になりました。

Amazon S3 Object Lock の可変保持機能は、契約成立や監査完了など、将来のイベントから始まる必要保持期間が設定されるオブジェクトに対して、書き込みは一度のみ読み取りは複数回可能（WORM）保護を適用します。オブジェクトにイベント保留と保持期間を設定すると、保留中は S3 がそのオブジェクトを保護します。
