# AWS Agent Registry は現在、WebBotAuth ボット登録をサポートしています。

## 概要

AWS Agent Registryは現在、新しいレコードタイプとしてWebBotAuth（WBA）ボットの登録をサポートしています。標準化されたプロトコルを通じて正当なボットトラフィックを検証しやすくします。これまでは組織が検証済みボットと悪意のあるトラフィックを識別する標準化された方法を欠いていました。現在、ボットはWebBotAuthを通じてドメイン所有権を証明でき、この検証をAWSの統合サービスと連携させることが可能です。
