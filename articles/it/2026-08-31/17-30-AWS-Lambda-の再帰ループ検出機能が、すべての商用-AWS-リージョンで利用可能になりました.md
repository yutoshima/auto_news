# AWS Lambda の再帰ループ検出機能が、すべての商用 AWS リージョンで利用可能になりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月31日 17:30
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/lambda-recursion-regions](https://aws.amazon.com/about-aws/whats-new/2026/08/lambda-recursion-regions)

## 概要

AWS Lambda の再帰ループ検出機能が、すべての商用 AWS リージョンへと拡張されました。デフォルトで有効になっているこの機能は、Lambda 関数と他のサポート対象サービス間の再帰的な起動を自動的に検出して停止するガードレールであり、暴走するワークロードを防ぎます。

S3、SQS、SNS などのイベントソースを使用して Lambda 関数をトリガーする場合、設定ミスが発生する可能性があります。
