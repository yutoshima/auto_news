# AWS Batchが現在、Amazon ECS Managed Instancesをサポートしました。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月25日 19:36
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/aws-batch-on-ecs-managed-instances/](https://aws.amazon.com/about-aws/whats-new/2026/08/aws-batch-on-ecs-managed-instances/)

## 概要

AWS Batchは新しいコンピュートオプションとしてAmazon ECS Managed Instances（ECS MI）をサポートするようになり、AWS管理のインフラ上でGPU加速および計算集約型のバッチワークロードを実行できます。ECS MI上のAWS Batchを利用すれば、GPU加速インスタンスにアクセスできるとともに、AMIの更新、セキュリティパッチ適用、インスタンスのライフサイクル管理をAWSが自動で処理するため、顧客管理のAmazon EC2インフラストラクチャに伴う運用負荷を削減できます。始めるには、ECS MI上のAWS Batchを作成してください。
