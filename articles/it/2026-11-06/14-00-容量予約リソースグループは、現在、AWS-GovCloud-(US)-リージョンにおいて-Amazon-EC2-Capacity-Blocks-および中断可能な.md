# 容量予約リソースグループは、現在、AWS GovCloud (US) リージョンにおいて Amazon EC2 Capacity Blocks および中断可能な Capacity Reservations をサポートします

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月06日 14:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/capacity-reservation-resource-groups-support-in-aws-govcloud-regions](https://aws.amazon.com/about-aws/whats-new/2026/11/capacity-reservation-resource-groups-support-in-aws-govcloud-regions)

## 概要

本日から、ML用の容量ブロックや中断可能な容量予約を、AWS GovCloud (US) リージョンの容量予約リソースグループに追加できるようになります。Amazon EC2 は、オンデマンド容量予約（ODCR）、中断可能な容量予約、ML用の容量ブロックなど、さまざまな予約提供を提供しています。従来、容量予約リソースグループにはODCRのみを含めることができました。これからは、どのタイプの容量予約でも容量予約リソースグループに追加できます。
