# Amazon S3 Vectors は現在、AWS ヨーロッパ管轄クラウド（ドイツ）リージョンで利用可能です。

## 概要

Amazon S3 Vectorsが、AWSの欧州主権クラウド（ドイツ）リージョンで利用できるようになりました。Amazon S3 Vectorsは、AIエージェント、推論、RAG（ Retrieval Augmented Generation ）、およびセマンティック検索を十億規模のベクトルで扱うために特別に設計されたベクトルストレージです。S3 Vectorsは、Amazon S3と同じ弾力性、耐久性、可用性を提供するよう設計されており、インフラを事前に用意することなくベクトルを格納・アクセス・クエリできる専用APIセットを備えています。
