# AWSエンドユーザーメッセージングは現在、OTP検証をエンドツーエンドで管理します

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月16日 07:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/aws-end-user-messaging-adds-end-to-end-managed-OTP](https://aws.amazon.com/about-aws/whats-new/2026/10/aws-end-user-messaging-adds-end-to-end-managed-OTP)

## 概要

本日、AWS End User MessagingはNotifyにおけるエンドツーエンドの管理型ワンタイムパスコード（OTP）検証を発表します。電話番号の設定、キャリアへの登録、またはメッセージの配信方法を管理することなく、電話番号とコード検証を含む5分未満で動作するOTPソリューションを利用できます。従来は自分でパスコードを生成してNotifyへ送信依頼をしており、コードの作成・保存・有効期限管理のロジックを構築・維持していました。今はNotifyがコードを生成します。
