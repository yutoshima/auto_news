# AWS End User Messagingは現在、ブランドプロファイルをサポートしています。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月16日 07:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/aws-end-user-messaging-now-supports-brand-profiles](https://aws.amazon.com/about-aws/whats-new/2026/10/aws-end-user-messaging-now-supports-brand-profiles)

## 概要

本日、AWS End User Messaging はブランドプロフィールを発表します。ブランドや会社情報を一度保存し、それをメッセージ登録全体で再利用できる機能です。SMS、RCS、WhatsApp でメッセージを送信するには、ブランドを通信事業者やメッセージ提供者に登録しますが、現在は各チャンネルと国ごとに、同じ会社の詳細情報、住所、連絡先、ユースケースを手動で各フォームに入力しています。その繰り返しの入力は新しい登録ごとに時間を要し、入力ミスやその他の誤りの原因になります。
