# AWS Transit Gatewayと AWS Cloud WAN が現在 1対1 NAT をサポートします

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月23日 15:43
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/aws-transit-gateway-cloud-wan-1-1-nat/](https://aws.amazon.com/about-aws/whats-new/2026/10/aws-transit-gateway-cloud-wan-1-1-nat/)

## 概要

<p>AWS Transit Gateway と AWS Cloud WAN は現在、Regional Private NAT Gateway との統合を通じて、アタッチメント上で直接管理された1対1のネットワークアドレス変換（NAT）を提供します。これにより、同じIPアドレス範囲を共有する private network 同士を、いずれのネットワークの番号変更も NAT アプライアンスの展開もリターン・トラフィックルールの作成も必要なく接続できるようになります。</p> 
<p>クラスレス・インタードメイン・ルーティング（CIDR）ブロックが重複するネットワークは長い間、通信できませんでしたが、これにより通信が可能になります。</p>
