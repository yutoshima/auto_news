# Amazon RDS for SQL Server は現在 M8id および R8id インスタンスをサポートしています。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月12日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/rds-sqlserver-supports-m8id-r8id-instances](https://aws.amazon.com/about-aws/whats-new/2026/11/rds-sqlserver-supports-m8id-r8id-instances)

## 概要

Amazon Relational Database Service (Amazon RDS) for SQL Serverは、M8idおよびR8idインスタンスのサポートを開始しました。これらのインスタンスは、AWS限定で提供されるカスタム Intel Xeon 6 プロセッサを搭載し、ローカル NVMe SSD ストレージを含みます。最大で384 vCPU、3 TiBのメモリ、22.8 TBのローカル NVMe SSDストレージまでスケールします。M5dおよびR5dインスタンスの4倍のvCPUとメモリ、そしてローカルストレージは6倍超を実現します。
