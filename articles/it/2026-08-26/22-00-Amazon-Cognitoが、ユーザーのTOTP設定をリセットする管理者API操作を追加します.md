# Amazon Cognitoが、ユーザーのTOTP設定をリセットする管理者API操作を追加します

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月26日 22:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-cognito-totp-reset/](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-cognito-totp-reset/)

## 概要

<p>Amazon Cognitoは、ユーザーの時間ベースのワンタイムパスワード（TOTP）多要素認証（MFA）設定をリセットする新しい管理 API 操作を提供します。ユーザーがTOTPデバイスへのアクセスを失った場合、管理者はデバイスの関連付けを解除でき、次回のサインイン時にユーザーが新しいデバイスを登録できるようにします。</p> 
<p>これにより、TOTPデバイスへのアクセスを失ってロックアウトされたユーザーを回復するためにアカウントを再作成する必要がなくなります。顧客はMFAの強制を維持しつつ、新しいデバイスの登録を許可する運用が可能です。</p>
