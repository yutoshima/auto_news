# Microsoft Edgeが、Chromeと同様、古い広告ブロッカーを締め出そうとしているところだ

## メタデータ

- **情報源**: The Verge
- **カテゴリ**: it
- **公開日時**: 2026年08月07日 17:43
- **URL**: [https://www.theverge.com/tech/976880/microsoft-edge-extensions-ad-blockers-mv2-mv3](https://www.theverge.com/tech/976880/microsoft-edge-extensions-ad-blockers-mv2-mv3)

## 概要

Microsoft EdgeはManifest V2拡張機能プラットフォームのサポートを終了します。これにより、uBlock Originのような広告ブロッカーを含む拡張機能の動作が停止します。これは、今年初めにGoogle Chromeが行った対応と同様です。Microsoftの説明によれば、Edgeアドオンストアには「実質的な利用がある」MV2をまだ使用している拡張機能はわずか58個で、うち3つのみだとのことです。
