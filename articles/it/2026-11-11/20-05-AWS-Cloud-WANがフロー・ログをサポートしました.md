# AWS Cloud WANがフロー・ログをサポートしました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月11日 20:05
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/aws-cloud-wan-flow-logs/](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-cloud-wan-flow-logs/)

## 概要

<p>AWS Cloud WANは現在、VPC Flow Logsをサポートしており、グローバルネットワーク全体のIPトラフィックを一元的に可視化します。Flow Logsは各フローの詳細情報をキャプチャするため、AWS Cloud WANアカウントを離れることなく、コアネットワーク上のトラフィックの動きを理解できます。</p>
<p>これまでは、ネットワーク管理者がグローバルネットワーク全体のトラフィックを把握するために、複数のVPC、アカウント、リージョンからVPC Flow Logsを組み合わせて確認する必要がありました。彼らはしばしば、他のチームにアクセス権を依頼していました。</p>
