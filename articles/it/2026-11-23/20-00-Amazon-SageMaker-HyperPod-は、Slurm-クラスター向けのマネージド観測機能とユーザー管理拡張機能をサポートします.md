# Amazon SageMaker HyperPod は、Slurm クラスター向けのマネージド観測機能とユーザー管理拡張機能をサポートします

## 概要

<p>Amazon SageMaker HyperPod は Slurm クラスター用のマネージド・クラスター拡張機能をサポートします。SageMaker AI コンソールまたは API から、マネージド機能のインストール・設定・更新・削除を行えます。最初の2つの拡張機能は、可観測性とユーザー管理をカバーします。これまでは HyperPod Slurm クラスターの可観測性やユーザー管理の変更のたびにライフサイクル・スクリプトを編集し、その後ノードを置換するか再実行する必要がありました。現在、HyperPod がこれらの機能を代行して管理し、あなたはライフサイクル・スクリプトとカスタム設定を維持します。</p>
