# Amazon BedrockのManaged Knowledge Baseが、Confluence Data Centerをネイティブデータソースコネクターとして利用可能になりました。

## 概要

AWSは、完全管理型の検索強化生成（RAG）サービスであるAmazon Bedrock Managed Knowledge Base向けのConfluence Data Centerデータソースコネクターを発表しました。自主運用のConfluence Data Centerを実行しているお客様は、Confluenceスペース内のブログやページを直接マネージドナレッジベースへクロールできます。以前はConfluence Data CenterのコンテンツをBedrock Knowledge Basesに取り込むにはカスタムインジェストパイプラインを構築する必要がありましたが、今後はインスタンスの認証情報を提供するだけで済みます。
