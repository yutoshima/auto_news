# Amazon MSKスタンダード・ブローカーが Apache Kafka バージョン4.2をサポートに追加する

- **カテゴリ**: it

## 概要

<p>Amazon Managed Streaming for Apache Kafka（Amazon MSK）は、標準ブローカーで Apache Kafka バージョン 4.2 をサポートします。本リリースの重要なポイントは、Queues for Kafka がついに本番運用に耐える状態になったことです。Queues を使用すると、同じトピックのパーティションから複数のコンシューマがメッセージを処理できるようになり、ポイント・ツー・ポイントのメッセージ配信を必要とするワークロードの並列性とスループットが向上します。また、本リリースにはリーダー選出の正確性を向上させる Eligible Leader Replicas（ELR）の強化も含まれています。これによりリーダー選出の正確性が改善されます。
