# AWS Direct Connect がペルー・リマで100G拡張を発表

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年07月22日 04:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/07/aws-direct-connect-100g-lima/](https://aws.amazon.com/about-aws/whats-new/2026/07/aws-direct-connect-100g-lima/)

## 概要

今日は、ペルー共和国リマのCirionデータセンターにある既存の AWS Direct Connect ロケーションで、100 Gbps専用接続の拡張を発表しました。これにより、現地からすべての公開AWSリージョン（中国を除く）、AWS GovCloudリージョン、そしてAWS Local Zones へのプライベートで直接的なネットワークアクセスを確立できるようになりました。これは、最初の AWS Direct Connect ロケーションです。
