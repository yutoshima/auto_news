# Amazon EC2 P6-B300 インスタンスが、AWS アジア太平洋（ジャカルタ）リージョンで利用可能になりました。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月03日 19:03
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-ec2-p6-b300-instances-available-asia-pacific-jakarta](https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-ec2-p6-b300-instances-available-asia-pacific-jakarta)

## 概要

本日より、Amazon Elastic Cloud Compute（Amazon EC2）P6-B300インスタンスがAWSアジア太平洋（ジャカルタ）リージョンで利用可能になります。P6-B300インスタンスは、8基のNVIDIA Blackwell Ultra GPUsを搭載し、2.1 TBの高帯域GPUメモリ、6.4 TbpsのEFAネットワーキング、300 Gbpsの専用ENAスループット、4 TBのシステムメモリを提供します。

P6-B300インスタンスはP6-B200インスタンスと比較して、ネットワーク帯域を2倍、GPUメモリ容量を1.5倍、GPUのTFLOPSを1.5倍（FP4、スパース性なし）を実現しており、適しています。
