## 概要

<p>Amazon Connect Customer は標準メトリクスのライブラリを提供します。カスタムメトリクスはさらに踏み込み、ビジネス固有の測定値を定義します。しかし、さまざまなインスタンスで手動で管理すると、定義が徐々にずれてしまい、数値が一致しなくなってしまいます。信頼できないメトリクスは、情報が全くないメトリクスよりも悪いもので、人々はそれに基づいて意思決定をしてしまうからです。</p> 
<p>今度は、メトリクスを一度定義して、7つの新しい API 操作（CreateMetric、DeleteMetric、…）を通じてプログラムmaticallyに管理します。</p>
