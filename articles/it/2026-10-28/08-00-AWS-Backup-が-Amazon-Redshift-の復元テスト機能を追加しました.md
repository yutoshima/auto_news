# AWS Backup が Amazon Redshift の復元テスト機能を追加しました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月28日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/aws-backup-adds-redshift-restore-testing/](https://aws.amazon.com/about-aws/whats-new/2026/10/aws-backup-adds-redshift-restore-testing/)

## 概要

AWS Backupの復元テストは現在、Amazon Redshiftをサポートしています。復元テストはバックアップの復元を自動化・定期的に実行するのに役立ち、Amazon Redshiftのバックアップが正常に復元されることを確認し、復元に要する時間を測定できます。

これで他のサポート対象のAWSリソースと同様に、ストレージ、コンピュート、データベースサービス全体の復元テスト計画にAmazon Redshiftを含めることができます。復元テスト計画は回復ポイントを自動的に選択し、復元を実行します。
