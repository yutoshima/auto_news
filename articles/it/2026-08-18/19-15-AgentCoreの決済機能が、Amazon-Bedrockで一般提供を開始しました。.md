# AgentCoreの決済機能が、Amazon Bedrockで一般提供を開始しました。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月18日 19:15
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/bedrock-agentcore-payments-ga/](https://aws.amazon.com/about-aws/whats-new/2026/08/bedrock-agentcore-payments-ga/)

## 概要

本日、AWSは AgentCore ペイメントの一般提供を発表します。これは Amazon Bedrock の AgentCore 内の機能で、AIエージェントが数行のコードで有料API、MCP、コンテンツを自律的に発見・アクセス・支払いできるようにします。AgentCore ペイメントは、企業が大規模に取引エージェントを本番環境で展開する際に必要なセキュリティ、ガードレール、 observability（可観測性）を提供します。

AgentCore ペイメントはマイクロトランザクション用に Coinbase と Stripe Privy ウォレットと統合し、ペイメントを実現します。
