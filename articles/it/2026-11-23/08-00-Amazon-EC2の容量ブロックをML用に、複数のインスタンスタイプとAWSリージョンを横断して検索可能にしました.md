# Amazon EC2の容量ブロックをML用に、複数のインスタンスタイプとAWSリージョンを横断して検索可能にしました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月23日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/ec2-capacity-blocks-ml-flex-search/](https://aws.amazon.com/about-aws/whats-new/2026/11/ec2-capacity-blocks-ml-flex-search/)

## 概要

Amazon EC2 Capacity Blocks for MLは、複数のインスタンスタイプとAWSリージョンを1回の検索で横断して検索できるようになり、MLワークロードに必要な容量を見つけて確保するのがこれまでより容易になりました。ML向けCapacity Blocksを利用すると、将来の開始日と最大6か月間の予約期間で、Amazon EC2 P6-B300、P6-B200、Trn2などの加速コンピュートインスタンスを予約できます。

これまでは、Capacity Blocksを購入するために、各インスタンスタイプごとに別々の検索を実行しなければなりませんでした。
