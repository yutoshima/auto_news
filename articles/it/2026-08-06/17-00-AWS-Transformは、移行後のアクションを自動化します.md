# AWS Transformは、移行後のアクションを自動化します

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月06日 17:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/aws-transform-for-migrations-automates-post-launch-actions](https://aws.amazon.com/about-aws/whats-new/2026/08/aws-transform-for-migrations-automates-post-launch-actions)

## 概要

AWS Transformは、移行ワークフローを通じて起動後のアクションの設定と実行を自動化します。アカウントレベルでアクションを定義し、ターゲットアカウントごとに各ソースサーバへ自動適用します（マルチアカウント移行を含む）。これらのアクションを自動化することで、サーバーごとに設定する遅くてミスが発生しやすい作業を排除し、チームがより多くのサーバーを手動作業を減らして移行できます。

起動後のアクションは、AWS Systems Manager（SSM）を通じて直ちに実行されます。
