# Amazon Route 53 Resolver DNSファイアウォールは現在、自動許可リスト生成をサポートします

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月17日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/route-53-dns-firewall-auto-allowlists/](https://aws.amazon.com/about-aws/whats-new/2026/11/route-53-dns-firewall-auto-allowlists/)

## 概要

<p>Amazon Route 53 Resolver DNSファイアウォールは、VPCの観測DNSクエリ トラフィックから自動的にドメインの許可リストを生成し、最小権限のDNSアクセスを強制し、DNSベースのデータ外部流出リスクを低減します。</p>
<p>以前は、最小権限モデルを実装するにはセキュリティチームがDNSクエリログを手動で分析し、VPCが依存しているドメインを特定してから許可リストルールを展開する必要がありました。これにより運用上の負荷が発生し、 deny-by-def の適用が遅れることがありました。</p>
