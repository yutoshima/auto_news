# Amazon EKS は、Amazon EKS Auto Mode および Karpenter で EFA とプレースメント グループをサポートします。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年07月22日 14:30

## 概要

<p>Amazon Elastic Kubernetes Service（EKS）は現在、EKS Auto Mode のノードプールとオープンソースの Karpenter プロジェクトに対して、Amazon EC2 プレースメントグループおよび Elastic Fabric Adapter（EFA）のネットワークデバイス構成をサポートしており、パフォーマンスと可用性を最適化するための EKS ワークロードを可能にします。これらの機能により、分散トレーニングおよび推論ワークロードのために EFA ネットワークインターフェイスの構成や、EC2 インスタンスが AWS インフラストラクチャ全体に物理的にどのように分散されるかを制御できます。<br /> <br />
