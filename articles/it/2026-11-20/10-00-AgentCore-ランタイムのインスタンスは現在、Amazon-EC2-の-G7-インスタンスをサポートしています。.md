# AgentCore ランタイムのインスタンスは現在、Amazon EC2 の G7 インスタンスをサポートしています。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月20日 10:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/agentcore-ec2-g7/](https://aws.amazon.com/about-aws/whats-new/2026/11/agentcore-ec2-g7/)

## 概要

<p>Amazon Bedrock AgentCore の <a href="https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/runtime-instances.html">ランタイムインスタンス</a> が、NVIDIA RTX PRO 4500 Blackwell Server Edition GPU を搭載した Amazon EC2 G7 インスタンスをサポートしました。ランタイムインスタンスは AgentCore がプロビジョニング、パッチ適用、スケーリング、ライフサイクル管理を処理する一方で、エージェントを Amazon EC2 インスタンス上で実行します。G7 インスタンスは、3D レンダリングやモデル推論を行うエージェントに、G6e ファミリーなどと並ぶ追加の GPU オプションを提供します。
