# Amazon EC2 Dedicated Hostsは、セルフマネージドライセンスなしでホストリソースグループをサポートするようになりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年07月24日 21:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/07/ec2-dedicated-hosts-hrg/](https://aws.amazon.com/about-aws/whats-new/2026/07/ec2-dedicated-hosts-hrg/)

## 概要

本日から、顧客は EC2 Dedicated Hosts のためのホストリソースグループ（HRG）を、以前必要だった自分で管理するライセンス（SML）を作成し、AWS License Manager を通じて AMI を紐づけるというステップを踏まずに作成できるようになります。

この柔軟性は特に EC2 Mac インスタンスのお客様や、BYOL（Bring Your Own License）を利用する場合ではなく、ハードウェアレベルの分離のために Dedicated Hosts が必要な顧客にとって価値があります。BYOL ワークロードをお持ちのお客様は、HRG を SML で作成して、o への対応を確実にすることを続けることができます。
