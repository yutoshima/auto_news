# AWSアプリケーションロードバランサーとネットワークロードバランサーが、RFC 9151準拁のセキュリティポリシーに対応しました

## メタデータ

- **カテゴリ**: it
- **公開日時**: 2026年08月04日 18:28
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/aws-application-network/](https://aws.amazon.com/about-aws/whats-new/2026/08/aws-application-network/)

## 概要

AWS Application Load Balancer（ALB）と Network Load Balancer（NLB）は、RFC 9151 TLSサーバ要件に準拠したCNSA 1.0スイート要件を満たす新しいTLSベースのセキュリティポリシーをサポートします。これらのポリシーは、TLS 1.2およびTLS 1.3プロトコルを用いた安全な通信のためにUS国家安全保障局（NSA）が定義した暗号要件を実装しています。  
CNSA 1.0 TLSセキュリティ要件を満たす必要があるお客様は、今すぐご利用いただけます。
