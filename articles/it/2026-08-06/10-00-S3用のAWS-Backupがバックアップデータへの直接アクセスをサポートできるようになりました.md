# S3用のAWS Backupがバックアップデータへの直接アクセスをサポートできるようになりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月06日 10:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/aws-backup-amazon-s3-direct-access/](https://aws.amazon.com/about-aws/whats-new/2026/08/aws-backup-amazon-s3-direct-access/)

## 概要

AWS Backup for Amazon S3は現在、S3アクセスポイントの作成をサポートしており、復元を開始することなく、標準のS3 APIを使用してバックアップデータへ即座に読み取り専用アクセスを提供します。これにより、バックアップデータを回復することなく、ターゲットファイルのリカバリ、データ検証、コンプライアンス監査、法科学調査を実施でき、バックアップデータはバックアップ保管庫内で保護されたままになります。

S3リカバリポイントのアクセスニッポを作成し、GetObject、HeadObject、ListObjectsV2などの標準S3操作を使用してバックアップデータを読み取ることができます。
