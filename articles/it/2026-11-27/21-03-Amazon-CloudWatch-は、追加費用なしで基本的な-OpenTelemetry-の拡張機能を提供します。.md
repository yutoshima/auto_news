# Amazon CloudWatch は、追加費用なしで基本的な OpenTelemetry の拡張機能を提供します。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月27日 21:03
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-cloudwatch-opentelemetry-enrichment/](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-cloudwatch-opentelemetry-enrichment/)

## 概要

<p>Amazon CloudWatchは現在、追加費用なしでAWSサービスのメトリクス向けの基本的なOpenTelemetryエンリッチを提供します。基本エンリッチは、AWSサービスがCloudWatchに公開するメトリクスを、PromQLでクエリできるOpenTelemetryデータポイントへ変換します。InstanceIdディメンションなど、リソースを識別するメトリクスを対象とします。エンリッチされたメトリクスには、Amazon Resource Name、クラウドプロバイダー、リージョン、アカウントIDのリソース属性と、計測スコープの命名が付与されます。
