# Amazon MSKは現在、Kafkaオーソライザーログを顧客に提供します

- **カテゴリ**: it

## 概要

<p><a href="https://aws.amazon.com/msk/">Amazon Managed Streaming for Apache Kafka (MSK)</a> は、標準クラスタと Express ブローカーの両方を含む「認証機能ログ配信」を追加料金なしでサポートします。認証機能ログを利用することで、ユーザーおよびアプリケーションのアクセスを詳細に把握し、クライアントの認可問題を特定・対処し、組織のセキュリティ要件を満たすことができます。拒否された認可リクエストはすべて、クライアントのIPアドレスと該当の API とともに記録されます。
