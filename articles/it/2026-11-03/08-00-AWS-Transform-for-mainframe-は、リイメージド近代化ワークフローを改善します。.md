# AWS Transform for mainframe は、リイメージド近代化ワークフローを改善します。

## 概要

<p>メインフレーム向け AWS Transform は、ビジネス機能をフィールドレベルの正確さで検出し、アセスメントとリイメージのワークフロー内で新しい要件カバレッジレポートを生成します。以前は、同じテーブルやファイルを使用するビジネス機能がまとめられており、AWS Transform のアーティファクトから独自のトレーサビリティレポートを作成する必要がありました。今回のリリースにより、ビジネス機能のより正確なカタログから z/OS COBOL および PL/I ワークロードの近代化を開始し、要件のカバレッジを検証できます。</p>
