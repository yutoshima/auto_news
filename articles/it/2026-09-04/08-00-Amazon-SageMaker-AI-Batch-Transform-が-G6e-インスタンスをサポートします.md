# Amazon SageMaker AI Batch Transform が G6e インスタンスをサポートします

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月04日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/09/sagemaker-batch-transform-g6e-instances/](https://aws.amazon.com/about-aws/whats-new/2026/09/sagemaker-batch-transform-g6e-instances/)

## 概要

Amazon SageMaker AI は現在、バッチ変換のために <a href="https://aws.amazon.com/ec2/instance-types/g6e/">Amazon EC2 G6e インスタンス</a> をサポートします。バッチ変換は、Amazon S3 に保存されたデータセットに対して予測を実行するためのもので、継続的な推論エンドポイントを必要としない大規模データセットに適しています。

Amazon EC2 G6e インスタンスは、GPU 1 台あたり 48 GB のメモリを搭載した最大 8 台の NVIDIA L40S Tensor Core GPU と、第3世代 AMD EPYC プロセッサを搭載しています。G6e インスタンスは、性能の向上を実現します。
