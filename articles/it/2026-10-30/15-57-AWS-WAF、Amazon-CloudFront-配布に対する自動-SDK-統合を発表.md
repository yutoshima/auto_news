# AWS WAF、Amazon CloudFront 配布に対する自動 SDK 統合を発表

- **カテゴリ**: it

## 概要

<p>AWS WAFはAmazon CloudFront配信の自動SDK統合を発表します。有効にすると、CloudFrontは提供するHTMLにAWS WAF JavaScript SDKのスクリプトタグを追加しますが、アプリケーションコード・ビルドプロセス・デプロイには一切変更を加えません。SDKは、3つのAWS WAFマネージドルールグループが使用するクライアントサイドのシグナルを提供します。対象検査レベルのBot Control、アカウウント乗っ取り防止（ATP）、アカウント作成詐欺防止（ACFP）です。</p>
