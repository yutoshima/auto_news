# AWS Lambdaの耐久性機能が、AWS GovCloud（US）リージョンで利用可能になりました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月16日 18:26
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/durablefunctions-govcloud/](https://aws.amazon.com/about-aws/whats-new/2026/10/durablefunctions-govcloud/)

## 概要

AWS Lambda ド durable functions は、AWS GovCloud (US-West) および AWS GovCloud (US-East) リージョンで利用可能になりました。Lambda durable functions を使うと、Lambda の開発者体験の中で、信頼性の高いマルチステップのアプリケーションや AI ワークフローを構築できます。

Lambda durable functions は、イベントハンドラ内の新しいプリミティブ（「step」や「wait」など）を追加することで、進捗をチェックポイント化し、障害から自動的に回復し、実行を一時停止することを可能にする、Lambda のプログラミングモデルを拡張します。
