# Amazon EKS Auto Mode が Pods の適正サイズ化を行い、計算コストを削減します（プレビュー）

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月17日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/eks-auto-mode-pod-rightsizing-preview/](https://aws.amazon.com/about-aws/whats-new/2026/11/eks-auto-mode-pod-rightsizing-preview/)

## 概要

Amazon Elastic Kubernetes Service（Amazon EKS）は、EKS Auto Modeのリソース最適化を導入します。これは、実際の使用量に基づいて実行中の Pods の CPU とメモリのリクエストを適正化する新機能です。CPU とメモリのリクエストはデプロイ時に設定され、その後見直されることはほとんどありませんが、Auto Mode はこれらに合わせて EC2 インスタンスをプロビジョニングします。リサイズ機能により、Auto Mode が同じデプロイメントや StatefulSet を、手動で調整せず、追加料金なしで、より少ないまたはより小さなインスタンスで実行できるようになります。
