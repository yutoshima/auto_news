# AWS Marketplaceはマルチプロダクトソリューションにおける専門サービスの出品手数料を引き下げます。

## メタデータ

- **カテゴリ**: it
- **公開日時**: 2026年09月01日 18:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/09/aws-marketplace-fee-professional-services/](https://aws.amazon.com/about-aws/whats-new/2026/09/aws-marketplace-fee-professional-services/)

## 概要

AWS Marketplaceは、適格なマルチプロダクトソリューションの一部として購入される専門サービスに対して、0%のリスティング料金を提供するようになりました。これは、最近の専門サービスのリスティング料金を0.5%に引き下げたことを受けた取り組みで、AWS Marketplaceを通じてサービスを取引するパートナーのコストをさらに下げつつ、同時に伴う課金特典を維持します。
