## 概要

<p><a href="https://aws.amazon.com/products/developer-tools/emulator/">AWS Emulator</a> は、ローカルで AWS アプリケーションを構築・テストするために利用可能です。</p>
<p>本日から、AWS Emulator を使って、自分のコンピュータ上または継続的インテグレーション（CI）環境で AWS アプリケーションを構築・テストできます。既存の AWS SDK および CLI の呼び出しはすべて AWS Emulator に向かい、数ミリ秒で戻ってくるため、デプロイや AWS アカウントが不要な状態で、ローカルでエラーを見つけて修正できます。</p>
