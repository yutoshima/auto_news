## 概要

<p>AWS Private Certificate Authority (AWS Private CA) は、Kubernetes 用の AWS Private CA Connector をマネージド Amazon EKS アドオンとして、そして AWS GovCloud (US-East) および AWS GovCloud (US-West) リージョンで AWS Private CA Connector for Active Directory を提供開始します。これらの新機能は、政府ワークロードを管理する AWS GovCloud (US) の顧客が利用できる証明書自動化機能を拡張します。</p>
<p>AWS Private CA Connector for Kubernetes EKS アドオンは、インストールを簡素化します。>
