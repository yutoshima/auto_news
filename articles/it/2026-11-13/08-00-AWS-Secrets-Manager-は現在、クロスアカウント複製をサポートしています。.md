# AWS Secrets Manager は現在、クロスアカウント複製をサポートしています。

- **カテゴリ**: it
- **公開日時**: 2026年11月13日 08:00

## 概要

AWS Secrets Manager は現在、クロスアカウントレプリケーションをサポートしており、セカンダリの AWS アカウントにプライマリ秘密情報の同期済みコピーを維持することで、クロスアカウントアクセス、バックアップ、災害復旧を実現します。クロスアカウントレプリケーションは、既存のマルチリージョンレプリケーション機能をアカウント境界を越えて拡張します。

クロスアカウントレプリケーションを使えば、プラットフォームやセキュリティの担当者が秘密情報を一元管理してローテーションでき、各利用アカウントは常に最新のローカルコピーを受け取ることになります。
