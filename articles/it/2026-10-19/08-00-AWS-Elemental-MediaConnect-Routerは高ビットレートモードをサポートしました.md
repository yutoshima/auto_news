# AWS Elemental MediaConnect Routerは高ビットレートモードをサポートしました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月19日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/mediaconnect-router-high-bitrate/](https://aws.amazon.com/about-aws/whats-new/2026/10/mediaconnect-router-high-bitrate/)

## 概要

AWS Elemental MediaConnect Routerは、250 Mbpsと500 Mbpsの2つの新しい階層を追加し、高ビットレートモードをサポートしました。これにより、より高いビットレートを必要とするプロの放送局は、品質や信頼性を損なうことなく高価値コンテンツを転送できます。

この強化により、放送送出、コンテンツ配信、リモートプロダクションなど、業界標準のワークフローであるVSF TR-07準拠のトランスポートストリーム配信を含む配信が可能になります。高ビットレートモードは、最大2つの冗長ソースをサポートします。
