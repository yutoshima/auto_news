# AWS Glue Data Quality は、コンテキストに特化したルール推奨を数秒で提供します。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年09月22日 08:00

## 概要

AWS Glue Data Qualityは今、数秒でデータ品質ルールを生成し、AWS Glue Data Catalog内のテーブルに対するデータ品質チェックを確立する時間を短縮します。手動設定なしで、全列を網羅した即使用可能なルールセットを提供するため、パイプラインを作成する際に生データから信頼性のあるデータへと、より速く移行できます。

これは、新しいAdvancedモードのルール推奨機能を通じて提供されます。AWS Glue Data Qualityは生成AIを用いて、意図を検出します。
