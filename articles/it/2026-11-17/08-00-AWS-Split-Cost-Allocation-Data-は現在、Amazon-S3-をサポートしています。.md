# AWS Split Cost Allocation Data は現在、Amazon S3 をサポートしています。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月17日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/s3-split-cost-allocation/](https://aws.amazon.com/about-aws/whats-new/2026/11/s3-split-cost-allocation/)

## 概要

<p>共有の Amazon S3 汎用バケットのストレージとリクエスト料金を、AWS コストと使用量レポート（CUR）のプレフィックスに割り当てて表示できるようになりました。多くの組織は、同じバケット内に「marketing/」や「finance/」などの異なるプレフィックスの下で、複数のチーム、アプリケーション、またはテナントのデータを格納しています。以前は、プレフィックス別にこのバケットの請求を分割するには、カスタムパイプラインと独自の料金ロジックが必要でした。</p>
<p>この新機能により、S3 Storage Lens はプレフィックス単位のストレージとリクエストを公開します。</p>
