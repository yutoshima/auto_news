# AWS Site-to-Site VPN は現在、ポスト量子鍵交換をサポートしています

## 概要

AWS Site-to-Site VPNがポスト量子鍵交換をサポートし、VPNトンネルのセキュリティ体制の強化に役立ちます。この機能は、NISTのガイドラインに基づくポスト量子暗号化への移行を支援します。  
  
AWS Site-to-Site VPNは、データセンターや支店とAWSリソース間をIPsecトンネルで暗号化接続する、完全管理型のサービスです。AWS Site-to-Site VPNを使用すると、VPNトンネル内でポスト量子鍵交換方式を設定できるようになります。
