# Amazon BedrockがOpenAI GPTモデル向けのWeb検索を開始します

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月04日 20:37
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-bedrock-web/](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-bedrock-web/)

## 概要

今日は、Amazon Bedrock上のWeb検索の一般提供を発表します。これはAWS内で完全にウェブ検索を実行する組み込みのサーバーサイドツールで、OpenAIモデル（GPT-5.4、GPT-5.5、GPT-5.6 Sol/Terra/Luna）に最新のウェブ知識を用いた回答の根拠を提供すると同時に、データ出力を発生させず、安全なAWS環境内でデータが所在する状態を維持します。従来、ウェブ根拠付けを行うには第三者の検索プロバイダーを導入し、APIキーと請求を別々に管理する必要がありましたが、今回の機能によりそれを解消します。
