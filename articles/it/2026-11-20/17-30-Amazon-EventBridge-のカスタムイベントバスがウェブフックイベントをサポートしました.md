# Amazon EventBridge のカスタムイベントバスがウェブフックイベントをサポートしました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月20日 17:30
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-eventbridge-webhook-events](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-eventbridge-webhook-events)

## 概要

<p>Amazon EventBridge は拡張された Custom イベントバスに対する Webhook イベントをサポートするようになり、SaaS アプリケーション、AIエージェント、カスタム統合が HTTPS 経由でイベントをバスに送信できるようになりました。もう自分の API エンドポイントと計算資源をデプロイ・運用してウェブフックを受信し、それをバスへ公開する必要はありません。</p> 
<p>EventBridge Custom イベントバスはサーバーレスのイベントブローカーで、アプリケーション間、SaaS統合間のイベントをルーティングすることで、スケーラブルなイベント駆動型アプリケーションを作成できるようにします。
