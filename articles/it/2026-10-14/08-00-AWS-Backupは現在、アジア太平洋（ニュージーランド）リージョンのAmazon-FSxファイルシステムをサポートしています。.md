# AWS Backupは現在、アジア太平洋（ニュージーランド）リージョンのAmazon FSxファイルシステムをサポートしています。

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年10月14日 08:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/10/aws-backup-fsx-asia-pacific-new-zealand/](https://aws.amazon.com/about-aws/whats-new/2026/10/aws-backup-fsx-asia-pacific-new-zealand/)

## 概要

AWS Backupは、アジア太平洋（ニュージーランド）リージョンで、Amazon FSx for Lustre、Amazon FSx for NetApp ONTAP、Amazon FSx for OpenZFS、Amazon FSx for Windows File Serverをサポートするようになりました。

このローンチにより、AWS Backupを使ってアジア太平洋（ニュージーランド）リージョンのAmazon FSxファイルシステムのデータ保護を、他のサポート対象リソースと共に中央管理・自動化できます。ポリシーベースのバックアッププランを作成してバックアップのスケジュール設定や保持ルールの適用を行い、バックアップを保存できます。
