# Amazon Aurora DSQL が外部キー制約をサポートしました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年08月27日 07:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/08/aurora-dsql-foreign-key-constraints/](https://aws.amazon.com/about-aws/whats-new/2026/08/aurora-dsql-foreign-key-constraints/)

## 概要

<p><a href="https://aws.amazon.com/rds/aurora/dsql/">Amazon Aurora DSQL</a>は、新規および既存のテーブルに外部キー制約を追加できるようになりました。Aurora DSQLは、サーバーレスで分散型のSQLデータベースで、PostgreSQL互換性とアクティブ-アクティブのマルチリージョン対応を特徴としています。</p>
<p>これにより、アプリケーションのテーブル間の参照ルールを、Aurora DSQLクラスタ内の FOREIGN KEY 制約として表現できるようになりました。たとえば、顧客の「主要住所」が存在することを参照する必要がある、という制約を宣言できます。
