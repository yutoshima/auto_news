# AWS Lambdaが現在、Lambda Managed Instancesの容量プロバイダーのログを公開しています

## 概要

<p>AWS Lambda は現在、Lambda Managed Instances (LMI) キャパシティ・プロバイダのログを Amazon CloudWatch Logs に公開しており、スケーリングアクティビティとインスタンスライフサイクル操作を可視化します。LMI は、サーバーレス運用のシンプルさを維持しつつ、EC2 インスタンス上で Lambda 関数を実行できるようにします。キャパシティ・プロバイダは、Lambda が代わりに用意するコンピュートリソースを定義できるリソースです。キャパシティ・プロバイダのログを使用することで、これらのリソースを監視・トラブルシュート・最適化できます。
