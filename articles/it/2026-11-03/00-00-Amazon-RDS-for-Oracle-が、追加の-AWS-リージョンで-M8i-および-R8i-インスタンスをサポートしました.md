# Amazon RDS for Oracle が、追加の AWS リージョンで M8i および R8i インスタンスをサポートしました

## メタデータ

- **情報源**: AWS What's New
- **カテゴリ**: it
- **公開日時**: 2026年11月03日 00:00
- **URL**: [https://aws.amazon.com/about-aws/whats-new/2026/11/rds-oracle-m8i-r8i-instances-new-regions/](https://aws.amazon.com/about-aws/whats-new/2026/11/rds-oracle-m8i-r8i-instances-new-regions/)

## 概要

Amazon Relational Database Service (Amazon RDS) for Oracleは、追加のAWSリージョンでM8iおよびR8iインスタンスをサポートするようになりました。M8iとR8iの両方のインスタンスは、アジア太平洋地域（ニュージーランド）およびカナダ西部（カルガリー）で利用可能になり、R8iは欧州（ミラノ、ストックホルム、チューリッヒ）およびイスラエル（テルアビブ）でも利用可能です。

これらのインスタンスは、AWS限定のカスタムIntel Xeon 6プロセッサを搭載しており、最高のパフォーマンスを提供します。
